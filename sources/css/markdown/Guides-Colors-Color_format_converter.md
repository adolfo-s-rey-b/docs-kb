Color format converter
======================

This tool lets you enter or pick a color and copy its corresponding value in any CSS [color format](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value)
. You can use the generated color value anywhere the [`<color>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value)
 data type is supported in CSS. This tool can also help you understand the syntax of the different color notations.

[How to use the tool](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Colors/Color_format_converter#how_to_use_the_tool)

---------------------------------------------------------------------------------------------------------------------------------

Enter a color in any format or pick one in the sRGB [color space](https://developer.mozilla.org/en-US/docs/Glossary/Color_space)
. You can also adjust the opacity (alpha channel).

Click the **Copy** button next to the corresponding color format to quickly copy its value. You can also click a color format name to learn more about it.

[See also](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Colors/Color_format_converter#see_also)
