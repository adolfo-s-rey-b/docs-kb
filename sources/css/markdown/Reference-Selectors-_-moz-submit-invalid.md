`:-moz-submit-invalid` CSS pseudo-class
=======================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`:-moz-submit-invalid`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 [pseudo-class](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-classes)
 is a [Mozilla extension](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Mozilla_extensions)
 that represents any submit [`<button>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/button)
 on forms whose contents aren't valid based on their [validation constraints](https://developer.mozilla.org/en-US/docs/Web/HTML/Guides/Constraint_validation)
.

By default, no style is applied. You can use this pseudo-class to customize the appearance of the submit button when there are invalid form fields.
