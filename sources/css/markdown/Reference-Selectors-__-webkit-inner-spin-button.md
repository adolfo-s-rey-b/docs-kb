`::-webkit-inner-spin-button` CSS pseudo-element
================================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`::-webkit-inner-spin-button`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 pseudo-element is used to style the inner part of the spinner button of number picker input elements.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-webkit-inner-spin-button#syntax)

------------------------------------------------------------------------------------------------------------------

[Examples](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-webkit-inner-spin-button#examples)

----------------------------------------------------------------------------------------------------------------------

These examples work only in browsers based on WebKit and Blink.

### [Changing the cursor in the spin controls](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-webkit-inner-spin-button#changing_the_cursor_in_the_spin_controls)

In this example, the CSS [`cursor`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/cursor)
 is changed to `pointer` whenever the cursor is positioned over the inner part of the input's spin controls.
