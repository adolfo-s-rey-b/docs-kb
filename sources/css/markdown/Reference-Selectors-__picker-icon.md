`::picker-icon` CSS pseudo-element
==================================

Limited availability

This feature is not Baseline because it does not work in some of the most widely-used browsers.

Want more browser support for this feature? [Tell us why.](https://github.com/web-platform-dx/developer-signals/issues/278)

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::picker-icon#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`::picker-icon`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 [pseudo-element](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-elements)
 targets the picker icon inside form controls that have an icon associated with them. In the case of a [customizable select element](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)
, it selects the arrow icon shown on the `<select>` element that points down when it is closed.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::picker-icon#syntax)

----------------------------------------------------------------------------------------------------

[Description](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::picker-icon#description)

--------------------------------------------------------------------------------------------------------------

The `::picker-icon` pseudo-element targets the picker icon of form controls, that is, the icon shown on the control button. It is only available to target when the originating element has a picker and has base appearance set on it via the [`appearance`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/appearance)
 property `base-select` value. Its generated box appears after any boxes generated by the [`::after`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::after)
 pseudo-element, with the icon specified in default browser stylesheet; you can customize it using the [`content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/content)
 property.

The `::picker-icon` selector can be used to select the down-facing arrow on the inline-end side of a [customizable select element](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)
. This is useful for example if you want to customize the color or size of the icon, use a different icon (using [`content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/content)
 or [SVG](https://developer.mozilla.org/en-US/docs/Web/SVG)
), or animate it when the picker is opened and closed.

Selecting customizable `<select>` picker icons is the only current use case for `::picker-icon`, but more may be added in the future.

**Note:** The `::picker-icon` pseudo-element is not included in the accessibility tree, so any generated [`content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/content)
 set on it will not be announced by assistive technologies. You should still make sure that any new icon you set visually makes sense for its intended purpose.

[Examples](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::picker-icon#examples)

--------------------------------------------------------------------------------------------------------

### [Animating the picker icon](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::picker-icon#animating_the_picker_icon)

To opt-in to customizable select functionality, the `<select>` element and its picker both need to have an [`appearance`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/appearance)
 value of `base-select` set on them:

You could then, for example, target the `::picker-icon` and give it a custom [`color`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color)
 and a [`transition`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transition)
 so that changes to its [`rotate`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/rotate)
 property are smoothly animated:

In the next rule, `::picker-icon` is combined with the [`:open`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:open)
 pseudo-class — which targets the icon only when the picker is open — transitioning it to a `rotate` value of `180deg` when the `<select>` is opened.

See [Styling the picker icon](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select#styling_the_picker_icon)
 for a full example that uses this code, along with a live example rendering.

[Specifications](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::picker-icon#specifications)
