`-moz-float-edge` CSS property
==============================

Deprecated

Avoid using this feature in new projects. This feature may be a candidate for removal from web standards or browsers.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-float-edge#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The non-standard **`-moz-float-edge`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 property specifies whether the height and width properties of the element include the margin, border, or padding thickness.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-float-edge#syntax)

-------------------------------------------------------------------------------------------------------

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-float-edge#values)

This property is specified as one of the following keyword values:

[`content-box`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-float-edge#content-box)

The height and width properties include the content, but not the padding, border or margin.

[`margin-box`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-float-edge#margin-box)

The height and width properties include the content, padding, border and margin.

[Formal definition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-float-edge#formal_definition)
