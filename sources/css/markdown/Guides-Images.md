CSS images
==========

The **CSS images** module defines the types of images that can be used (the [`<image>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/image)
 type, containing URLs, gradients and other types of images), how to resize them and how they, and other replaced content, interact with the different layout models.

[Reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Images#reference)

--------------------------------------------------------------------------------------

### [Properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Images#properties)

*   [`image-orientation`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/image-orientation)
    
*   [`image-rendering`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/image-rendering)
    
*   [`object-fit`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/object-fit)
    
*   [`object-position`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/object-position)
    
*   [`object-view-box`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/object-view-box)
    

The CSS images module also defines the [`image-resolution`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/image-resolution)
 property. Currently, no browsers support this feature.

The CSS images module also defines the [`image()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/image/image)
 function. Currently, no browsers support this feature.
