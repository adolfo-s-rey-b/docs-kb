`::checkmark` CSS pseudo-element
================================

Limited availability

This feature is not Baseline because it does not work in some of the most widely-used browsers.

Want more browser support for this feature? [Tell us why.](https://github.com/web-platform-dx/developer-signals/issues/278)

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`::checkmark`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 [pseudo-element](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-elements)
 targets the checkmark placed inside the currently-selected [`<option>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/option)
 element of a [customizable select element](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)
. It can be used to provide a visual indication of which option is selected.

[Try it](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#try_it)

--------------------------------------------------------------------------------------------------

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#syntax)

--------------------------------------------------------------------------------------------------

[Description](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#description)

------------------------------------------------------------------------------------------------------------

The `::checkmark` pseudo-element targets the checkmark placed inside a [customizable select element's](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)
 currently-selected `<option>`.

It is only available to target when the originating element has a picker and has base appearance set on it via the [`appearance`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/appearance)
 property `base-select` value. Its generated box appears before any boxes generated by the [`::before`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::before)
 pseudo-element. The icon can be customized using the [`content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/content)
 property.

The `::checkmark` selector is useful for example if you want to hide the checkmark, use a custom icon, or adjust the checkmark's rendering position inside `<option>` elements.

**Note:** The `::checkmark` pseudo-element is not included in the accessibility tree, so any generated [`content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/content)
 set on it will not be announced by assistive technologies. You should still make sure that any new icon you set visually makes sense for its intended purpose.

[Examples](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#examples)

------------------------------------------------------------------------------------------------------

### [Customizing the checkmark](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#customizing_the_checkmark)

To opt-in to customizable select functionality, the `<select>` element and its picker both need to have an [`appearance`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/appearance)
 value of `base-select` set on them:

Assuming [flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Flexible_box_layout)
 is being used to lay out the `<option>` elements (which is true in **current implementations** of customizable selects), you could then move the checkmark from the start of the row to the end by setting an [`order`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/order)
 value on it greater than `0`, and aligning it to the end of the row using an `auto` [`margin-left`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/margin-left)
 value (see [Alignment and auto margins](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Box_alignment/In_flexbox#alignment_and_auto_margins)
).

The value of the [`content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/content)
 property could also be set to a different emoji to change the displayed icon.

See [Styling the current selection checkmark](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select#styling_the_current_selection_checkmark)
 for a full example that uses this code, along with a live example rendering.

[Specifications](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::checkmark#specifications)
