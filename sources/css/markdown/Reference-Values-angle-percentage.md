`<angle-percentage>` CSS type
=============================

Baseline

Widely available

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/angle-percentage#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`<angle-percentage>`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 [data type](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/Data_types)
 represents a value that can be either an [`<angle>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/angle)
 or a [`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage)
.

Where an `<angle-percentage>` is specified as an allowable type, this means that the percentage resolves to an angle and therefore can be used in a [`calc()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/calc)
 expression.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/angle-percentage#syntax)

Refer to the documentation for [`<angle>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/angle)

 for details of the individual syntaxes allowed by this type.

[Formal syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/angle-percentage#formal_syntax)
