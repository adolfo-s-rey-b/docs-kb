`-webkit-box-reflect` CSS property
==================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`-webkit-box-reflect`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 property lets you reflect the content of an element in one specific direction.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-box-reflect#syntax)

-----------------------------------------------------------------------------------------------------------

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-box-reflect#values)

This property is specified as a space-separated list of the following values:

[`above`_,_ `below`_,_ `right`_,_ `left`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-box-reflect#above)

Are keywords indicating in which direction the reflection is to happen.

[`<length>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length)

Indicates the size of the reflection.

[`<image>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/image)

Describes the mask to be applied to the reflection.

[Formal definition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-box-reflect#formal_definition)
