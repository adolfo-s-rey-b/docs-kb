`::-webkit-meter-suboptimum-value` CSS pseudo-element
=====================================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`::-webkit-meter-suboptimum-value`** [pseudo-element](https://developer.mozilla.org/en-US/docs/Glossary/Pseudo-element)
 styles the [`<meter>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meter)
 element when the value attribute falls outside of the low-high range and is not equivalent to the optimum value.

Yellow is the default color.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-webkit-meter-suboptimum-value#syntax)
