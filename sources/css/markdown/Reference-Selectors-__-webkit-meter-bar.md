`::-webkit-meter-bar` CSS pseudo-element
========================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`::-webkit-meter-bar`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 [pseudo-element](https://developer.mozilla.org/en-US/docs/Glossary/Pseudo-element)
 is a [WebKit extension](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Webkit_extensions)
 that represents the background of a [`<meter>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meter)
 element. It is used for selecting and applying styles to the container of a meter gauge.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-webkit-meter-bar#syntax)
