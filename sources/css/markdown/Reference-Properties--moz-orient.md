`-moz-orient` CSS property
==========================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`-moz-orient`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 property specifies the orientation of the element to which it's applied.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#syntax)

---------------------------------------------------------------------------------------------------

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#values)

This property is specified as one of the following keyword values:

[`inline`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#inline)

The element is rendered in the same direction as the axis of the text: horizontally for horizontal writing modes, vertically for vertical writing modes.

[`block`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#block)

The element is rendered orthogonally to the axis of the text: vertically for horizontal writing modes, horizontal for vertical writing modes.

[`horizontal`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#horizontal)

The element is rendered horizontally.

[`vertical`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#vertical)

The element is rendered vertically.

[Formal definition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-moz-orient#formal_definition)
