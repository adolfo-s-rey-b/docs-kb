`-webkit-mask-position-y` CSS property
======================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The `-webkit-mask-position-y` CSS property sets the initial vertical position of a mask image.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-mask-position-y#syntax)

---------------------------------------------------------------------------------------------------------------

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-mask-position-y#values)

This property is specified as one or more comma-separated values:

[`<length-percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-mask-position-y#length-percentage)

A length indicating the position of the top side of the image relative to the box's top padding edge. Percentages are calculated against the vertical dimension of the box padding area. A value of `0%` means the top edge of the image is aligned with the box's top padding edge and a value of `100%` means the bottom edge of the image is aligned with the box's bottom padding edge.

[`top`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-mask-position-y#top)

Equivalent to `0%`.

[`bottom`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-mask-position-y#bottom)

Equivalent to `100%`.

[`center`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/-webkit-mask-position-y#center)

Equivalent to `50%`.
