`::-moz-range-thumb` CSS pseudo-element
=======================================

**Non-standard:** This feature is not standardized. We do not recommend using non-standard features in production, as they have limited browser support, and may change or be removed. However, they can be a suitable alternative in specific cases where no standard option exists.

The **`::-moz-range-thumb`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 [pseudo-element](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-elements)
 is a [Mozilla extension](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Mozilla_extensions)
 that represents the _thumb_ (i.e., virtual knob) of an [`<input>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input)
 of `type="range"`. The user can move the thumb along the input's track to alter its numerical value.

**Note:** Using `::-moz-range-thumb` with anything but an `<input type="range">` doesn't match anything and has no effect.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-moz-range-thumb#syntax)

*   The pseudo-elements used by Gecko to style other parts of a range input:
    
    *   [`::-moz-range-track`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-moz-range-track)
         represents the groove in which the thumb slides.
    *   [`::-moz-range-progress`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::-moz-range-progress)
         represents the lower portion of the track.
