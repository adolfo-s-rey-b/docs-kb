`min-height` CSS property
=========================

Baseline

Widely available

\*

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

\* Some parts of this feature may have varying levels of support.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-height#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`min-height`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 property sets the minimum height of an element. It prevents the [used value](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Property_value_processing#used_value)
 of the [`height`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/height)
 property from becoming smaller than the value specified for `min-height`.

The element's height is set to the value of `min-height` whenever `min-height` is larger than [`max-height`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/max-height)
 or [`height`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/height)
.

[Try it](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-height#try_it)

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-height#values)

[`<length>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length)

Defines the `min-height` as an absolute value.

[`<percentage>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/percentage)

Defines the `min-height` as a percentage of the containing block's height.

[`auto`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-height#auto)

The browser will calculate and select a `min-height` for the specified element.

[`max-content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/max-content)

The intrinsic preferred `min-height`.

[`min-content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/min-content)

The intrinsic minimum `min-height`.

[`fit-content`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/fit-content)

Use the available space, but not more than [max-content](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/max-content)
, i.e., `min(max-content, max(min-content, stretch))`.

[`fit-content(<length-percentage>)`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/fit-content_function)

Uses the `fit-content` formula with the available space replaced by the specified argument, i.e., `min(max-content, max(min-content, argument))`.

[`stretch`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-height#stretch)

Limits the minimum height of the element's [margin box](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/Box_model#parts_of_a_box)
 to the height of its [containing block](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Display/Containing_block#identifying_the_containing_block)
. It attempts to make the margin box fill the available space in the containing block, so in a way behaving similar to `100%` but applying the resulting size to the margin box rather than the box determined by [box-sizing](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/box-sizing)
.

**Note:** To check aliases used by browsers for the `stretch` value and its implementation status, see the [Browser compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/min-height#browser_compatibility)
 section.
