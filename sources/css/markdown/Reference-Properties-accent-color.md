`accent-color` CSS property
===========================

Limited availability

This feature is not Baseline because it does not work in some of the most widely-used browsers.

Want more browser support for this feature? [Tell us why.](https://github.com/web-platform-dx/developer-signals/issues/146)

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`accent-color`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 property sets the [accent](https://developer.mozilla.org/en-US/docs/Glossary/Accent)
 color for user-interface controls generated by some elements.

[Try it](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#try_it)

----------------------------------------------------------------------------------------------------

    accent-color: red;
    

    accent-color: #74992e;
    

    accent-color: rgb(255 255 128);
    

    accent-color: hsl(250 100% 34%);
    

    <section class="default-example container" id="default-example">
      <div>
        <input checked id="example-element" type="checkbox" />
        <label for="example-element" id="example-label">Example Label</label>
      </div>
    </section>
    

    .container > div {
      display: flex;
      align-items: center;
    }
    
    #example-element {
      width: 40px;
      height: 40px;
    }
    
    #example-label {
      margin-left: 10px;
      font-size: x-large;
    }
    

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#syntax)

----------------------------------------------------------------------------------------------------

css

    /* Keyword value */
    accent-color: auto;
    
    /* <color> values */
    accent-color: darkred;
    accent-color: #5729e9;
    accent-color: rgb(0 200 0);
    accent-color: hsl(228 4% 24%);
    
    /* Global values */
    accent-color: inherit;
    accent-color: initial;
    accent-color: revert;
    accent-color: revert-layer;
    accent-color: unset;
    

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#values)

This property is specified as the keyword `auto` or one `<color>` value:

[`auto`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#auto)

Represents a UA-chosen color, which should match the accent color of the platform, if any.

[`<color>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value)

Specifies the color to be used as the accent color.

[Description](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#description)

--------------------------------------------------------------------------------------------------------------

Browsers that support `accent-color` currently apply it to the following HTML elements:

*   [`<input type="checkbox">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/checkbox)
    
*   [`<input type="radio">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/radio)
    
*   [`<input type="range">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/range)
    
*   [`<progress>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/progress)
    

Each user agent has an accent color, with variations to ensure legibility and contrast. That accent color is not used by every user-interface control nor in every state of the control. The `accent-color` is only applied to user-interface controls that use an accent color in the states where it is applicable.

**Note:** To reduce the risk of [fingerprinting](https://developer.mozilla.org/en-US/docs/Glossary/Fingerprinting)
, some browsers return a fixed value for `accent-color: auto` unless it is used in certain restricted circumstances. See [browser compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#browser_compatibility)
 for details.

### [Setting a custom accent color](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/accent-color#setting_a_custom_accent_color)

#### HTML

html

    <input type="checkbox" checked />
    <input type="checkbox" class="custom" checked />
    

#### CSS

css

    input {
      accent-color: auto;
      display: block;
      width: 30px;
      height: 30px;
    }
    
    input.custom {
      accent-color: rebeccapurple;
    }
