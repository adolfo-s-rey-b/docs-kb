`outline-width` CSS property
============================

Baseline

Widely available

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/outline-width#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 **`outline-width`** property sets the thickness of an element's outline. An outline is a line that is drawn around an element, outside the [`border`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/border)
.

It is often more convenient to use the shorthand property [`outline`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/outline)
 when defining the appearance of an outline.

[Try it](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/outline-width#try_it)

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/outline-width#values)

This property is specified as one `<line-width>` value.

[`<line-width>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/line-width)

Defines the width of the outline, either as an explicit non-negative [`<length>`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/length)
 or the keywords: `thin`, `medium`, or `thick`. The default is `medium`.

[Formal definition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/outline-width#formal_definition)
