`mask-border-mode` CSS property
===============================

The **`mask-border-mode`** [CSS](https://developer.mozilla.org/en-US/docs/Web/CSS)
 property specifies the blending mode used in a [mask border](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-border)
.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-border-mode#syntax)

--------------------------------------------------------------------------------------------------------

### [Values](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-border-mode#values)

This property is specified as one of the following keyword values:

[`luminance`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-border-mode#luminance)

The luminance values of the mask border image are used as the mask values.

[`alpha`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-border-mode#alpha)

The alpha values of the mask border image are used as the mask values.

[Formal definition](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/mask-border-mode#formal_definition)
