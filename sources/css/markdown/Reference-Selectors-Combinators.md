CSS combinators
===============

CSS **combinators** define relationships between [selectors](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors)
. They allow you to select elements based on their relationship to other elements in the document tree.

For example, to style only paragraph elements that are direct children of a [`<div>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/div)
, you can use the child combinator (`>`):

[Syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Combinators#syntax)
