Cell Objects[¶](https://docs.python.org/3/c-api/cell.html#cell-objects "Link to this heading")

===============================================================================================

“Cell” objects are used to implement variables referenced by multiple scopes. For each such variable, a cell object is created to store the value; the local variables of each stack frame that references the value contain a reference to the cells from outer scopes which also use that variable. When the value is accessed, the value contained in the cell is used instead of the cell object itself. This de-referencing of the cell object requires support from the generated byte-code; these are not automatically de-referenced when accessed. Cell objects are not likely to be useful elsewhere.

type PyCellObject[¶](https://docs.python.org/3/c-api/cell.html#c.PyCellObject "Link to this definition")
  

The C structure used for cell objects.

[PyTypeObject](https://docs.python.org/3/c-api/type.html#c.PyTypeObject "PyTypeObject")
 PyCell\_Type[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_Type "Link to this definition")
  

The type object corresponding to cell objects.

int PyCell\_Check([PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*ob)[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_Check "Link to this definition")
  

Return true if _ob_ is a cell object; _ob_ must not be `NULL`. This function always succeeds.

[PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*PyCell\_New([PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*ob)[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_New "Link to this definition")
  

_Return value: New reference._

Create and return a new cell object containing the value _ob_. The parameter may be `NULL`.

[PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*PyCell\_Get([PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*cell)[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_Get "Link to this definition")
  

_Return value: New reference._

Return the contents of the cell _cell_, which can be `NULL`. If _cell_ is not a cell object, returns `NULL` with an exception set.

[PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*PyCell\_GET([PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*cell)[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_GET "Link to this definition")
  

_Return value: Borrowed reference._

Return the contents of the cell _cell_, but without checking that _cell_ is non-`NULL` and a cell object.

int PyCell\_Set([PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*cell, [PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*value)[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_Set "Link to this definition")
  

Set the contents of the cell object _cell_ to _value_. This releases the reference to any current content of the cell. _value_ may be `NULL`. _cell_ must be non-`NULL`.

On success, return `0`. If _cell_ is not a cell object, set an exception and return `-1`.

void PyCell\_SET([PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*cell, [PyObject](https://docs.python.org/3/c-api/structures.html#c.PyObject "PyObject")
 \*value)[¶](https://docs.python.org/3/c-api/cell.html#c.PyCell_SET "Link to this definition")
  

Sets the value of the cell object _cell_ to _value_. No reference counts are adjusted, and no checks are made for safety; _cell_ must be non-`NULL` and must be a cell object.
