`pstats` — Statistics for profilers[¶](https://docs.python.org/3/library/pstats.html#module-pstats "Link to this heading")

===========================================================================================================================

**Source code:** [Lib/pstats.py](https://github.com/python/cpython/tree/3.15/Lib/pstats.py)

* * *

The `pstats` module provides tools for reading, manipulating, and displaying profiling statistics generated by Python’s profilers. It reads output from both [`profiling.tracing`](https://docs.python.org/3/library/profiling.tracing.html#module-profiling.tracing "profiling.tracing: Deterministic tracing profiler for Python programs.")
 (deterministic profiler) and [`profiling.sampling`](https://docs.python.org/3/library/profiling.sampling.html#module-profiling.sampling "profiling.sampling: Statistical sampling profiler for Python processes.")
 (statistical profiler).

Reading and displaying profile data[¶](https://docs.python.org/3/library/pstats.html#reading-and-displaying-profile-data "Link to this heading")

-------------------------------------------------------------------------------------------------------------------------------------------------

The [`Stats`](https://docs.python.org/3/library/pstats.html#pstats.Stats "pstats.Stats")
 class is the primary interface for working with profile data. It can read statistics from files or directly from a [`Profile`](https://docs.python.org/3/library/profiling.tracing.html#profiling.tracing.Profile "profiling.tracing.Profile")
 object.

Load statistics from a file and print a basic report:

Copy

import pstats

p \= pstats.Stats('profile\_output.prof')
p.print\_stats()

The [`Stats`](https://docs.python.org/3/library/pstats.html#pstats.Stats "pstats.Stats")
 object provides methods for sorting and filtering the data before printing. For example, to see the ten functions with the highest cumulative time:

Copy

from pstats import SortKey

p \= pstats.Stats('profile\_output.prof')
p.sort\_stats(SortKey.CUMULATIVE).print\_stats(10)

### Working with statistics[¶](https://docs.python.org/3/library/pstats.html#working-with-statistics "Link to this heading")

The [`Stats`](https://docs.python.org/3/library/pstats.html#pstats.Stats "pstats.Stats")
 class supports method chaining, making it convenient to perform multiple operations:

Copy

p \= pstats.Stats('restats')
p.strip\_dirs().sort\_stats(\-1).print\_stats()

The [`strip_dirs()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.strip_dirs "pstats.Stats.strip_dirs")
 method removes directory paths from filenames, making the output more compact. The [`sort_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.sort_stats "pstats.Stats.sort_stats")
 method accepts various keys to control the sort order.

Different sort keys highlight different aspects of performance:

Copy

from pstats import SortKey

\# Functions that consume the most cumulative time
p.sort\_stats(SortKey.CUMULATIVE).print\_stats(10)

\# Functions that consume the most time in their own code
p.sort\_stats(SortKey.TIME).print\_stats(10)

\# Functions sorted by name
p.sort\_stats(SortKey.NAME).print\_stats()

### Filtering output[¶](https://docs.python.org/3/library/pstats.html#filtering-output "Link to this heading")

The [`print_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_stats "pstats.Stats.print_stats")
 method accepts restrictions that filter which functions are displayed. Restrictions can be integers (limiting the count), floats between 0 and 1 (selecting a percentage), or strings (matching function names via regular expression).

Print only the top 10%:

Copy

p.print\_stats(.1)

Print only functions whose names contain “init”:

Copy

p.print\_stats('init')

Combine restrictions (they apply sequentially):

Copy

\# Top 10%, then only those containing "init"
p.print\_stats(.1, 'init')

\# Functions in files matching "foo:", limited to top 50%
p.sort\_stats(SortKey.FILENAME).print\_stats('foo:', .5)

### Analyzing call relationships[¶](https://docs.python.org/3/library/pstats.html#analyzing-call-relationships "Link to this heading")

The [`print_callers()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_callers "pstats.Stats.print_callers")
 method shows which functions called each displayed function:

Copy

p.print\_callers()

The [`print_callees()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_callees "pstats.Stats.print_callees")
 method shows the opposite relationship, listing which functions each displayed function called:

Copy

p.print\_callees()

Both methods accept the same restriction arguments as [`print_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_stats "pstats.Stats.print_stats")
.

### Combining multiple profiles[¶](https://docs.python.org/3/library/pstats.html#combining-multiple-profiles "Link to this heading")

Statistics from multiple profiling runs can be combined into a single [`Stats`](https://docs.python.org/3/library/pstats.html#pstats.Stats "pstats.Stats")
 object:

Copy

\# Load multiple files at once
p \= pstats.Stats('run1.prof', 'run2.prof', 'run3.prof')

\# Or add files incrementally
p \= pstats.Stats('run1.prof')
p.add('run2.prof')
p.add('run3.prof')

When files are combined, statistics for identical functions (same file, line, and name) are accumulated, giving an aggregate view across all profiling runs.

The `Stats` class[¶](https://docs.python.org/3/library/pstats.html#the-stats-class "Link to this heading")

-----------------------------------------------------------------------------------------------------------

class pstats.Stats(_\*filenames\_or\_profile_, _stream\=sys.stdout_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats "Link to this definition")

Create a statistics object from profile data.

The arguments can be filenames (strings or path-like objects) or [`Profile`](https://docs.python.org/3/library/profiling.tracing.html#profiling.tracing.Profile "profiling.tracing.Profile")
 objects. If multiple sources are provided, their statistics are combined.

The _stream_ argument specifies where output from [`print_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_stats "pstats.Stats.print_stats")
 and related methods is written. It defaults to [`sys.stdout`](https://docs.python.org/3/library/sys.html#sys.stdout "sys.stdout")
.

The profile data format is specific to the Python version that created it. There is no compatibility guarantee between Python versions or between different profilers.

strip\_dirs()[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.strip_dirs "Link to this definition")

Remove leading path information from all filenames.

This method modifies the object in place and returns it for method chaining. After stripping, the statistics are considered to be in random order.

If stripping causes two functions to become indistinguishable (same filename, line number, and function name), their statistics are combined into a single entry.

add(_\*filenames_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.add "Link to this definition")

Add profiling data from additional files.

The files must have been created by the same profiler type. Statistics for identical functions are accumulated.

dump\_stats(_filename_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.dump_stats "Link to this definition")

Save the current statistics to a file.

The file is created if it does not exist and overwritten if it does. The saved data can be loaded by creating a new `Stats` object.

sort\_stats(_\*keys_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.sort_stats "Link to this definition")

Sort the statistics according to the specified criteria.

Each key can be a string or a [`SortKey`](https://docs.python.org/3/library/pstats.html#pstats.SortKey "pstats.SortKey")
 enum member. When multiple keys are provided, later keys break ties in earlier keys.

Using [`SortKey`](https://docs.python.org/3/library/pstats.html#pstats.SortKey "pstats.SortKey")
 enum members is preferred over strings as it provides better error checking:

Copy

from pstats import SortKey
p.sort\_stats(SortKey.CUMULATIVE)

Valid sort keys:

| String | Enum | Meaning |
| --- | --- | --- |
| `'calls'` | `SortKey.CALLS` | call count |
| `'cumulative'` | `SortKey.CUMULATIVE` | cumulative time |
| `'cumtime'` | N/A | cumulative time |
| `'file'` | N/A | file name |
| `'filename'` | `SortKey.FILENAME` | file name |
| `'module'` | N/A | file name |
| `'ncalls'` | N/A | call count |
| `'pcalls'` | `SortKey.PCALLS` | primitive call count |
| `'line'` | `SortKey.LINE` | line number |
| `'name'` | `SortKey.NAME` | function name |
| `'nfl'` | `SortKey.NFL` | name/file/line |
| `'stdname'` | `SortKey.STDNAME` | standard name |
| `'time'` | `SortKey.TIME` | internal time |
| `'tottime'` | N/A | internal time |

All sorts on statistics are in descending order (most time consuming first), while name, file, and line number sorts are ascending (alphabetical).

The difference between `SortKey.NFL` and `SortKey.STDNAME` is that NFL sorts line numbers numerically while STDNAME sorts them as strings. `sort_stats(SortKey.NFL)` is equivalent to `sort_stats(SortKey.NAME, SortKey.FILENAME, SortKey.LINE)`.

For backward compatibility, the numeric arguments `-1`, `0`, `1`, and `2` are also accepted, meaning `'stdname'`, `'calls'`, `'time'`, and `'cumulative'` respectively.

Added in version 3.7: The [`SortKey`](https://docs.python.org/3/library/pstats.html#pstats.SortKey "pstats.SortKey")
 enum.

reverse\_order()[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.reverse_order "Link to this definition")

Reverse the current sort order.

By default, the sort direction is chosen appropriately for the sort key (descending for time-based keys, ascending for name-based keys). This method inverts that choice.

print\_stats(_\*restrictions_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_stats "Link to this definition")

Print a report of the profiling statistics.

The output includes a header line summarizing the data, followed by a table of function statistics sorted according to the last [`sort_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.sort_stats "pstats.Stats.sort_stats")
 call.

Restrictions filter the output. Each restriction is either:

*   An integer: limits output to that many entries
    
*   A float between 0.0 and 1.0: selects that fraction of entries
    
*   A string: matches function names via regular expression
    

Restrictions are applied sequentially. For example:

Copy

print\_stats(.1, 'foo:')

First limits to the top 10%, then filters to functions matching ‘foo:’.

print\_callers(_\*restrictions_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_callers "Link to this definition")

Print the callers of each function in the statistics.

For each function in the filtered results, shows which functions called it and how often.

With [`profiling.tracing`](https://docs.python.org/3/library/profiling.tracing.html#module-profiling.tracing "profiling.tracing: Deterministic tracing profiler for Python programs.")
 (or `cProfile`), each caller line shows three numbers: the number of calls from that caller, and the total and cumulative times for those specific calls.

Accepts the same restriction arguments as [`print_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_stats "pstats.Stats.print_stats")
.

print\_callees(_\*restrictions_)[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_callees "Link to this definition")

Print the functions called by each function in the statistics.

This is the inverse of [`print_callers()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_callers "pstats.Stats.print_callers")
, showing which functions each listed function called.

Accepts the same restriction arguments as [`print_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.print_stats "pstats.Stats.print_stats")
.

get\_stats\_profile()[¶](https://docs.python.org/3/library/pstats.html#pstats.Stats.get_stats_profile "Link to this definition")

Return a `StatsProfile` object containing the statistics.

The returned object provides programmatic access to the profile data, with function names mapped to `FunctionProfile` objects containing timing and call count information.

Added in version 3.9.

class pstats.SortKey[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey "Link to this definition")

An enumeration of valid sort keys for [`Stats.sort_stats()`](https://docs.python.org/3/library/pstats.html#pstats.Stats.sort_stats "pstats.Stats.sort_stats")
.

CALLS[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.CALLS "Link to this definition")

Sort by call count.

CUMULATIVE[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.CUMULATIVE "Link to this definition")

Sort by cumulative time.

FILENAME[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.FILENAME "Link to this definition")

Sort by file name.

LINE[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.LINE "Link to this definition")

Sort by line number.

NAME[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.NAME "Link to this definition")

Sort by function name.

NFL[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.NFL "Link to this definition")

Sort by name, then file, then line number (numeric line sort).

PCALLS[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.PCALLS "Link to this definition")

Sort by primitive (non-recursive) call count.

STDNAME[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.STDNAME "Link to this definition")

Sort by standard name (string-based line sort).

TIME[¶](https://docs.python.org/3/library/pstats.html#pstats.SortKey.TIME "Link to this definition")

Sort by internal time (time in function excluding subcalls).

Command-line interface[¶](https://docs.python.org/3/library/pstats.html#command-line-interface "Link to this heading")

-----------------------------------------------------------------------------------------------------------------------

The `pstats` module can be invoked as a script to interactively browse profile data:

Copy

python \-m pstats profile\_output.prof

This opens a line-oriented interface (built on [`cmd`](https://docs.python.org/3/library/cmd.html#module-cmd "cmd: Build line-oriented command interpreters.")
) for examining the statistics. Type `help` at the prompt for available commands.

Deterministic tracing profiler.
