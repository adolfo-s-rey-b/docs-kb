Empty guide
===========

Source: [`R/guide-none.R`](https://github.com/tidyverse/ggplot2/blob/v4.0.3/R/guide-none.R)

`guide_none.Rd`

This guide draws nothing.

Usage[](https://ggplot2.tidyverse.org/reference/guide_none.html#ref-usage)

---------------------------------------------------------------------------

    guide_none(title = waiver(), position = waiver())

Arguments[](https://ggplot2.tidyverse.org/reference/guide_none.html#arguments)

-------------------------------------------------------------------------------

title[](https://ggplot2.tidyverse.org/reference/guide_none.html#arg-title)

A character string or expression indicating a title of guide. If `NULL`, the title is not shown. By default (`[waiver()](https://ggplot2.tidyverse.org/reference/waiver.html) `), the name of the scale object or the name specified in `[labs()](https://ggplot2.tidyverse.org/reference/labs.html) ` is used for the title.

position[](https://ggplot2.tidyverse.org/reference/guide_none.html#arg-position)

Where this guide should be drawn: one of top, bottom, left, or right.
