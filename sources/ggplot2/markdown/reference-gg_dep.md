Give a deprecation error, warning, or message, depending on version number.
===========================================================================

Source: [`R/utilities.R`](https://github.com/tidyverse/ggplot2/blob/v4.0.3/R/utilities.R)

`gg_dep.Rd`

[![[Deprecated]](https://ggplot2.tidyverse.org/reference/figures/lifecycle-deprecated.svg)](https://lifecycle.r-lib.org/articles/stages.html#deprecated)

Usage[](https://ggplot2.tidyverse.org/reference/gg_dep.html#ref-usage)

-----------------------------------------------------------------------

    gg_dep(version, msg)

Arguments[](https://ggplot2.tidyverse.org/reference/gg_dep.html#arguments)

---------------------------------------------------------------------------

version[](https://ggplot2.tidyverse.org/reference/gg_dep.html#arg-version)

The last version of ggplot2 where this function was good (in other words, the last version where it was not deprecated).

msg[](https://ggplot2.tidyverse.org/reference/gg_dep.html#arg-msg)

The message to print.
