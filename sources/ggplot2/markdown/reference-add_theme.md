`add_theme.Rd`

Modify properties of an element in a theme object

Usage[](https://ggplot2.tidyverse.org/reference/add_theme.html#ref-usage)

--------------------------------------------------------------------------

    add_theme(t1, t2, t2name, call = caller_env())

Arguments[](https://ggplot2.tidyverse.org/reference/add_theme.html#arguments)

------------------------------------------------------------------------------

t1[](https://ggplot2.tidyverse.org/reference/add_theme.html#arg-t-)

A theme object

t2[](https://ggplot2.tidyverse.org/reference/add_theme.html#arg-t-)

A theme object that is to be added to `t1`

t2name[](https://ggplot2.tidyverse.org/reference/add_theme.html#arg-t-name)

A name of the t2 object. This is used for printing informative error messages.
