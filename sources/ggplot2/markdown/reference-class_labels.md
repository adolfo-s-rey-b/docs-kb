The labels class
================

Source: [`R/all-classes.R`](https://github.com/tidyverse/ggplot2/blob/v4.0.3/R/all-classes.R)

`class_labels.Rd`

The labels class holds a list with label information to display as titles of plot components. The preferred way to construct an object of the labels class is to use the `[labs()](https://ggplot2.tidyverse.org/reference/labs.html) ` function.

Usage[](https://ggplot2.tidyverse.org/reference/class_labels.html#ref-usage)

-----------------------------------------------------------------------------

    class_labels(labels = list(), ...)

Arguments[](https://ggplot2.tidyverse.org/reference/class_labels.html#arguments)

---------------------------------------------------------------------------------

labels[](https://ggplot2.tidyverse.org/reference/class_labels.html#arg-labels)

A named list.

...[](https://ggplot2.tidyverse.org/reference/class_labels.html#arg--)

Reserved for future expansion.

Details[](https://ggplot2.tidyverse.org/reference/class_labels.html#details)

-----------------------------------------------------------------------------

All members of `labels` are expected to be named and names should be unique.
