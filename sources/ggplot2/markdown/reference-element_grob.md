Generate grid grob from theme element
=====================================

Source: [`R/theme-elements.R`](https://github.com/tidyverse/ggplot2/blob/v4.0.3/R/theme-elements.R)

`element_grob.Rd`

The `element_grob()` function is vestigial and `draw_element()` should be used instead.

Usage[](https://ggplot2.tidyverse.org/reference/element_grob.html#ref-usage)

-----------------------------------------------------------------------------

    element_grob(element, ...)

Arguments[](https://ggplot2.tidyverse.org/reference/element_grob.html#arguments)

---------------------------------------------------------------------------------

element[](https://ggplot2.tidyverse.org/reference/element_grob.html#arg-element)

Theme element, i.e. `element_rect` or similar.

...[](https://ggplot2.tidyverse.org/reference/element_grob.html#arg--)

Other arguments to control specific of rendering. This is usually at least position. See the source code for individual methods.
