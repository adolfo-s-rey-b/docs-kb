Build a plot with all the usual bits and pieces.
================================================

Source: [`R/plot-build.R`](https://github.com/tidyverse/ggplot2/blob/v4.0.3/R/plot-build.R)

`ggplot_gtable.Rd`

This function builds all grobs necessary for displaying the plot, and stores them in a special data structure called a `[gtable](https://gtable.r-lib.org/reference/gtable.html) `. This object is amenable to programmatic manipulation, should you want to (e.g.) make the legend box 2 cm wide, or combine multiple plots into a single display, preserving aspect ratios across the plots.

Usage[](https://ggplot2.tidyverse.org/reference/ggplot_gtable.html#ref-usage)
