Class definitions
=================

Source: [`R/all-classes.R`](https://github.com/tidyverse/ggplot2/blob/v4.0.3/R/all-classes.R)

`class_definitions.Rd`

The S7 object oriented programming system requires class definitions. Here, we provide definitions of classes that are home to ggplot2.

S7 classes[](https://ggplot2.tidyverse.org/reference/class_definitions.html#s-classes)

---------------------------------------------------------------------------------------

A general advice the S7 package gives is to name class definition objects the same as the class name, which then becomes the constructor for the class. The classes listed below deviate from that advice for historical reasons, because some constructors like `[ggplot()](https://ggplot2.tidyverse.org/reference/ggplot.html) ` are also S3 generics with methods. The have the `class_`\-prefix to indicate their role.

*   `[class_ggplot](https://ggplot2.tidyverse.org/reference/class_ggplot.html) ` is an S7 class used for objects generated by `[ggplot()](https://ggplot2.tidyverse.org/reference/ggplot.html) `.
    
*   `[class_ggplot_built](https://ggplot2.tidyverse.org/reference/class_ggplot_built.html) ` is an S7 class used for objects generated by `[ggplot_build()](https://ggplot2.tidyverse.org/reference/ggplot_build.html) `.
    
*   `[class_mapping](https://ggplot2.tidyverse.org/reference/class_mapping.html) ` is an S7 class used for objects generated by `[aes()](https://ggplot2.tidyverse.org/reference/aes.html) `.
    
*   `[class_theme](https://ggplot2.tidyverse.org/reference/class_theme.html) ` is an S7 class used for objects generated by `[theme()](https://ggplot2.tidyverse.org/reference/theme.html) `.
    
*   `[class_labels](https://ggplot2.tidyverse.org/reference/class_labels.html) ` is an S7 class used for objects generated by `[labs()](https://ggplot2.tidyverse.org/reference/labs.html) `.
    

*   `class_gg` is an abstract S7 class to used invoke similar behaviour among ggplot objects.
    

Theme elements[](https://ggplot2.tidyverse.org/reference/class_definitions.html#theme-elements)

------------------------------------------------------------------------------------------------

The theme elements follow the advice of the S7 package that the class names are also the class definitions and constructors.

*   `[element](https://ggplot2.tidyverse.org/reference/element.html) ` is an abstract S7 class used to invoke similar behaviour among theme element objects.
    
*   `[element_blank](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for not drawing theme elements.
    
*   `[element_rect](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for drawing rectangles.
    
*   `[element_line](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for drawing lines.
    
*   `[element_text](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for rendering text.
    
*   `[element_polygon](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for drawing polygons.
    
*   `[element_point](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for drawing points.
    
*   `[element_geom](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class holding geom defaults.
    
*   `[margin](https://ggplot2.tidyverse.org/reference/element.html) ` is an S7 class for declaring margins.
    

ggproto classes[](https://ggplot2.tidyverse.org/reference/class_definitions.html#ggproto-classes)

--------------------------------------------------------------------------------------------------

The ggproto classes are S3 classes of the type environment that form the backbone of most systems in ggplot2 and are in particular crucial to the extension system.

*   `class_ggproto` is an S3 class used for the objects generated by `[ggproto()](https://ggplot2.tidyverse.org/reference/ggproto.html) ` which are of the type environment.
    

*   `class_scale` is a subclass of `class_ggproto` and is more described in the [Scale](https://ggplot2.tidyverse.org/reference/Scale.html)
     documentation.
    

*   `class_guides` is a subclass of `class_ggproto` and is considered an internal class.
    

*   `class_guide` is a subclass of `class_ggproto` and is more described in the [Guide](https://ggplot2.tidyverse.org/reference/Guide.html)
     documentation.
    

*   `class_coord` is a subclass of `class_ggproto` and is more described in the [Coord](https://ggplot2.tidyverse.org/reference/Coord.html)
     documentation.
    

*   `class_facet` is a subclass of `class_ggproto` and is more described in the [Facet](https://ggplot2.tidyverse.org/reference/Facet.html)
     documentation.
    

*   `class_layer` is a subclass of `class_ggproto` and is used for the objects generated by `[layer()](https://ggplot2.tidyverse.org/reference/layer.html) `. The class itself is considered internal and is described in more detail in the [Layer](https://ggplot2.tidyverse.org/reference/Layer-class.html)
     documentation.
    

*   `class_layout` is a subclass of `class_ggproto` and is considered an internal class. It is described in more detail in the [Layout](https://ggplot2.tidyverse.org/reference/Layout.html)
     documentation.
    

*   `class_scales_list` is a subclass of `class_ggproto` and is considered an internal class.
    

S3 classes[](https://ggplot2.tidyverse.org/reference/class_definitions.html#s-classes-1)

-----------------------------------------------------------------------------------------

Some simple classes remain S3, primarily because they aren't meant to be recycled into new classes.

*   [![[Superseded]](https://ggplot2.tidyverse.org/reference/figures/lifecycle-superseded.svg)](https://lifecycle.r-lib.org/articles/stages.html#superseded)
     `class_S3_gg` is a temporary S3 class until R 4.3.0 is the minimum supported version. It is exported and listed here for completeness, but its use is heavily discouraged. It is superseded by `class_gg`.
    

*   `class_rel` is an S3 class used in [element](https://ggplot2.tidyverse.org/reference/element.html)
     properties.
    

*   `class_zero_grob` is an S3 class used to indicate empty drawings.
    

*   `class_waiver` is an S3 sentinel value class used in various places.
    

*   `class_derive` is an S3 sentinel value class used primarily in `[sec_axis()](https://ggplot2.tidyverse.org/reference/sec_axis.html) `.
