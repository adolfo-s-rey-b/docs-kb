matplotlib.colors.to\_hex(_c_, _keep\_alpha\=False_)[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/colors.py#L563-L582)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.colors.to_hex.html#matplotlib.colors.to_hex "Link to this definition")

Convert _c_ to a hex color.

Parameters:

**c**[color](https://matplotlib.org/stable/users/explain/colors/colors.html#colors-def)
 or [`numpy.ma.masked`](https://numpy.org/doc/stable/reference/maskedarray.baseclass.html#numpy.ma.masked "(in NumPy v2.5)")

**keep\_alpha**bool, default: False

If False, use the `#rrggbb` format, otherwise use `#rrggbbaa`.

Returns:

str

`#rrggbb` or `#rrggbbaa` hex color string
