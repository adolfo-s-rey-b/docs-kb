[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.box.html#matplotlib.pyplot.box "Link to this definition")

Turn the Axes box on or off on the current Axes.

Parameters:

**on**bool or None

The new [`Axes`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.html#matplotlib.axes.Axes "matplotlib.axes.Axes")
 box state. If `None`, toggle the state.
