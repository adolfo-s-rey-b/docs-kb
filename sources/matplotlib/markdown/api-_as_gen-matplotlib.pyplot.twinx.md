matplotlib.pyplot.twinx(_ax\=None_)[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/pyplot.py#L2126-L2139)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.twinx.html#matplotlib.pyplot.twinx "Link to this definition")

Make and return a second Axes that shares the _x_\-axis. The new Axes will overlay _ax_ (or the current Axes if _ax_ is _None_), and its ticks will be on the right.
