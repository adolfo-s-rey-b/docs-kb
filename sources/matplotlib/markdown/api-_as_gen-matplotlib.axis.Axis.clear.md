Axis.clear()[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/axis.py#L891-L932)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.axis.Axis.clear.html#matplotlib.axis.Axis.clear "Link to this definition")

Clear the axis.

This resets axis properties to their default values:

*   the label
    
*   the scale
    
*   locators, formatters and ticks
    
*   major and minor grid
    
*   units
    
*   registered callbacks
