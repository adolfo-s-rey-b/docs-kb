Draw a stacked area plot or a streamgraph.

See [`stackplot`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.stackplot.html#matplotlib.axes.Axes.stackplot "matplotlib.axes.Axes.stackplot")

import numpy as np

plt.style.use('\_mpl-gallery')
