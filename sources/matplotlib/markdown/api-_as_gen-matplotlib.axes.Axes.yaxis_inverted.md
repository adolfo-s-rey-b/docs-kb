\[_Discouraged_\] Return whether the yaxis is oriented in the "inverse" direction.

The "normal" direction is increasing to the right for the x-axis and to the top for the y-axis; the "inverse" direction is increasing to the left for the x-axis and to the bottom for the y-axis.

Discouraged

The use of this method is discouraged. Use [`Axes.get_yinverted`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.get_yinverted.html#matplotlib.axes.Axes.get_yinverted "matplotlib.axes.Axes.get_yinverted")
