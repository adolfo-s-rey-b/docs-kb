Plotting with keywords[#](https://matplotlib.org/stable/gallery/misc/keyword_plotting.html#plotting-with-keywords "Link to this heading")

==========================================================================================================================================

Some data structures, like dict, [structured numpy array](https://numpy.org/doc/stable/user/basics.rec.html#structured-arrays)
 or [`pandas.DataFrame`](https://pandas.pydata.org/docs/reference/api/pandas.DataFrame.html#pandas.DataFrame "(in pandas v3.0.5)")
 provide access to labelled data via string index access `data[key]`.

For these data types, Matplotlib supports passing the whole datastructure via the `data` keyword argument, and using the string names as plot function parameters, where you'd normally pass in your data.

![keyword plotting](https://matplotlib.org/stable/_images/sphx_glr_keyword_plotting_001_2_00x.png)
