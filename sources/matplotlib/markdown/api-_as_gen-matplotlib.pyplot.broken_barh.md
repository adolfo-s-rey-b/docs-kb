[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.broken_barh.html#matplotlib.pyplot.broken_barh "Link to this definition")

Plot a horizontal sequence of rectangles.

A rectangle is drawn for each element of _xranges_. All rectangles have the same vertical position and size defined by _yrange_.

Parameters:

**xranges**sequence of tuples (_xmin_, _xwidth_)

The x-positions and extents of the rectangles. For each tuple (_xmin_, _xwidth_) a rectangle is drawn from _xmin_ to _xmin_ + _xwidth_.

**yrange**(_ypos_, _yheight_)

The y-position and extent for all the rectangles.

**align**{"bottom", "center", "top"}, default: 'bottom'

The alignment of the yrange with respect to the y-position. One of:

*   "bottom": Resulting y-range \[ypos, ypos + yheight\]
    
*   "center": Resulting y-range \[ypos - yheight/2, ypos + yheight/2\]
    
*   "top": Resulting y-range \[ypos - yheight, ypos\]
    

Added in version 3.11.

Returns:

[`PolyCollection`](https://matplotlib.org/stable/api/collections_api.html#matplotlib.collections.PolyCollection "matplotlib.collections.PolyCollection")

Other Parameters:

**data**indexable object, optional

If given, all parameters also accept a string `s`, which is interpreted as `data[s]` if `s` is a key in `data`.

**\*\*kwargs**[`PolyCollection`](https://matplotlib.org/stable/api/collections_api.html#matplotlib.collections.PolyCollection "matplotlib.collections.PolyCollection")
 properties

Each _kwarg_ can be either a single argument applying to all rectangles, e.g.:

facecolors\='black'

or a sequence of arguments over which is cycled, e.g.:

facecolors\=('black', 'blue')

would create interleaving black and blue rectangles.
