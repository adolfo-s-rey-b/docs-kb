Plot types[#](https://matplotlib.org/stable/plot_types/index.html#plot-types "Link to this heading")

=====================================================================================================

Overview of many common plotting commands provided by Matplotlib.

See the [gallery](https://matplotlib.org/stable/gallery/index.html)
 for more examples and the [tutorials page](https://matplotlib.org/stable/tutorials/index.html)
 for longer examples.
