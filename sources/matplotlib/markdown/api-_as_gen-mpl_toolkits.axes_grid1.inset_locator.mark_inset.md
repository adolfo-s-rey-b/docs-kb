Draw a box to mark the location of an area represented by an inset axes.

This function draws a box in _parent\_axes_ at the bounding box of _inset\_axes_, and shows a connection with the inset axes by drawing lines at the corners, giving a "zoomed in" effect.

Parameters:

**parent\_axes**[`Axes`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.html#matplotlib.axes.Axes "matplotlib.axes.Axes")

Axes which contains the area of the inset axes.

**inset\_axes**[`Axes`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.html#matplotlib.axes.Axes "matplotlib.axes.Axes")

The inset axes.

**loc1, loc2**{1, 2, 3, 4}

Corners to use for connecting the inset axes and the area in the parent axes.
