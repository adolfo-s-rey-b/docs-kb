Return the position of the Axes within the figure as a [`Bbox`](https://matplotlib.org/stable/api/transformations.html#matplotlib.transforms.Bbox "matplotlib.transforms.Bbox")
.

Parameters:

**original**bool

If `True`, return the original position. Otherwise, return the active position. For an explanation of the positions see [`set_position`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_position.html#matplotlib.axes.Axes.set_position "matplotlib.axes.Axes.set_position")
