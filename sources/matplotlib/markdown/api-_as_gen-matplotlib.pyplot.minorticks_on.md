matplotlib.pyplot.minorticks\_on()[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/pyplot.py#L3873-L3875)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.minorticks_on.html#matplotlib.pyplot.minorticks_on "Link to this definition")

Display minor ticks on the Axes.

Displaying minor ticks may reduce performance; you may turn them off using [`minorticks_off()`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.minorticks_off.html#matplotlib.pyplot.minorticks_off "matplotlib.pyplot.minorticks_off")
 if drawing speed is a problem.

Notes

Note

This is the [pyplot wrapper](https://matplotlib.org/stable/users/explain/figure/api_interfaces.html#pyplot-interface)
 for [`axes.Axes.minorticks_on`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.minorticks_on.html#matplotlib.axes.Axes.minorticks_on "matplotlib.axes.Axes.minorticks_on")
