Do not hide all visual components of the x- and y-axis.

This reverts the effect of a prior [`set_axis_off()`](https://matplotlib.org/stable/api/_as_gen/mpl_toolkits.mplot3d.axes3d.Axes3D.set_axis_off.html#mpl_toolkits.mplot3d.axes3d.Axes3D.set_axis_off "mpl_toolkits.mplot3d.axes3d.Axes3D.set_axis_off")
 call. Whether the individual axis decorations are drawn is controlled by their respective visibility settings.

This is on by default.
