The difference between \\dfrac and \\frac[#](https://matplotlib.org/stable/gallery/text_labels_and_annotations/dfrac_demo.html#the-difference-between-dfrac-and-frac "Link to this heading")

=============================================================================================================================================================================================

In this example, the differences between the \\dfrac and \\frac TeX macros are illustrated; in particular, the difference between display style and text style fractions when using Mathtext.

Added in version 2.1.

Note

To use \\dfrac with the LaTeX engine (text.usetex : True), you need to import the amsmath package with `[rcParams["text.latex.preamble"]](https://matplotlib.org/stable/users/explain/configuration.html?highlight=text.latex.preamble#rcparam-text-latex-preamble) ` (default: `''`), which is an unsupported feature; therefore, it is probably a better idea to just use the \\displaystyle option before the \\frac macro to get this behavior with the LaTeX engine.

![dfrac demo](https://matplotlib.org/stable/_images/sphx_glr_dfrac_demo_001_2_00x.png)

import matplotlib.pyplot as plt

[fig](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.html#matplotlib.figure.Figure "matplotlib.figure.Figure")
 \= [plt.figure](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.figure.html#matplotlib.pyplot.figure "matplotlib.pyplot.figure")
(figsize\=(5.25, 0.75))
[fig.text](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.text.html#matplotlib.figure.Figure.text "matplotlib.figure.Figure.text")
(0.5, 0.3, r'\\dfrac: $\\dfrac{a}{b}$',
         horizontalalignment\='center', verticalalignment\='center')
[fig.text](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.text.html#matplotlib.figure.Figure.text "matplotlib.figure.Figure.text")
(0.5, 0.7, r'\\frac: $\\frac{a}{b}$',
         horizontalalignment\='center', verticalalignment\='center')
[plt.show](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.show.html#matplotlib.pyplot.show "matplotlib.pyplot.show")
()
