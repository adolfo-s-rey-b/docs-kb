=======================================================================================================================

The [`matplotlib.ticker`](https://matplotlib.org/stable/api/ticker_api.html#module-matplotlib.ticker "matplotlib.ticker")
 module defines many preset tickers, but was primarily designed for extensibility, i.e., to support user customized ticking.

In this example, a user defined function is used to format the ticks in millions of dollars on the y-axis.

import matplotlib.pyplot as plt

def millions(x, pos):
    """The two arguments are the value and tick position."""
    return f'${x\*1e-6:1.1f}M'
