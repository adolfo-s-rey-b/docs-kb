Convenience method for simple axis view autoscaling.

See [`Axes.autoscale`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.autoscale.html#matplotlib.axes.Axes.autoscale "matplotlib.axes.Axes.autoscale")
 for full documentation. Because this function applies to 3D Axes, _axis_ can also be set to 'z', and setting _axis_ to 'both' autoscales all three axes.
