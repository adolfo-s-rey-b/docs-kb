\# Make data

([xs](https://numpy.org/doc/stable/reference/generated/numpy.ndarray.html#numpy.ndarray "numpy.ndarray")
 \* 6 \* [np.pi](https://docs.python.org/3/library/functions.html#float "builtins.float")
)
