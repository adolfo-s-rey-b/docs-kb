matplotlib.pyplot.sci(_im_)[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/pyplot.py#L4564-L4566)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.sci.html#matplotlib.pyplot.sci "Link to this definition")

Set the current image.

This image will be the target of colormap functions like `pyplot.viridis`, and other functions such as [`clim`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.clim.html#matplotlib.pyplot.clim "matplotlib.pyplot.clim")
. The current image is an attribute of the current Axes.
