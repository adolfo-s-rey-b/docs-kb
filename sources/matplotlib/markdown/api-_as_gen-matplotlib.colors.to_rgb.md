[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.colors.to_rgb.html#matplotlib.colors.to_rgb "Link to this definition")

Convert the [color](https://matplotlib.org/stable/users/explain/colors/colors.html#colors-def)
 _c_ to an RGB color tuple.

If c has an alpha channel value specified, that is silently dropped.
