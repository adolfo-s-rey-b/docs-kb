[Improved collections](https://matplotlib.org/stable/release/prev_whats_new/whats_new_1.2.2.html#id2)
[#](https://matplotlib.org/stable/release/prev_whats_new/whats_new_1.2.2.html#improved-collections "Link to this heading")

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

The individual items of a collection may now have different alpha values and be rendered correctly. This also fixes a bug where collections were always filled in the PDF backend.

[Multiple images on same axes are correctly transparent](https://matplotlib.org/stable/release/prev_whats_new/whats_new_1.2.2.html#id3)
[#](https://matplotlib.org/stable/release/prev_whats_new/whats_new_1.2.2.html#multiple-images-on-same-axes-are-correctly-transparent "Link to this heading")

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

When putting multiple images onto the same axes, the background color of the axes will now show through correctly.
