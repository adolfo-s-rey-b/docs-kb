Using ttf font files[#](https://matplotlib.org/stable/gallery/text_labels_and_annotations/font_file.html#using-ttf-font-files "Link to this heading")

======================================================================================================================================================

Although it is usually not a good idea to explicitly point to a single ttf file for a font instance, you can do so by passing a [`pathlib.Path`](https://docs.python.org/3/library/pathlib.html#pathlib.Path "(in Python v3.14)")
 instance as the _font_ parameter. Note that passing paths as [`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")
s is intentionally not supported, but you can simply wrap [`str`](https://docs.python.org/3/library/stdtypes.html#str "(in Python v3.14)")
s in [`pathlib.Path`](https://docs.python.org/3/library/pathlib.html#pathlib.Path "(in Python v3.14)")
s as needed.

Here, we use the Computer Modern roman font (`cmr10`) shipped with Matplotlib.

For a more flexible solution, see [Configure the font family](https://matplotlib.org/stable/gallery/text_labels_and_annotations/font_family_rc.html)
 and [Fonts demo (object-oriented style)](https://matplotlib.org/stable/gallery/text_labels_and_annotations/fonts_demo.html)
.

from pathlib import [Path](https://docs.python.org/3/library/pathlib.html#pathlib.Path "pathlib.Path")

import matplotlib.pyplot as plt

import matplotlib as mpl

[fig](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.html#matplotlib.figure.Figure "matplotlib.figure.Figure")
, [ax](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.html#matplotlib.axes.Axes "matplotlib.axes.Axes")
 \= [plt.subplots](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.subplots.html#matplotlib.pyplot.subplots "matplotlib.pyplot.subplots")
()

[fpath](https://docs.python.org/3/library/pathlib.html#pathlib.PosixPath "pathlib.PosixPath")
 \= [Path](https://docs.python.org/3/library/pathlib.html#pathlib.Path "pathlib.Path")
([mpl.get\_data\_path](https://matplotlib.org/stable/api/matplotlib_configuration_api.html#matplotlib.get_data_path "matplotlib.get_data_path")
(), "fonts/ttf/cmr10.ttf")
[ax.set\_title](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_title.html#matplotlib.axes.Axes.set_title "matplotlib.axes.Axes.set_title")
(f'This is a special font: {[fpath.name](https://docs.python.org/3/library/pathlib.html#pathlib.PurePath.name "pathlib.PurePath.name")
}', font\=[fpath](https://docs.python.org/3/library/pathlib.html#pathlib.PosixPath "pathlib.PosixPath")
)
[ax.set\_xlabel](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_xlabel.html#matplotlib.axes.Axes.set_xlabel "matplotlib.axes.Axes.set_xlabel")
('This is the default font')

[plt.show](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.show.html#matplotlib.pyplot.show "matplotlib.pyplot.show")
()
