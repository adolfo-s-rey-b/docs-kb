Display minor ticks on the Axes.

Displaying minor ticks may reduce performance; you may turn them off using [`minorticks_off()`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.minorticks_off.html#matplotlib.axes.Axes.minorticks_off "matplotlib.axes.Axes.minorticks_off")
