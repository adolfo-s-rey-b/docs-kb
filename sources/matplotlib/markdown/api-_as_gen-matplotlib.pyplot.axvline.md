matplotlib.pyplot.axvline[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.axvline.html#matplotlib-pyplot-axvline "Link to this heading")

========================================================================================================================================================

matplotlib.pyplot.axvline(_x\=0_, _ymin\=0_, _ymax\=1_, _\*\*kwargs_)[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/pyplot.py#L3113-L3115)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.axvline.html#matplotlib.pyplot.axvline "Link to this definition")

Add a vertical line spanning the whole or fraction of the Axes.

Note: If you want to set y-limits in data coordinates, use [`vlines`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.vlines.html#matplotlib.axes.Axes.vlines "matplotlib.axes.Axes.vlines")
 instead.

Parameters:

**x**float, default: 0

x position in [data coordinates](https://matplotlib.org/stable/users/explain/artists/transforms_tutorial.html#coordinate-systems)
.

**ymin**float, default: 0

The start y-position in [axes coordinates](https://matplotlib.org/stable/users/explain/artists/transforms_tutorial.html#coordinate-systems)
. Should be between 0 and 1, 0 being the bottom of the plot, 1 the top of the plot.

**ymax**float, default: 1

The end y-position in [axes coordinates](https://matplotlib.org/stable/users/explain/artists/transforms_tutorial.html#coordinate-systems)
. Should be between 0 and 1, 0 being the bottom of the plot, 1 the top of the plot.

Returns:

[`Line2D`](https://matplotlib.org/stable/api/_as_gen/matplotlib.lines.Line2D.html#matplotlib.lines.Line2D "matplotlib.lines.Line2D")

A [`Line2D`](https://matplotlib.org/stable/api/_as_gen/matplotlib.lines.Line2D.html#matplotlib.lines.Line2D "matplotlib.lines.Line2D")
 specified via two points `(x, ymin)`, `(x, ymax)`. Its transform is set such that _x_ is in [data coordinates](https://matplotlib.org/stable/users/explain/artists/transforms_tutorial.html#coordinate-systems)
 and _y_ is in [axes coordinates](https://matplotlib.org/stable/users/explain/artists/transforms_tutorial.html#coordinate-systems)
.

This is still a generic line and the vertical character is only realized through using identical _x_ values for both points. Thus, if you want to change the _x_ value later, you have to provide two values `line.set_xdata([3, 3])`.

Notes

Note

This is the [pyplot wrapper](https://matplotlib.org/stable/users/explain/figure/api_interfaces.html#pyplot-interface)
 for [`axes.Axes.axvline`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.axvline.html#matplotlib.axes.Axes.axvline "matplotlib.axes.Axes.axvline")
.

Examples

*   draw a thick red vline at _x_ = 0 that spans the yrange:
    
    \>>> axvline(linewidth\=4, color\='r')
    
*   draw a default vline at _x_ = 1 that spans the yrange:
    
    \>>> axvline(x\=1)
    
*   draw a default vline at _x_ = .5 that spans the middle half of the yrange:
    
    \>>> axvline(x\=.5, ymin\=0.25, ymax\=0.75)
