Unicode minus[#](https://matplotlib.org/stable/gallery/text_labels_and_annotations/unicode_minus.html#unicode-minus "Link to this heading")

============================================================================================================================================

By default, tick labels at negative values are rendered using a [Unicode minus](https://en.wikipedia.org/wiki/Plus_and_minus_signs#Character_codes)
 (U+2212) rather than an ASCII hyphen (U+002D). This can be controlled by setting `[rcParams["axes.unicode_minus"]](https://matplotlib.org/stable/users/explain/configuration.html?highlight=axes.unicode_minus#rcparam-axes-unicode-minus) ` (default: `True`).

The replacement is performed at draw time of the tick labels (usually during a [`pyplot.show()`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.show.html#matplotlib.pyplot.show "matplotlib.pyplot.show")
 or [`pyplot.savefig()`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html#matplotlib.pyplot.savefig "matplotlib.pyplot.savefig")
 call). Therefore, all tick labels of the figure follow the same setting and we cannot demonstrate both glyphs on real tick labels of the same figure simultaneously.

Instead, this example simply showcases the difference between the two glyphs in a magnified font.

![unicode minus](https://matplotlib.org/stable/_images/sphx_glr_unicode_minus_001_2_00x.png)

import matplotlib.pyplot as plt

[fig](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.html#matplotlib.figure.Figure "matplotlib.figure.Figure")
 \= [plt.figure](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.figure.html#matplotlib.pyplot.figure "matplotlib.pyplot.figure")
(figsize\=(4, 2))
[fig.text](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.text.html#matplotlib.figure.Figure.text "matplotlib.figure.Figure.text")
(.15, .6, "Unicode minus:", fontsize\=20)
[fig.text](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.text.html#matplotlib.figure.Figure.text "matplotlib.figure.Figure.text")
(.85, .6, "\\N{MINUS SIGN}1", ha\='right', fontsize\=20)
[fig.text](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.text.html#matplotlib.figure.Figure.text "matplotlib.figure.Figure.text")
(.15, .3, "ASCII hyphen:", fontsize\=20)
[fig.text](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.text.html#matplotlib.figure.Figure.text "matplotlib.figure.Figure.text")
(.85, .3, "-1", ha\='right', fontsize\=20)
[plt.show](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.show.html#matplotlib.pyplot.show "matplotlib.pyplot.show")
()
