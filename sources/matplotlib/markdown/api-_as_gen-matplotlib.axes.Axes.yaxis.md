Axes.yaxis[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.yaxis.html#matplotlib.axes.Axes.yaxis "Link to this definition")

The [`YAxis`](https://matplotlib.org/stable/api/axis_api.html#matplotlib.axis.YAxis "matplotlib.axis.YAxis")
 instance.

Common axis-related configuration can be achieved through high-level wrapper methods on Axes; e.g. [`ax.set_yticks`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_yticks.html#matplotlib.axes.Axes.set_yticks "matplotlib.axes.Axes.set_yticks")
 is a shortcut for [`ax.yaxis.set_ticks`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axis.Axis.set_ticks.html#matplotlib.axis.Axis.set_ticks "matplotlib.axis.Axis.set_ticks")
. The _yaxis_ attribute gives direct access to the underlying [`Axis`](https://matplotlib.org/stable/api/axis_api.html#matplotlib.axis.Axis "matplotlib.axis.Axis")
 if you need more control.

See also
