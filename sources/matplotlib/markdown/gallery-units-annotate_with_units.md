Annotation with units[#](https://matplotlib.org/stable/gallery/units/annotate_with_units.html#annotation-with-units "Link to this heading")

============================================================================================================================================

The example illustrates how to create text and arrow annotations using a centimeter-scale plot.

This example requires [`basic_units.py`](https://matplotlib.org/stable/_downloads/0f0fd288c7d4a6a16f4835b96343f597/basic_units.py)

![annotate with units](https://matplotlib.org/stable/_images/sphx_glr_annotate_with_units_001_2_00x.png)

from basic\_units import cm

import matplotlib.pyplot as plt

[fig](https://matplotlib.org/stable/api/_as_gen/matplotlib.figure.Figure.html#matplotlib.figure.Figure "matplotlib.figure.Figure")
, [ax](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.html#matplotlib.axes.Axes "matplotlib.axes.Axes")
 \= [plt.subplots](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.subplots.html#matplotlib.pyplot.subplots "matplotlib.pyplot.subplots")
()

[ax.annotate](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.annotate.html#matplotlib.axes.Axes.annotate "matplotlib.axes.Axes.annotate")
("Note 01", \[0.5\*cm, 0.5\*cm\])

\# xy and text both unitized
[ax.annotate](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.annotate.html#matplotlib.axes.Axes.annotate "matplotlib.axes.Axes.annotate")
('local max', xy\=(3\*cm, 1\*cm), xycoords\='data',
            xytext\=(0.8\*cm, 0.95\*cm), textcoords\='data',
            arrowprops\=dict(facecolor\='black', shrink\=0.05),
            horizontalalignment\='right', verticalalignment\='top')

\# mixing units w/ nonunits
[ax.annotate](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.annotate.html#matplotlib.axes.Axes.annotate "matplotlib.axes.Axes.annotate")
('local max', xy\=(3\*cm, 1\*cm), xycoords\='data',
            xytext\=(0.8, 0.95), textcoords\='axes fraction',
            arrowprops\=dict(facecolor\='black', shrink\=0.05),
            horizontalalignment\='right', verticalalignment\='top')

[ax.set\_xlim](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_xlim.html#matplotlib.axes.Axes.set_xlim "matplotlib.axes.Axes.set_xlim")
(0\*cm, 4\*cm)
[ax.set\_ylim](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_ylim.html#matplotlib.axes.Axes.set_ylim "matplotlib.axes.Axes.set_ylim")
(0\*cm, 4\*cm)
[plt.show](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.show.html#matplotlib.pyplot.show "matplotlib.pyplot.show")
()
