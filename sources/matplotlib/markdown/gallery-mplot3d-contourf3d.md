=========================================================================================================================

[`Axes3D.contourf`](https://matplotlib.org/stable/api/_as_gen/mpl_toolkits.mplot3d.axes3d.Axes3D.contourf.html#mpl_toolkits.mplot3d.axes3d.Axes3D.contourf "mpl_toolkits.mplot3d.axes3d.Axes3D.contourf")
 differs from [`Axes3D.contour`](https://matplotlib.org/stable/api/_as_gen/mpl_toolkits.mplot3d.axes3d.Axes3D.contour.html#mpl_toolkits.mplot3d.axes3d.Axes3D.contour "mpl_toolkits.mplot3d.axes3d.Axes3D.contour")
 in that it creates filled contours, i.e. a discrete number of colours are used to shade the domain.

This is like a [`Axes.contourf`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.contourf.html#matplotlib.axes.Axes.contourf "matplotlib.axes.Axes.contourf")
 plot in 2D except that the shaded region corresponding to the level c is graphed on the plane `z=c`.
