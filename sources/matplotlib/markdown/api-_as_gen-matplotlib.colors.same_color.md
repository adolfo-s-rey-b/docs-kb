matplotlib.colors.same\_color(_c1_, _c2_)[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/colors.py#L287-L311)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.colors.same_color.html#matplotlib.colors.same_color "Link to this definition")

Return whether the colors _c1_ and _c2_ are the same.

Parameters:

**c1, c2**[color](https://matplotlib.org/stable/users/explain/colors/colors.html#colors-def)
 or list of [color](https://matplotlib.org/stable/users/explain/colors/colors.html#colors-def)
 or RGB(A) array

If passing multiple colors, _c1_ and _c2_ must be of the same length. RGB(A) arrays must be of shape (ncolors, 3) or (ncolors, 4).

Returns:

bool
