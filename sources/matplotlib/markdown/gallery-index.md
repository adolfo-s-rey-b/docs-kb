Event handling[#](https://matplotlib.org/stable/gallery/index.html#event-handling "Link to this heading")

----------------------------------------------------------------------------------------------------------

Matplotlib supports [event handling](https://matplotlib.org/stable/users/explain/figure/event_handling.html#id1)
 with a GUI neutral event model, so you can connect to Matplotlib events without knowledge of what user interface Matplotlib will ultimately be plugged in to. This has two advantages: the code you write will be more portable, and Matplotlib events are aware of things like data coordinate space and which axes the event occurs in so you don't have to mess with low level transformation details to go from canvas space to data space. Object picking examples are also included.
