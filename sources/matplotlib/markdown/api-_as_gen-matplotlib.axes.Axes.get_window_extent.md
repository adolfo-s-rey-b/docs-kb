Axes.get\_window\_extent(_renderer\=None_)[\[source\]](https://github.com/matplotlib/matplotlib/blob/v3.11.2/lib/matplotlib/axes/_base.py#L867-L881)
[#](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.get_window_extent.html#matplotlib.axes.Axes.get_window_extent "Link to this definition")

Return the Axes bounding box in display space.

This bounding box does not include the spines, ticks, ticklabels, or other labels. For a bounding box including these elements use [`get_tightbbox`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.get_tightbbox.html#matplotlib.axes.Axes.get_tightbbox "matplotlib.axes.Axes.get_tightbbox")
