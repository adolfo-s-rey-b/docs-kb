Plot with radians from the basic\_units mockup example package.

This example shows how the unit class can determine the tick locating, formatting and axis labeling.

This example requires [`basic_units.py`](https://matplotlib.org/stable/_downloads/0f0fd288c7d4a6a16f4835b96343f597/basic_units.py)

![radian demo](https://matplotlib.org/stable/_images/sphx_glr_radian_demo_001_2_00x.png)
