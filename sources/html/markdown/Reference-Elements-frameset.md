`<frameset>` HTML frameset element
==================================

Deprecated

Avoid using this feature in new projects. This feature may be a candidate for removal from web standards or browsers.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`<frameset>`** [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
 element is used to contain [`<frame>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frame)
 elements.

**Note:** Because the use of frames is now discouraged in favor of using [`<iframe>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)
, this element is not typically used by modern websites.

[Attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#attributes)

-------------------------------------------------------------------------------------------------------

Like all other HTML elements, this element supports the [global attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
.

[`cols`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#cols)

This attribute specifies the number and size of horizontal spaces in a frameset.

[`rows`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#rows)

This attribute specifies the number and size of vertical spaces in a frameset.

[Example](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#example)

-------------------------------------------------------------------------------------------------

### [A frameset document](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#a_frameset_document)

A frameset document has a `<frameset>` element instead of a [`<body>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/body)
 element. The [`<frame>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frame)
 elements are placed within the `<frameset>`.

If you want to embed another HTML page into the [`<body>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/body)
 of a document, use an [`<iframe>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)
 element.

[Specifications](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/frameset#specifications)
