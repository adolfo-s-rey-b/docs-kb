`for` HTML attribute
====================

The **`for`** attribute is an allowed attribute for [`<label>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/label)
 and [`<output>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/output)
. When used on a `<label>` element it indicates the form element that this label describes. When used on an `<output>` element it allows for an explicit relationship between the elements that represent values which are used in the output.

[Try it](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/for#try_it)

--------------------------------------------------------------------------------------------

[Usage notes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/for#usage_notes)

------------------------------------------------------------------------------------------------------

When used as an attribute of `<label>`, the `for` attribute has a value which is the `id` of the form element it relates to.

When used as an attribute of `<output>`, the `for` attribute has a value which is a space separated list of the `id` values of the elements which are used to create the output.

[Examples](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/for#examples)

------------------------------------------------------------------------------------------------

See examples of usage on the element pages for [`<label>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/label)
 and [`<output>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/output)
.
