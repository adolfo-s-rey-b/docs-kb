`<font>` HTML font element
==========================

Deprecated

Avoid using this feature in new projects. This feature may be a candidate for removal from web standards or browsers.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/font#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`<font>`** [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
 element defines the font size, color and face for its content.

**Warning:** Do not use this element. Use the CSS [Fonts](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Fonts)
 properties to style text.

[Attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/font#attributes)

---------------------------------------------------------------------------------------------------

Like all other HTML elements, this element supports the [global attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
.

[`color`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/font#color)

This attribute sets the text color using either a named color or a color specified in the hexadecimal #RRGGBB format.

[`face`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/font#face)

This attribute contains a comma-separated list of one or more font names. The document text in the default style is rendered in the first font face that the client's browser supports. If no font listed is installed on the local system, the browser typically defaults to the proportional or fixed-width font for that system.

[`size`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/font#size)

This attribute specifies the font size as either a numeric or relative value. Numeric values range from `1` to `7` with `1` being the smallest and `3` the default. It can be defined using a relative value, like `+2` or `-3`, which sets it relative to `3`, the default value.

[DOM interface](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/font#dom_interface)

---------------------------------------------------------------------------------------------------------

This element implements the [`HTMLFontElement`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLFontElement)
 interface.
