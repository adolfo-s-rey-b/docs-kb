`<dir>` HTML directory element
==============================

Deprecated

Avoid using this feature in new projects. This feature may be a candidate for removal from web standards or browsers.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dir#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`<dir>`** [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
 element is used as a container for a directory of files and/or folders, potentially with styles and icons applied by the [user agent](https://developer.mozilla.org/en-US/docs/Glossary/User_agent)
. Do not use this obsolete element; instead, you should use the [`<ul>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/ul)
 element for lists, including lists of files.

**Warning:** Do not use this element. Though present in early HTML specifications, it has been deprecated in HTML 4, and has since been removed entirely.

[DOM interface](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dir#dom_interface)

--------------------------------------------------------------------------------------------------------

This element implements the `HTMLDirectoryElement` interface.

[Attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dir#attributes)

--------------------------------------------------------------------------------------------------

Like all other HTML elements, this element supports the [global attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
.

[`compact`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dir#compact)

This Boolean attribute hints that the list should be rendered in a compact style. The interpretation of this attribute depends on the user agent and it doesn't work in all browsers.

    , and [`<menu>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/menu)
    ;
*   CSS properties that may be specially useful to style the `<dir>` element:
    *   The [`list-style`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/list-style)
         property, useful to choose the way the ordinal is displayed.
    *   [CSS counters](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Counter_styles/Using_counters)
        , useful to handle complex nested lists.
    *   The [`line-height`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/line-height)
         property, useful to simulate the deprecated [`compact`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dir#compact)
         attribute.
    *   The [`margin`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/margin)
         property, useful to control the indent of the list.
