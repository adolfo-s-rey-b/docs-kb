`rel="me"` HTML attribute value
===============================

The **`me`** keyword for the [`rel`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/link#rel)
 attribute of the [`<link>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/link)
 and [`<a>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a)
 elements indicates that the current resource is represented by the linked party. The `me` value was introduced in the [XHTML Friends Network (XFN) specification](https://gmpg.org/xfn/ "External link (opens in new tab)")
.

The `rel="me"` attribute is used in [RelMeAuth](https://microformats.org/wiki/RelMeAuth "External link (opens in new tab)")
 and [Web sign in](https://microformats.org/wiki/web-sign-in "External link (opens in new tab)")
 specifications as a way to enable a person to identify themselves to a web service using their domain name or a particular URL.
