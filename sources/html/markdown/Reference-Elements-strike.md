`<strike>` HTML strikethrough element
=====================================

Deprecated

Avoid using this feature in new projects. This feature may be a candidate for removal from web standards or browsers.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/strike#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`<strike>`** [HTML](https://developer.mozilla.org/en-US/docs/Web/HTML)
 element places a strikethrough (horizontal line) over text.

**Warning:** This element is deprecated in HTML 4 and XHTML 1, and obsoleted in the [HTML Living Standard](https://html.spec.whatwg.org/multipage/obsolete.html#strike "External link (opens in new tab)")
. If semantically appropriate, i.e., if it represents _deleted_ content, use [`<del>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/del)
 instead. In all other cases use [`<s>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/s)
.

[Attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/strike#attributes)

-----------------------------------------------------------------------------------------------------

This element includes the [global attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes)
.

[Examples](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/strike#examples)

-------------------------------------------------------------------------------------------------

html

    &lt;strike&gt;: <strike>Today's Special: Salmon</strike> SOLD OUT<br />
    &lt;s&gt;: <s>Today's Special: Salmon</s> SOLD OUT
