`rel="noreferrer"` HTML attribute value
=======================================

The **`noreferrer`** keyword for the [`rel`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/rel)
 attribute of the [`<a>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a)
, [`<area>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/area)
, and [`<form>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/form)
 elements instructs the browser, when fetching the target resource, to omit the [`Referer`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Referer)
 header and otherwise leak no referrer information — and additionally to behave as if the [`noopener`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/rel/noopener)
 keyword were also specified.
