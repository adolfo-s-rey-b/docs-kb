Gaussian Mixture Model Sine Curve[#](https://scikit-learn.org/stable/auto_examples/mixture/plot_gmm_sin.html#gaussian-mixture-model-sine-curve "Link to this heading")

=======================================================================================================================================================================

This example demonstrates the behavior of Gaussian mixture models fit on data that was not sampled from a mixture of Gaussian random variables. The dataset is formed by 100 points loosely spaced following a noisy sine curve. There is therefore no ground truth value for the number of Gaussian components.

The first model is a classical Gaussian Mixture Model with 10 components fit with the Expectation-Maximization algorithm.

The second model is a Bayesian Gaussian Mixture Model with a Dirichlet process prior fit with variational inference. The low value of the concentration prior makes the model favor a lower number of active components. This models “decides” to focus its modeling power on the big picture of the structure of the dataset: groups of points with alternating directions modeled by non-diagonal covariance matrices. Those alternating directions roughly capture the alternating nature of the original sine signal.

The third model is also a Bayesian Gaussian mixture model with a Dirichlet process prior but this time the value of the concentration prior is higher giving the model more liberty to model the fine-grained structure of the data. The result is a mixture with a larger number of active components that is similar to the first model where we arbitrarily decided to fix the number of components to 10.

Which model is the best is a matter of subjective judgment: do we want to favor models that only capture the big picture to summarize and explain most of the structure of the data while ignoring the details or do we prefer models that closely follow the high density regions of the signal?

The last two panels show how we can sample from the last two models. The resulting samples distributions do not look exactly like the original data distribution. The difference primarily stems from the approximation error we made by using a model that assumes that the data was generated by a finite number of Gaussian components instead of a continuous noisy sine curve.

import itertools

import matplotlib as mpl

color\_iter \= [itertools.cycle](https://docs.python.org/3/library/itertools.html#itertools.cycle "itertools.cycle")
(\["navy", "c", "cornflowerblue", "gold", "darkorange"\])

def plot\_results(X, Y, means, covariances, index, title):
    splot \= [plt.subplot](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.subplot.html#matplotlib.pyplot.subplot "matplotlib.pyplot.subplot")

    for i, (mean, covar, color) in enumerate(zip(means, covariances, color\_iter)):
        v, w \= [linalg.eigh](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.eigh.html#scipy.linalg.eigh "scipy.linalg.eigh")
(covar)
        v \= 2.0 \* [np.sqrt](https://numpy.org/doc/stable/reference/generated/numpy.sqrt.html#numpy.sqrt "numpy.sqrt")
(2.0) \* [np.sqrt](https://numpy.org/doc/stable/reference/generated/numpy.sqrt.html#numpy.sqrt "numpy.sqrt")
(v)
        u \= w\[0\] / [linalg.norm](https://docs.scipy.org/doc/scipy/reference/generated/scipy.linalg.norm.html#scipy.linalg.norm "scipy.linalg.norm")
(w\[0\])
        \# as the DP will not use every component it has access to
        \# unless it needs it, we shouldn't plot the redundant
        \# components.
        if not [np.any](https://numpy.org/doc/stable/reference/generated/numpy.any.html#numpy.any "numpy.any")
(Y \== i):
            continue
        [plt.scatter](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.scatter.html#matplotlib.pyplot.scatter "matplotlib.pyplot.scatter")
(X\[Y \== i, 0\], X\[Y \== i, 1\], 0.8, color\=color)

        \# Plot an ellipse to show the Gaussian component
        angle \= [np.arctan](https://numpy.org/doc/stable/reference/generated/numpy.arctan.html#numpy.arctan "numpy.arctan")

        angle \= 180.0 \* angle / [np.pi](https://numpy.org/doc/stable/reference/constants.html#numpy.pi "numpy.pi")
  \# convert to degrees
        ell \= [mpl.patches.Ellipse](https://matplotlib.org/stable/api/_as_gen/matplotlib.patches.Ellipse.html#matplotlib.patches.Ellipse "matplotlib.patches.Ellipse")
(mean, v\[0\], v\[1\], angle\=180.0 + angle, color\=color)
        ell.set\_clip\_box(splot.bbox)
        ell.set\_alpha(0.5)
        splot.add\_artist(ell)

    [plt.xlim](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.xlim.html#matplotlib.pyplot.xlim "matplotlib.pyplot.xlim")
(\-6.0, 4.0 \* [np.pi](https://numpy.org/doc/stable/reference/constants.html#numpy.pi "numpy.pi")
 \- 6.0)
    [plt.ylim](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.ylim.html#matplotlib.pyplot.ylim "matplotlib.pyplot.ylim")
(\-5.0, 5.0)
    [plt.title](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.title.html#matplotlib.pyplot.title "matplotlib.pyplot.title")
(title)
    [plt.xticks](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.xticks.html#matplotlib.pyplot.xticks "matplotlib.pyplot.xticks")
(())
    [plt.yticks](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.yticks.html#matplotlib.pyplot.yticks "matplotlib.pyplot.yticks")

    [plt.subplot](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.subplot.html#matplotlib.pyplot.subplot "matplotlib.pyplot.subplot")

    for i, color in zip(range(n\_components), color\_iter):

    [plt.xlim](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.xlim.html#matplotlib.pyplot.xlim "matplotlib.pyplot.xlim")

\# Parameters
n\_samples \= 100

\# Generate random sample following a sine curve
[np.random.seed](https://numpy.org/doc/stable/reference/random/generated/numpy.random.seed.html#numpy.random.seed "numpy.random.seed")
(0)
X \= [np.zeros](https://numpy.org/doc/stable/reference/generated/numpy.zeros.html#numpy.zeros "numpy.zeros")
((n\_samples, 2))
step \= 4.0 \* [np.pi](https://numpy.org/doc/stable/reference/constants.html#numpy.pi "numpy.pi")
 / n\_samples

for i in range(X.shape\[0\]):
    x \= i \* step \- 6.0
    X\[i, 0\] \= x + [np.random.normal](https://numpy.org/doc/stable/reference/random/generated/numpy.random.normal.html#numpy.random.normal "numpy.random.normal")
(0, 0.1)
    X\[i, 1\] \= 3.0 \* ([np.sin](https://numpy.org/doc/stable/reference/generated/numpy.sin.html#numpy.sin "numpy.sin")
(x) + [np.random.normal](https://numpy.org/doc/stable/reference/random/generated/numpy.random.normal.html#numpy.random.normal "numpy.random.normal")
(0, 0.2))

[plt.figure](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.figure.html#matplotlib.pyplot.figure "matplotlib.pyplot.figure")
(figsize\=(10, 10))
[plt.subplots\_adjust](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.subplots_adjust.html#matplotlib.pyplot.subplots_adjust "matplotlib.pyplot.subplots_adjust")
(
    bottom\=0.04, top\=0.95, hspace\=0.2, wspace\=0.05, left\=0.03, right\=0.97
)

\# Fit a Gaussian mixture with EM using ten components
gmm \= [mixture.GaussianMixture](https://scikit-learn.org/stable/modules/generated/sklearn.mixture.GaussianMixture.html#sklearn.mixture.GaussianMixture "sklearn.mixture.GaussianMixture")
(
    n\_components\=10, covariance\_type\="full", max\_iter\=100
).fit(X)
plot\_results(
    X, gmm.predict(X), gmm.means\_, gmm.covariances\_, 0, "Expectation-maximization"
)

dpgmm \= [mixture.BayesianGaussianMixture](https://scikit-learn.org/stable/modules/generated/sklearn.mixture.BayesianGaussianMixture.html#sklearn.mixture.BayesianGaussianMixture "sklearn.mixture.BayesianGaussianMixture")
(
    n\_components\=10,
    covariance\_type\="full",
    weight\_concentration\_prior\=1e-2,
    weight\_concentration\_prior\_type\="dirichlet\_process",
    mean\_precision\_prior\=1e-2,
    covariance\_prior\=1e0 \* [np.eye](https://numpy.org/doc/stable/reference/generated/numpy.eye.html#numpy.eye "numpy.eye")
(2),
    init\_params\="random",
    max\_iter\=100,
    random\_state\=2,
).fit(X)
plot\_results(
    X,
    dpgmm.predict(X),
    dpgmm.means\_,
    dpgmm.covariances\_,
    1,
    "Bayesian Gaussian mixture models with a Dirichlet process prior "
    r"for $\\gamma\_0=0.01$.",
)

X\_s, y\_s \= dpgmm.sample(n\_samples\=2000)
plot\_samples(
    X\_s,
    y\_s,
    dpgmm.n\_components,
    0,
    "Gaussian mixture with a Dirichlet process prior "
    r"for $\\gamma\_0=0.01$ sampled with $2000$ samples.",
)

dpgmm \= [mixture.BayesianGaussianMixture](https://scikit-learn.org/stable/modules/generated/sklearn.mixture.BayesianGaussianMixture.html#sklearn.mixture.BayesianGaussianMixture "sklearn.mixture.BayesianGaussianMixture")
(
    n\_components\=10,

    weight\_concentration\_prior\=1e2,

    init\_params\="kmeans",
    max\_iter\=100,
