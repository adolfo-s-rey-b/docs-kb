1970-01-01 UTC
==============

Source: [`R/instants.r`](https://github.com/tidyverse/lubridate/blob/v1.9.5/R/instants.r)

`origin.Rd`

Origin is the date-time for 1970-01-01 UTC in POSIXct format. This date-time is the origin for the numbering system used by POSIXct, POSIXlt, chron, and Date classes.

Usage[](https://lubridate.tidyverse.org/reference/origin.html#ref-usage)

-------------------------------------------------------------------------

    origin

Format[](https://lubridate.tidyverse.org/reference/origin.html#format)

-----------------------------------------------------------------------

An object of class `POSIXct` (inherits from `POSIXt`) of length 1.

Examples[](https://lubridate.tidyverse.org/reference/origin.html#ref-examples)

-------------------------------------------------------------------------------

    origin
    #> [1] "1970-01-01 UTC"
