Timespan class
==============

Source: [`R/timespans.r`](https://github.com/tidyverse/lubridate/blob/v1.9.5/R/timespans.r)

`Timespan-class.Rd`

Timespan is an S4 class with no slots. It is extended by the [Interval](https://lubridate.tidyverse.org/reference/Interval-class.html)
, [Period](https://lubridate.tidyverse.org/reference/Period-class.html)
, and [Duration](https://lubridate.tidyverse.org/reference/Duration-class.html)
 classes.
