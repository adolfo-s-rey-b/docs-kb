torch.Tensor.index\_put\_[#](https://docs.pytorch.org/docs/2.15/generated/torch.Tensor.index_put_.html#torch-tensor-index-put "Link to this heading")

======================================================================================================================================================

Tensor.index\_put\_(_indices_, _values_, _accumulate\=False_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[#](https://docs.pytorch.org/docs/2.15/generated/torch.Tensor.index_put_.html#torch.Tensor.index_put_ "Link to this definition")

Puts values from the tensor [`values`](https://docs.pytorch.org/docs/2.15/generated/torch.Tensor.values.html#torch.Tensor.values "torch.Tensor.values")
 into the tensor `self` using the indices specified in [`indices`](https://docs.pytorch.org/docs/2.15/generated/torch.Tensor.indices.html#torch.Tensor.indices "torch.Tensor.indices")
 (which is a tuple of Tensors). The expression `tensor.index_put_(indices, values)` is equivalent to `tensor[indices] = values`. Returns `self`.

If `accumulate` is `True`, the elements in [`values`](https://docs.pytorch.org/docs/2.15/generated/torch.Tensor.values.html#torch.Tensor.values "torch.Tensor.values")
 are added to `self`. If accumulate is `False`, the behavior is undefined if indices contain duplicate elements.

Parameters:

*   **indices** ([_tuple_](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
     _of_ _LongTensor_) – tensors used to index into self.
    
*   **values** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – tensor of same dtype as self.
    
*   **accumulate** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    ) – whether to accumulate into self
