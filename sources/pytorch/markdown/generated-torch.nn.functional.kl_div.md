torch.nn.functional.kl\_div(_input_, _target_, _size\_average\=None_, _reduce\=None_, _reduction\='mean'_, _log\_target\=False_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/functional.py#L3401)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.kl_div.html#torch.nn.functional.kl_div "Link to this definition")

Compute the KL Divergence loss.

Refer - The [Kullback-Leibler divergence Loss](https://en.wikipedia.org/wiki/Kullback-Leibler_divergence)

See [`KLDivLoss`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.KLDivLoss.html#torch.nn.KLDivLoss "torch.nn.KLDivLoss")
 for details.

Parameters:

*   **input** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Tensor of arbitrary shape in log-probabilities.
    
*   **target** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Tensor of the same shape as input. See `log_target` for the target’s interpretation.
    
*   **size\_average** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Deprecated (see `reduction`).
    
*   **reduce** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Deprecated (see `reduction`).
    
*   **reduction** ([_str_](https://docs.python.org/3/builtins/stdtypes.html#str "(in Python v3.15)")
    _,_ _optional_) – Specifies the reduction to apply to the output: `'none'` | `'batchmean'` | `'sum'` | `'mean'`. `'none'`: no reduction will be applied `'batchmean'`: the sum of the output will be divided by the batchsize `'sum'`: the output will be summed `'mean'`: the output will be divided by the number of elements in the output Default: `'mean'`
    
*   **log\_target** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    ) – A flag indicating whether `target` is passed in the log space. It is recommended to pass certain distributions (like `softmax`) in the log space to avoid numerical issues caused by explicit `log`. Default: `False`
    

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")

Note

`size_average` and `reduce` are in the process of being deprecated, and in the meantime, specifying either of those two args will override `reduction`.

Warning

`reduction` = `'mean'` doesn’t return the true kl divergence value, please use `reduction` = `'batchmean'` which aligns with KL math definition.
