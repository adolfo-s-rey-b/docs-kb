=======================================================================================================================================================================================================

torch.nn.utils.rnn.pack\_padded\_sequence(_input_, _lengths_, _batch\_first\=False_, _enforce\_sorted\=True_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/rnn.py#L258)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pack_padded_sequence.html#torch.nn.utils.rnn.pack_padded_sequence "Link to this definition")

Packs a Tensor containing padded sequences of variable length.

`input` can be of size `T x B x *` (if `batch_first` is `False`) or `B x T x *` (if `batch_first` is `True`) where `T` is the length of the longest sequence, `B` is the batch size, and `*` is any number of dimensions (including 0).

For unsorted sequences, use enforce\_sorted = False. If `enforce_sorted` is `True`, the sequences should be sorted by length in a decreasing order, i.e. `input[:,0]` should be the longest sequence, and `input[:,B-1]` the shortest one. enforce\_sorted = True is only necessary for ONNX export.

It is an inverse operation to [`pad_packed_sequence()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pad_packed_sequence.html#torch.nn.utils.rnn.pad_packed_sequence "torch.nn.utils.rnn.pad_packed_sequence")
, and hence [`pad_packed_sequence()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pad_packed_sequence.html#torch.nn.utils.rnn.pad_packed_sequence "torch.nn.utils.rnn.pad_packed_sequence")
 can be used to recover the underlying tensor packed in [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
.

Note

This function accepts any input that has at least two dimensions. You can apply it to pack the labels, and use the output of the RNN with them to compute the loss directly. A Tensor can be retrieved from a [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
 object by accessing its `.data` attribute.

Parameters:

*   **input** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – padded batch of variable length sequences.
    
*   **lengths** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
     _or_ [_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    _(_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _)_) – list of sequence lengths of each batch element (must be on the CPU if provided as a tensor).
    
*   **batch\_first** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – if `True`, the input is expected in `B x T x *` format, `T x B x *` otherwise. Default: `False`.
    
*   **enforce\_sorted** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – if `True`, the input is expected to contain sequences sorted by length in a decreasing order. If `False`, the input will get sorted unconditionally. Default: `True`.
    

Return type:

[_PackedSequence_](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")

Warning

The dim of `input` tensor will be truncated if its length larger than correspond value in `length`.

a [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
 object
