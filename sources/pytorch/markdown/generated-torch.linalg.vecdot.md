torch.linalg.vecdot[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.vecdot.html#torch-linalg-vecdot "Link to this heading")

=========================================================================================================================================

torch.linalg.vecdot(_x_, _y_, _\*_, _dim\=\-1_, _out\=None_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/linalg/__init__.py#L3091)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.vecdot.html#torch.linalg.vecdot "Link to this definition")

Computes the dot product of two batches of vectors along a dimension.

In symbols, this function computes

∑i\=1nxi‾yi.\\sum\_{i=1}^n \\overline{x\_i}y\_i.i\=1∑n​xi​​yi​.

over the dimension `dim` where xi‾\\overline{x\_i}xi​​ denotes the conjugate for complex vectors, and it is the identity for real vectors.

Supports input of half, bfloat16, float, double, cfloat, cdouble and integral dtypes. It also supports broadcasting.

Parameters:

*   **x** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – first batch of vectors of shape (\*, n).
    
*   **y** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – second batch of vectors of shape (\*, n).
    

Keyword Arguments:

*   **dim** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    ) – Dimension along which to compute the dot product. Default: \-1.
    
*   **out** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    _,_ _optional_) – output tensor. Ignored if None. Default: None.
    

Examples:

\>>> v1 \= torch.randn(3, 2)
\>>> v2 \= torch.randn(3, 2)
\>>> linalg.vecdot(v1, v2)
tensor(\[ 0.3223,  0.2815, -0.1944\])
\>>> torch.vdot(v1\[0\], v2\[0\])
tensor(0.3223)
