torch.linalg.tensorsolve[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.tensorsolve.html#torch-linalg-tensorsolve "Link to this heading")

========================================================================================================================================================

torch.linalg.tensorsolve(_A_, _B_, _dims\=None_, _\*_, _out\=None_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/linalg/__init__.py#L2799)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.tensorsolve.html#torch.linalg.tensorsolve "Link to this definition")

Computes the solution X to the system torch.tensordot(A, X) = B.

If m is the product of the first `B`.ndim dimensions of `A` and n is the product of the rest of the dimensions, this function expects m and n to be equal.

The returned tensor x satisfies tensordot(`A`, x, dims=x.ndim) == `B`. x has shape `A`\[B.ndim:\].

If `dims` is specified, `A` will be reshaped as

A = movedim(A, dims, range(len(dims) - A.ndim + 1, 0))

Copy to clipboard

Supports inputs of float, double, cfloat and cdouble dtypes.

See also

[`torch.linalg.tensorinv()`](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.tensorinv.html#torch.linalg.tensorinv "torch.linalg.tensorinv")
 computes the multiplicative inverse of [`torch.tensordot()`](https://docs.pytorch.org/docs/2.15/generated/torch.tensordot.html#torch.tensordot "torch.tensordot")
.

Parameters:

*   **A** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – tensor to solve for. Its shape must satisfy prod(`A`.shape\[:`B`.ndim\]) == prod(`A`.shape\[`B`.ndim:\]).
    
*   **B** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – tensor of shape `A`.shape\[:`B`.ndim\].
    
*   **dims** (_Tuple__\[_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _\]__,_ _optional_) – dimensions of `A` to be moved. If None, no dimensions are moved. Default: None.
    

Keyword Arguments:

**out** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
_,_ _optional_) – output tensor. Ignored if None. Default: None.

Raises:

[**RuntimeError**](https://docs.python.org/3/builtins/exceptions.html#RuntimeError "(in Python v3.15)")
 – if the reshaped `A`.view(m, m) with m as above is not invertible or the product of the first `ind` dimensions is not equal to the product of the rest of the dimensions.

Examples:

\>>> A \= torch.eye(2 \* 3 \* 4).reshape((2 \* 3, 4, 2, 3, 4))
\>>> B \= torch.randn(2 \* 3, 4)
\>>> X \= torch.linalg.tensorsolve(A, B)
\>>> X.shape
torch.Size(\[2, 3, 4\])
\>>> torch.allclose(torch.tensordot(A, X, dims\=X.ndim), B)
True

\>>> A \= torch.randn(6, 4, 4, 3, 2)
\>>> B \= torch.randn(4, 3, 2)
\>>> X \= torch.linalg.tensorsolve(A, B, dims\=(0, 2))
\>>> X.shape
torch.Size(\[6, 4\])
\>>> A \= A.permute(1, 3, 4, 0, 2)
\>>> A.shape\[B.ndim:\]
torch.Size(\[6, 4\])
\>>> torch.allclose(torch.tensordot(A, X, dims\=X.ndim), B, atol\=1e-6)
True
