Add pruning on the fly and reparameterization of a tensor.

Adds the forward pre-hook that enables pruning on the fly and the reparameterization of a tensor in terms of the original tensor and the pruning mask.

prune(_t_, _default\_mask\=None_, _importance\_scores\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/prune.py#L208)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.prune.Identity_class.html#torch.nn.utils.prune.Identity.prune "Link to this definition")

Compute and returns a pruned version of input tensor `t`.

According to the pruning rule specified in `compute_mask()`.

Parameters:

*   **t** ([_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – tensor to prune (of same dimensions as `default_mask`).
    
*   **importance\_scores** ([_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – tensor of importance scores (of same shape as `t`) used to compute mask for pruning `t`. The values in this tensor indicate the importance of the corresponding elements in the `t` that is being pruned. If unspecified or None, the tensor `t` will be used in its place.
    
*   **default\_mask** ([_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    _,_ _optional_) – mask from previous pruning iteration, if any. To be considered when determining what portion of the tensor that pruning should act on. If None, default to a mask of ones.
    

Returns:

pruned version of tensor `t`.

remove(_module_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/prune.py#L240)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.prune.Identity_class.html#torch.nn.utils.prune.Identity.remove "Link to this definition")

Remove the pruning reparameterization from a module.

The pruned parameter named `name` remains permanently pruned, and the parameter named `name+'_orig'` is removed from the parameter list. Similarly, the buffer named `name+'_mask'` is removed from the buffers.

Note

Pruning itself is NOT undone or reversed!
