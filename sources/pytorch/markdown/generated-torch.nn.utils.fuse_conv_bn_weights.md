torch.nn.utils.fuse\_conv\_bn\_weights(_conv\_w_, _conv\_b_, _bn\_rm_, _bn\_rv_, _bn\_eps_, _bn\_w_, _bn\_b_, _transpose\=False_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/fusion.py#L58)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.fuse_conv_bn_weights.html#torch.nn.utils.fuse_conv_bn_weights "Link to this definition")

Fuse convolutional module parameters and BatchNorm module parameters into new convolutional module parameters.

Parameters:

*   **conv\_w** ([_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Convolutional weight.
    
*   **conv\_b** (_Optional__\[_[_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")\
    _\]_) – Convolutional bias.
    
*   **bn\_rm** ([_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – BatchNorm running mean.
    
*   **bn\_rv** ([_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – BatchNorm running variance.
    
*   **bn\_eps** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    ) – BatchNorm epsilon.
    
*   **bn\_w** (_Optional__\[_[_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")\
    _\]_) – BatchNorm weight.
    
*   **bn\_b** (_Optional__\[_[_torch.Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")\
    _\]_) – BatchNorm bias.
    
*   **transpose** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – If True, transpose the conv weight. Defaults to False.
    

Returns:

Fused convolutional weight and bias.

Return type:

Tuple\[torch.nn.Parameter, torch.nn.Parameter\]
