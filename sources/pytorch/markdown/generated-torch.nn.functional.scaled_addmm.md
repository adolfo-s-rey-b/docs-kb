torch.nn.functional.scaled\_addmm[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.scaled_addmm.html#torch-nn-functional-scaled-addmm "Link to this heading")

=================================================================================================================================================================================

torch.nn.functional.scaled\_addmm(_input_, _mat1_, _mat2_, _scale\_a_, _scale\_recipe\_a_, _scale\_b_, _scale\_recipe\_b_, _swizzle\_a\=None_, _swizzle\_b\=None_, _contraction\_dim\=()_, _use\_fast\_accum\=False_, _\*_, _beta\=1.0_, _alpha\=1.0_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/functional.py#L7302)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.scaled_addmm.html#torch.nn.functional.scaled_addmm "Link to this definition")

Compute a scaled matrix product and add it to `input`.

The result is

out\=β input+α scaled\_mm(mat1,mat2).\\mathrm{out} = \\beta\\,\\mathrm{input} + \\alpha\\,\\mathrm{scaled\\\_mm}(\\mathrm{mat1}, \\mathrm{mat2}). out\=βinput+αscaled\_mm(mat1,mat2).

The scaling recipes and swizzles have the same meaning as in [`scaled_mm()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.scaled_mm.html#torch.nn.functional.scaled_mm "torch.nn.functional.scaled_mm")
. `input` must be a canonically contiguous, 16-byte-aligned matrix with shape `(mat1.size(0), mat2.size(1))` and dtype `float16`, `bfloat16`, or `float32`. The result has the dtype of `input`; there is no separate output dtype. CUDA recipes are supported when their selected implementation uses cuBLASLt; non-cuBLAS fallbacks and ROCm are not supported.

    ) – Matrix accumulated into the scaled matrix product.
    
*   **mat1** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Left matrix operand.
    
*   **mat2** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Right matrix operand.

    _\[_[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")\
    _\]_) – Tensor containing decoding scaling factors for `mat1`.

    _\[__\_ScalingType__\]_) – Scaling recipe for `mat1`.

     _|_ [_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")

    _\]_) – Tensor containing decoding scaling factors for `mat2`.

    _\[__\_ScalingType__\]_) – Scaling recipe for `mat2`.
    
*   **swizzle\_a** (_\_SwizzleType_ _|_ [_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    _\[__\_SwizzleType__\]_ _|_ _None_) – Swizzling pattern, if any, for `scale_a`.
    
*   **swizzle\_b** (_\_SwizzleType_ _|_ [_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")

    _,_ _...__\]_) – Must be empty or `(1, 0)` (equivalent negative dimensions are also accepted).
    
*   **use\_fast\_accum** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    ) – Whether to enable tensor-core fast accumulation.

    ) – Multiplier for `input`.
    
*   **alpha** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    ) – Multiplier for the scaled matrix product.
    

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")

Note

Fusing the addition removes an intermediate output rounding step, so the result need not be bitwise equal to a separate scaled matrix multiply followed by an addition.
