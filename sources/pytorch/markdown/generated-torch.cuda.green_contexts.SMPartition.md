_class_ torch.cuda.green\_contexts.SMPartition(_\_resource_, _\_device\_id_, _\_owner\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/cuda/green_contexts.py#L271)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.SMPartition.html#torch.cuda.green_contexts.SMPartition "Link to this definition")

An SM resource selected by CUDA, with its device and allocation metadata.

Obtain resources with [`from_device()`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.SMPartition.html#torch.cuda.green_contexts.SMPartition.from_device "torch.cuda.green_contexts.SMPartition.from_device")
, [`split()`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.SMPartition.html#torch.cuda.green_contexts.SMPartition.split "torch.cuda.green_contexts.SMPartition.split")
, or [`GreenContext.sm_partition`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.GreenContext.html#torch.cuda.green_contexts.GreenContext.sm_partition "torch.cuda.green_contexts.GreenContext.sm_partition")
. Construct a [`GreenContext`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.GreenContext.html#torch.cuda.green_contexts.GreenContext "torch.cuda.green_contexts.GreenContext")
 with `sm_partition=partition` to run work on the selected SMs.

A partition describes a set of SMs; it does not reserve them against other contexts. Reusing a partition for multiple contexts shares those SMs.

split(_\*_, _num\_sms\=0_, _coscheduled\_sm\_count\=0_, _preferred\_coscheduled\_sm\_count\=0_, _backfill\=False_, _locality\_domain\_ids\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/cuda/green_contexts.py#L344)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.SMPartition.html#torch.cuda.green_contexts.SMPartition.split "Link to this definition")

Split this resource into disjoint groups and an optional remainder.

Requires CUDA driver and bindings 13.1+. CUDA checks the requested counts and hardware constraints; counts are not automatically rounded. A count of zero requests discovery of the largest remaining group satisfying its constraints. Groups are processed in order.

Parameters:

*   **num\_sms** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ _sequence_ _of_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – SM count for each group. Zero requests discovery. Default: `0`.
    
*   **coscheduled\_sm\_count** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ _sequence_ _of_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – Co-scheduled SM grouping size for thread-block clusters. Zero lets CUDA determine cluster capabilities from the selected resources. Default: `0`.
    
*   **preferred\_coscheduled\_sm\_count** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ _sequence_ _of_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – Preferred larger grouping size, when CUDA can combine groups. Zero selects the CUDA default. Default: `0`.
    
*   **backfill** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
     _or_ _sequence_ _of_ [_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Allow CUDA to fill groups with SMs outside the co-scheduling or locality constraints. Default: `False`.
    
*   **locality\_domain\_ids** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _None__, or_ _sequence_ _of_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ _None__,_ _optional_) – Select SMs from these locality domains during splitting. `None` leaves locality unconstrained. Requires CUDA driver and bindings 13.4+ when any domain is specified. Default: `None`.
    

Return type:

[tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
\[[tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")\
\[[_SMPartition_](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.SMPartition.html#torch.cuda.green_contexts.SMPartition "torch.cuda.green_contexts.SMPartition")\
, …\], [_SMPartition_](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.SMPartition.html#torch.cuda.green_contexts.SMPartition "torch.cuda.green_contexts.SMPartition")\
 | None\]

Each option can be a scalar or a sequence. All sequences must have the same nonzero length; scalars are broadcast to that length. If every option is scalar, the split has one group. An early discovery group can exhaust the SMs needed by later groups. A group with both `num_sms=0` and `backfill=True` consumes all remaining SMs and must be the last group. Returns `(partitions, remainder)`, with `None` for an empty remainder. The remainder does not inherit the requested alignment.

To subdivide a returned partition or remainder, create a [`GreenContext`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.GreenContext.html#torch.cuda.green_contexts.GreenContext "torch.cuda.green_contexts.GreenContext")
 from it and split the context’s queried [`sm_partition`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.green_contexts.GreenContext.html#torch.cuda.green_contexts.GreenContext.sm_partition "torch.cuda.green_contexts.GreenContext.sm_partition")
. CUDA drivers can reject raw split outputs as already partitioned resources. Context creation is explicit.

Children are subsets of this resource and overlap it. Siblings from this operation, including the remainder, are disjoint. Results from separate splits on the same or overlapping input resources may overlap.

Example:

\>>> sms \= SMPartition.from\_device(device\_id\=0)
\>>> (first,), rest \= sms.split(num\_sms\=4, coscheduled\_sm\_count\=2)
\>>> rest\_ctx \= GreenContext(sm\_partition\=rest)
\>>> (second,), rest \= rest\_ctx.sm\_partition.split(
...     num\_sms\=4, coscheduled\_sm\_count\=2
... )
