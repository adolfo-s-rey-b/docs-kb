SequentialLR[#](https://docs.pytorch.org/docs/2.15/generated/torch.optim.lr_scheduler.SequentialLR.html#sequentiallr "Link to this heading")

=============================================================================================================================================

_class_ torch.optim.lr\_scheduler.SequentialLR(_optimizer_, _schedulers_, _milestones_, _last\_epoch\=\-1_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/optim/lr_scheduler.py#L1082)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.optim.lr_scheduler.SequentialLR.html#torch.optim.lr_scheduler.SequentialLR "Link to this definition")

Contains a list of schedulers expected to be called sequentially during the optimization process.

Specifically, the schedulers will be called according to the milestone points, which should provide exact intervals by which each scheduler should be called at a given epoch.

Parameters:

*   **optimizer** ([_Optimizer_](https://docs.pytorch.org/docs/2.15/optim.html#torch.optim.Optimizer "torch.optim.Optimizer")
    ) – Wrapped optimizer.
    
*   **schedulers** ([_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    ) – List of chained schedulers.
    
*   **milestones** ([_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    ) – List of integers that reflects milestone points.
    
*   **last\_epoch** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    ) – The index of last epoch. Default: -1.
    

Example

\>>> \# Assuming optimizer uses lr = 0.05 for all groups
\>>> \# lr = 0.005     if epoch == 0
\>>> \# lr = 0.005     if epoch == 1
\>>> \# lr = 0.005     if epoch == 2
\>>> \# ...
\>>> \# lr = 0.05      if epoch == 20
\>>> \# lr = 0.045     if epoch == 21
\>>> \# lr = 0.0405    if epoch == 22
\>>> scheduler1 \= ConstantLR(optimizer, factor\=0.1, total\_iters\=20)
\>>> scheduler2 \= ExponentialLR(optimizer, gamma\=0.9)
\>>> scheduler \= SequentialLR(
...     optimizer,
...     schedulers\=\[scheduler1, scheduler2\],
...     milestones\=\[20\],
... )
\>>> for epoch in range(100):
\>>>     train(...)
\>>>     validate(...)
\>>>     scheduler.step()
