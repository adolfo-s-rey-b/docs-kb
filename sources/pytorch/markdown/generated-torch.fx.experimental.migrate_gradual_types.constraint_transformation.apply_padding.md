torch.fx.experimental.migrate\_gradual\_types.constraint\_transformation.apply\_padding(_e1\_var_, _e11_, _e2_, _e12_, _d2_, _d11_, _d12_, _counter_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/fx/experimental/migrate_gradual_types/constraint_transformation.py#L1115)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.fx.experimental.migrate_gradual_types.constraint_transformation.apply_padding.html#torch.fx.experimental.migrate_gradual_types.constraint_transformation.apply_padding "Link to this definition")

We are considering the possibility where one input has less dimensions than another input, so we apply padding to the broadcasted results

Parameters:

*   **e1\_var** (_TVar_) – Variable representing the first input where padding will be
    
*   **e11** (_BinConstraintT_) – constraint of the form e11 = Tensortype\[d1, …, dn\]
    
*   **e2** (_BinConstraintT_) – constraint of the form e2 = Tensortype\[d1, …, dn\]
    
*   **e12** (_BinConstraintT_) – constraint of the form e11 = Tensortype\[d1, …, dn\]
    
*   **d2** ([_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    _\[__DVar__\]_) – Tensor variables for the second input
    
*   **d11** ([_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    _\[__DVar__\]_) – Tensor variables for the broadcasted first input
    
*   **d12** ([_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    _\[__DVar__\]_) – Tensor variables for the broadcasted second input
    
*   **counter** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    ) – variable tracking
    

Return type:

[tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
\[_Constraint_, [int](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
\]

Returns: A new constraint whose goal is to apply padding to the broadcasted result
