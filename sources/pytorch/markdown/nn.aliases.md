Strip the prefix in state\_dict in place, if any.

Given a state\_dict from a DP/DDP model, a local model can load it by applying consume\_prefix\_in\_state\_dict\_if\_present(state\_dict, “module.”) before calling [`torch.nn.Module.load_state_dict()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Module.html#torch.nn.Module.load_state_dict "torch.nn.Module.load_state_dict")

*   **state\_dict** (_OrderedDict_) – a state-dict to be loaded to the model.

    ) – prefix.
