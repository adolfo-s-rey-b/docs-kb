torch.nn.functional.silu[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.silu.html#torch-nn-functional-silu "Link to this heading")

========================================================================================================================================================

torch.nn.functional.silu(_input_, _inplace\=False_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/functional.py#L2429)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.silu.html#torch.nn.functional.silu "Link to this definition")

Apply the Sigmoid Linear Unit (SiLU) function, element-wise.

The SiLU function is also known as the swish function.

silu(x)\=x∗σ(x),where σ(x) is the logistic sigmoid.\\text{silu}(x) = x \* \\sigma(x), \\text{where } \\sigma(x) \\text{ is the logistic sigmoid.} silu(x)\=x∗σ(x),where σ(x) is the logistic sigmoid.

Note

See [Gaussian Error Linear Units (GELUs)](https://arxiv.org/abs/1606.08415)
 where the SiLU (Sigmoid Linear Unit) was originally coined, and see [Sigmoid-Weighted Linear Units for Neural Network Function Approximation in Reinforcement Learning](https://arxiv.org/abs/1702.03118)
 and [Swish: a Self-Gated Activation Function](https://arxiv.org/abs/1710.05941v1)
 where the SiLU was experimented with later.

See [`SiLU`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.SiLU.html#torch.nn.SiLU "torch.nn.SiLU")
 for more details.

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
