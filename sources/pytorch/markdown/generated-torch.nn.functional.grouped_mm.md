torch.nn.functional.grouped\_mm[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.grouped_mm.html#torch-nn-functional-grouped-mm "Link to this heading")

===========================================================================================================================================================================

torch.nn.functional.grouped\_mm(_mat\_a_, _mat\_b_, _\*_, _offs\=None_, _bias\=None_, _out\_dtype\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/functional.py#L7170)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.grouped_mm.html#torch.nn.functional.grouped_mm "Link to this definition")

Computes a grouped matrix multiply that shares weight shapes across experts but allows jagged token counts per expert, which is common in Mixture-of-Experts (MoE) layers. Both `mat_a` and `mat_b` must be 2D or 3D tensors that already satisfy the physical layout restrictions of grouped GEMM kernels (e.g., row-major `mat_a` and column-major `mat_b` for FP8 inputs). Inputs are currently expected to be `torch.bfloat16` values on CUDA devices with SM≥80SM \\ge 80SM≥80.

Parameters:

*   **mat\_a** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Left operand. When 2D, its leading dimension is sliced into groups according to `offs`. When 3D, its first dimension enumerates the groups directly and `offs` must be `None`.
    
*   **mat\_b** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Right operand. When both operands are 2D (e.g., MoE weight-gradient updates), the trailing dimension of `mat_a` and the leading dimension of `mat_b` are partitioned according to the same `offs` tensor. For the common forward pass (`out = input @ weight.T`) `mat_b` is 3D with shape `(num_groups, K, N)`. If expert weights are stored in the standard `nn.Linear` layout `(num_groups, N, K)`, pass `weight.transpose(-2, -1)` as `mat_b`.
    
*   **offs** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
     _|_ _None_) – Optional 1D tensor of monotonically increasing `int32` offsets that delimit the jagged dimension of any 2D operand. `offs[i]` marks the end of group `i` and `offs[-1]` must be strictly less than the total length of that operand’s sliced dimension; elements beyond `offs[-1]` are ignored.
    
*   **bias** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
     _|_ _None_) – Optional tensor that is added to the grouped outputs. Bias is not jagged and must be broadcastable to the result shape of each group.
    
*   **out\_dtype** ([_dtype_](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.dtype "torch.dtype")
     _|_ _None_) – Optional dtype that controls the accumulation/output dtype. Passing `torch.float32` accumulates BF16 inputs in FP32 while keeping the grouped GEMM API non-differentiable.
    

Returns:

A tensor containing the concatenated results of each per-group GEMM with shape inferred from the operands and `offs`.

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
