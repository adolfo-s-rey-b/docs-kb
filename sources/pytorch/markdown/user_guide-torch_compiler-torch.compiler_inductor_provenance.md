TorchInductor and AOTInductor Provenance Tracking[#](https://docs.pytorch.org/docs/2.15/user_guide/torch_compiler/torch.compiler_inductor_provenance.html#torchinductor-and-aotinductor-provenance-tracking "Link to this heading")

====================================================================================================================================================================================================================================

Created On: May 06, 2026 | Last Updated On: May 06, 2026

This section describes how to use the provenance tracking feature for TorchInductor and AOTInductor in `tlparse`. Provenance tracking helps you visualize the relationships between the input GraphModule to (AOT)Inductor and the optimized code generated. This feature allows you to trace how your original operations are transformed during compilation.

Some example screenshots of the provenance tracking tool are shown below. The tool visualizes the mapping between nodes in the input graph (panel 1), the post grad graph (panel 2), and the Inductor generated code (panel 3).

The **bolded** lines represent nodes/kernels covered by the current provenance tracing functionality. We currently cover triton kernels, cpp kernels, and combo kernels. The yellow highlighting shows the provenance of the nodes/kernels.

Example screenshot of the provenance tracking tool for TorchInductor:

![../../_images/provenance_jit_inductor.png](https://docs.pytorch.org/docs/2.15/_images/provenance_jit_inductor.png)

Example screenshot of the provenance tracking tool for AOTInductor:

![../../_images/provenance_aot_inductor.png](https://docs.pytorch.org/docs/2.15/_images/provenance_aot_inductor.png)

Using the Provenance Tracking Highlighter[#](https://docs.pytorch.org/docs/2.15/user_guide/torch_compiler/torch.compiler_inductor_provenance.html#using-the-provenance-tracking-highlighter "Link to this heading")

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Follow these steps to enable and use provenance tracking in your PyTorch project:

1.  Install `tlparse` by `cargo install tlparse`. If you don’t have `cargo`, see [The Cargo Book](https://doc.rust-lang.org/cargo/getting-started/installation.html)
     for instructions to install.
    
2.  Run your program with required flags:
    
    TORCH\_TRACE\=~/my\_trace\_log\_dir INDUCTOR\_PROVENANCE\=1 python your\_program.py
    
    Copy to clipboard
    
    This will generate a log file in `~/my_trace_log_dir`. The log file will be used by tlparse to generate the provenance tracking highlighter.
    
3.  Run `tlparse` on the log with `--inductor-provenance` flag. For example:
    
    tlparse log\_file\_name.log \--inductor-provenance
    
    Copy to clipboard
    
    *   Even if you don’t add the `--inductor-provenance` flag, you should be able to see the mapping in json format in the `inductor_provenance_tracking_node_mappings_<number>.json` file in the `index.html` tlparse output.
        
    *   Run `tlpare` directly on the log file. It might not work if you run “tlparse parse <folder\_name> –inductor-provenance”.
        
    *   The `tlparse` artifacts used by the provenance tracking highlighter are:
        
        *   `before_pre_grad_graph.txt`
            
        *   `after_post_grad_graph.txt`
            
        *   `inductor_aot_wrapper_code.txt`
            
        *   `inductor_output_code.txt`
            
        *   `inductor_provenance_tracking_node_mappings.json`
            

After running `tlparse <file_name> --inductor-provenance`, you should see an additional “Provenance Tracking” section in the tlparse output. Clicking into the link(s) to access the provenance tracking tool. For a demo, see: https://github.com/pytorch/tlparse/pull/93

![../../_images/index.png](https://docs.pytorch.org/docs/2.15/_images/index.png)

Source code corresponding to each Inductor kernel[#](https://docs.pytorch.org/docs/2.15/user_guide/torch_compiler/torch.compiler_inductor_provenance.html#source-code-corresponding-to-each-inductor-kernel "Link to this heading")

------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

With `INDUCTOR_PROVENANCE=1`, you can also view the source code corresponding to each Inductor kernel in tlparse. To access it, click the “readable\_html” link next to “inductor\_provenance\_tracking\_kernel\_stack\_traces.json” in the tlparse output.

![../../_images/index_2.png](https://docs.pytorch.org/docs/2.15/_images/index_2.png)

Below are some example screenshots. The `:1` and `:467` suffixes at the end of the kernel names are used to distinguish different calls to the same kernel. We refer to these suffixes as debug handles.

![../../_images/kernel_source_1.png](https://docs.pytorch.org/docs/2.15/_images/kernel_source_1.png) ![../../_images/kernel_source_2.png](https://docs.pytorch.org/docs/2.15/_images/kernel_source_2.png)

You can also find the debug handle in the comments within the kernel source code.

![../../_images/kernel_source_3.png](https://docs.pytorch.org/docs/2.15/_images/kernel_source_3.png)
