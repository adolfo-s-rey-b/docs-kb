torch.fx.experimental.migrate\_gradual\_types.constraint\_transformation.gen\_all\_reshape\_possibilities(_list\_of\_dims_, _target_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/fx/experimental/migrate_gradual_types/constraint_transformation.py#L1023)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.fx.experimental.migrate_gradual_types.constraint_transformation.gen_all_reshape_possibilities.html#torch.fx.experimental.migrate_gradual_types.constraint_transformation.gen_all_reshape_possibilities "Link to this definition")

Consider all possibilities what the input dimensions could be (number or dynamic) Then generate the appropriate constraints using multiplication or mod depending on the possibility The possibilities we consider here are the cross product of being equal to dyn or not equal to dyn for the input. Target is fixed because at most one dimension could be dyn. We have different cases for this.

Parameters:

*   **list\_of\_dims** ([_list_](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
    _\[__DVar__\]_) – The input list of dimensions
    
*   **target** ([_Sequence_](https://docs.python.org/3/library/collections.abc.html#collections.abc.Sequence "(in Python v3.15)")
    _\[__DVar_ _|_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
     _|_ _\_DynType__\]_) – The tensor we want to reshape to
    

Return type:

_Constraint_

Returns: A disjunction of transformed reshape constraints
