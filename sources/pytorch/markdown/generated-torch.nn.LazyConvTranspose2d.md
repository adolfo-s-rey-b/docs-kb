==================================================================================================================================================

_class_ torch.nn.LazyConvTranspose2d(_out\_channels_, _kernel\_size_, _stride\=1_, _padding\=0_, _output\_padding\=0_, _groups\=1_, _bias\=True_, _dilation\=1_, _padding\_mode\='zeros'_, _device\=None_, _dtype\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/modules/conv.py#L1781)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.LazyConvTranspose2d.html#torch.nn.LazyConvTranspose2d "Link to this definition")

A [`torch.nn.ConvTranspose2d`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ConvTranspose2d.html#torch.nn.ConvTranspose2d "torch.nn.ConvTranspose2d")
 module with lazy initialization of the `in_channels` argument.

The `in_channels` argument of the [`ConvTranspose2d`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ConvTranspose2d.html#torch.nn.ConvTranspose2d "torch.nn.ConvTranspose2d")
 is inferred from the `input.size(1)`. The attributes that will be lazily initialized are weight and bias.

Check the [`torch.nn.modules.lazy.LazyModuleMixin`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.modules.lazy.LazyModuleMixin.html#torch.nn.modules.lazy.LazyModuleMixin "torch.nn.modules.lazy.LazyModuleMixin")
 for further documentation on lazy modules and their limitations.

Parameters:

*   **out\_channels** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    ) – Number of channels produced by the convolution
    
*   **kernel\_size** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ [_tuple_](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
    ) – Size of the convolving kernel
    
*   **stride** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ [_tuple_](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
    _,_ _optional_) – Stride of the convolution. Default: 1
    
*   **padding** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ [_tuple_](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
    _,_ _optional_) – `dilation * (kernel_size - 1) - padding` zero-padding will be added to both sides of each dimension in the input. Default: 0
    
*   **output\_padding** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ [_tuple_](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
    _,_ _optional_) – Additional size added to one side of each dimension in the output shape. Default: 0
    
*   **groups** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – Number of blocked connections from input channels to output channels. Default: 1
    
*   **bias** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – If `True`, adds a learnable bias to the output. Default: `True`
    
*   **dilation** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")

    _,_ _optional_) – Spacing between kernel elements. Default: 1
