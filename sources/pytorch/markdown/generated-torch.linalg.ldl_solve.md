torch.linalg.ldl\_solve[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.ldl_solve.html#torch-linalg-ldl-solve "Link to this heading")

===================================================================================================================================================

torch.linalg.ldl\_solve(_LD_, _pivots_, _B_, _\*_, _hermitian\=False_, _out\=None_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/linalg/__init__.py#L1032)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.ldl_solve.html#torch.linalg.ldl_solve "Link to this definition")

Computes the solution of a system of linear equations using the LDL factorization.

`LD` and `pivots` are the compact representation of the LDL factorization and are expected to be computed by [`torch.linalg.ldl_factor_ex()`](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.ldl_factor_ex.html#torch.linalg.ldl_factor_ex "torch.linalg.ldl_factor_ex")
. `hermitian` argument to this function should be the same as the corresponding arguments in [`torch.linalg.ldl_factor_ex()`](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.ldl_factor_ex.html#torch.linalg.ldl_factor_ex "torch.linalg.ldl_factor_ex")
.

Supports input of float, double, cfloat and cdouble dtypes. Also supports batches of matrices, and if `A` is a batch of matrices then the output has the same batch dimensions.

Warning

This function is “experimental” and it may change in a future PyTorch release.

Parameters:

*   **LD** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – the n times n matrix or the batch of such matrices of size (\*, n, n) where \* is one or more batch dimensions.
    
*   **pivots** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – the pivots corresponding to the LDL factorization of `LD`.
    
*   **B** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – right-hand side tensor of shape (\*, n, k).
    

Keyword Arguments:

*   **hermitian** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – whether to consider the decomposed matrix to be Hermitian or symmetric. For real-valued matrices, this switch has no effect. Default: False.
    
*   **out** ([_tuple_](https://docs.python.org/3/builtins/stdtypes.html#tuple "(in Python v3.15)")
    _,_ _optional_) – output tensor. B may be passed as out and the result is computed in-place on B. Ignored if None. Default: None.
    

Examples:

\>>> A \= torch.randn(2, 3, 3)
\>>> A \= A @ A.mT \# make symmetric
\>>> LD, pivots, info \= torch.linalg.ldl\_factor\_ex(A)
\>>> B \= torch.randn(2, 3, 4)
\>>> X \= torch.linalg.ldl\_solve(LD, pivots, B)
\>>> torch.linalg.norm(A @ X \- B)
\>>> tensor(0.0001)
