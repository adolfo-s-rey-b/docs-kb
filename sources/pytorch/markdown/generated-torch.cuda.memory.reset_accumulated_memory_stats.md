torch.cuda.memory.reset\_accumulated\_memory\_stats(_device\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/cuda/memory.py#L362)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.memory.reset_accumulated_memory_stats.html#torch.cuda.memory.reset_accumulated_memory_stats "Link to this definition")

Reset the “accumulated” (historical) stats tracked by the CUDA memory allocator.

See `memory_stats()` for details. Accumulated stats correspond to the “allocated” and “freed” keys in each individual stat dict, as well as “num\_alloc\_retries” and “num\_ooms”.

Parameters:

**device** ([_torch.device_](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.device "torch.device")
 _or_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
_,_ _optional_) – selected device. Returns statistic for the current device, given by [`current_device()`](https://docs.pytorch.org/docs/2.15/generated/torch.cuda.current_device.html#torch.cuda.current_device "torch.cuda.current_device")
, if `device` is `None` (default).

Note

See [Memory management](https://docs.pytorch.org/docs/2.15/notes/cuda.html#cuda-memory-management)
 for more details about GPU memory management.
