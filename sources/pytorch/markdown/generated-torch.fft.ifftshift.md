torch.fft.ifftshift[#](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifftshift.html#torch-fft-ifftshift "Link to this heading")

=========================================================================================================================================

torch.fft.ifftshift(_input_, _dim\=None_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/fft/__init__.py#L1414)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifftshift.html#torch.fft.ifftshift "Link to this definition")

Inverse of [`fftshift()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.fftshift.html#torch.fft.fftshift "torch.fft.fftshift")
.

Parameters:

*   **input** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – the tensor in FFT order
    
*   **dim** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _Tuple__\[_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _\]__,_ _optional_) – The dimensions to rearrange. Only dimensions specified here will be rearranged, any other dimensions will be left in their original order. Default: All dimensions of `input`.
    

Example

\>>> f \= torch.fft.fftfreq(5)
\>>> f
tensor(\[ 0.0000,  0.2000,  0.4000, -0.4000, -0.2000\])

Copy to clipboard

A round-trip through [`fftshift()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.fftshift.html#torch.fft.fftshift "torch.fft.fftshift")
 and [`ifftshift()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifftshift.html#torch.fft.ifftshift "torch.fft.ifftshift")
 gives the same result:

\>>> shifted \= torch.fft.fftshift(f)
\>>> torch.fft.ifftshift(shifted)
tensor(\[ 0.0000,  0.2000,  0.4000, -0.4000, -0.2000\])
