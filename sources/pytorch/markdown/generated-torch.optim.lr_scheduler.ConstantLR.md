ConstantLR[#](https://docs.pytorch.org/docs/2.15/generated/torch.optim.lr_scheduler.ConstantLR.html#constantlr "Link to this heading")

=======================================================================================================================================

_class_ torch.optim.lr\_scheduler.ConstantLR(_optimizer_, _factor\=0.3333333333333333_, _total\_iters\=5_, _last\_epoch\=\-1_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/optim/lr_scheduler.py#L773)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.optim.lr_scheduler.ConstantLR.html#torch.optim.lr_scheduler.ConstantLR "Link to this definition")

Multiply the learning rate of each parameter group by a small constant factor.

The multiplication is done until the number of epoch reaches a pre-defined milestone: total\_iters. Notice that such multiplication of the small constant factor can happen simultaneously with other changes to the learning rate from outside this scheduler. When last\_epoch=-1, sets initial lr as lr.

Parameters:

*   **optimizer** ([_Optimizer_](https://docs.pytorch.org/docs/2.15/optim.html#torch.optim.Optimizer "torch.optim.Optimizer")
    ) – Wrapped optimizer.
    
*   **factor** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    ) – The number we multiply learning rate until the milestone. Default: 1./3.
    
*   **total\_iters** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    ) – The number of steps that the scheduler multiplies the learning rate by the factor. Default: 5.
    
*   **last\_epoch** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    ) – The index of the last epoch. Default: -1.
    

Example

\>>> \# Assuming optimizer uses lr = 0.05 for all groups
\>>> \# lr = 0.025   if epoch == 0
\>>> \# lr = 0.025   if epoch == 1
\>>> \# lr = 0.025   if epoch == 2
\>>> \# lr = 0.025   if epoch == 3
\>>> \# ...
\>>> \# lr = 0.05    if epoch >= 40
\>>> scheduler \= ConstantLR(optimizer, factor\=0.5, total\_iters\=40)
\>>> for epoch in range(100):
\>>>     train(...)
\>>>     validate(...)
\>>>     scheduler.step()

[#](https://docs.pytorch.org/docs/2.15/generated/torch.optim.lr_scheduler.ConstantLR.html#torch.optim.lr_scheduler.ConstantLR.get_lr "Link to this definition")

Compute the next learning rate for each of the optimizer’s `param_groups`.

When `last_epoch` is 0, this method scales the `group["lr"]`s in each of the optimizer’s `param_groups` by `factor`. Once `total_iters` is reached, it undoes this, scaling by `1 / factor`.

Returns:

A [`list`](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
 of learning rates for each of the optimizer’s `param_groups` with the same types as their current `group["lr"]`s.

Return type:

[list](https://docs.python.org/3/builtins/stdtypes.html#list "(in Python v3.15)")
\[[float](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")\
 | [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")\
\]

Note

If you’re trying to inspect the most recent learning rate, use [`get_last_lr()`](https://docs.pytorch.org/docs/2.15/generated/torch.optim.lr_scheduler.ConstantLR.html#torch.optim.lr_scheduler.ConstantLR.get_last_lr "torch.optim.lr_scheduler.ConstantLR.get_last_lr")
 instead.

Note

The returned [`Tensor`](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
s are copies, and never alias the optimizer’s `group["lr"]`s.
