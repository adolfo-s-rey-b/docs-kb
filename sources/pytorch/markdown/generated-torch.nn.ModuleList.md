_class_ torch.nn.ModuleList(_modules\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/modules/container.py#L341)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ModuleList.html#torch.nn.ModuleList "Link to this definition")

Holds submodules in a list.

[`ModuleList`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ModuleList.html#torch.nn.ModuleList "torch.nn.ModuleList")
 can be indexed like a regular Python list, but modules it contains are properly registered, and will be visible by all [`Module`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Module.html#torch.nn.Module "torch.nn.Module")
 methods.

Parameters:

**modules** (_iterable__,_ _optional_) – an iterable of modules to add

Example:

class MyModule(nn.Module):
    def \_\_init\_\_(self) \-> None:
        super().\_\_init\_\_()
        self.linears \= nn.ModuleList(\[nn.Linear(10, 10) for i in range(10)\])

    def forward(self, x):
        \# ModuleList can act as an iterable, or be indexed using ints
        for i, l in enumerate(self.linears):
            x \= self.linears\[i // 2\](x) + l(x)
        return x
