Computes the general cosine window.

The general cosine window is defined as follows:

wn\=∑i\=0M−1(−1)iaicos⁡(2πinM−1)w\_n = \\sum^{M-1}\_{i=0} (-1)^i a\_i \\cos{ \\left( \\frac{2 \\pi i n}{M - 1}\\right)} wn​\=i\=0∑M−1​(−1)iai​cos(M−12πin​)

The window is normalized to 1 (maximum value is 1). However, the 1 doesn’t appear if `M` is even and `sym` is True.

Parameters:

**M** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
) – the length of the window. In other words, the number of points of the returned window.

Keyword Arguments:

*   **a** (_Iterable_) – the coefficients associated to each of the cosine functions.
    
*   **sym** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – If False, returns a periodic window suitable for use in spectral analysis. If True, returns a symmetric window suitable for use in filter design. Default: True.
    
*   **dtype** ([`torch.dtype`](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.dtype "torch.dtype")
    , optional) – the desired data type of returned tensor. Default: if `None`, uses a global default (see [`torch.set_default_dtype()`](https://docs.pytorch.org/docs/2.15/generated/torch.set_default_dtype.html#torch.set_default_dtype "torch.set_default_dtype")
    ).
    
*   **layout** ([`torch.layout`](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.layout "torch.layout")
    , optional) – the desired layout of returned Tensor. Default: `torch.strided`.
    
*   **device** ([`torch.device`](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.device "torch.device")
    , optional) – the desired device of returned tensor. Default: if `None`, uses the current device for the default tensor type (see [`torch.set_default_device()`](https://docs.pytorch.org/docs/2.15/generated/torch.set_default_device.html#torch.set_default_device "torch.set_default_device")
    ). `device` will be the CPU for CPU tensor types and the current CUDA device for CUDA tensor types.
    
*   **requires\_grad** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – If autograd should record operations on the returned tensor. Default: `False`.
    

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")

Examples:

\>>> \# Generates a symmetric general cosine window with 3 coefficients.
\>>> torch.signal.windows.general\_cosine(10, a\=\[0.46, 0.23, 0.31\], sym\=True)
tensor(\[0.5400, 0.3376, 0.1288, 0.4200, 0.9136, 0.9136, 0.4200, 0.1288, 0.3376, 0.5400\])

\>>> \# Generates a periodic general cosine window with 2 coefficients.
\>>> torch.signal.windows.general\_cosine(10, a\=\[0.5, 1 \- 0.5\], sym\=False)
tensor(\[0.0000, 0.0955, 0.3455, 0.6545, 0.9045, 1.0000, 0.9045, 0.6545, 0.3455, 0.0955\])
