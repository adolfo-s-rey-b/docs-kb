_class_ torch.xpu.Stream(_device\=None_, _priority\=0_, _\*\*kwargs_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/xpu/streams.py#L17)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.xpu.Stream_class.html#torch.xpu.Stream "Link to this definition")

Wrapper around a XPU stream.

A XPU stream is a linear sequence of execution that belongs to a specific device, independent from other streams. It supports with statement as a context manager to ensure the operators within the with block are running on the corresponding stream.

Parameters:

*   **device** ([_torch.device_](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.device "torch.device")
     _or_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – a device on which to allocate the stream. If [`device`](https://docs.pytorch.org/docs/2.15/generated/torch.xpu.device.html#torch.xpu.device "torch.xpu.device")
     is `None` (default) or a negative integer, this will use the current device.
    
*   **priority** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – priority of the stream, which can be positive, 0, or negative. A lower number indicates a higher priority. By default, the priority is set to 0. If the value falls outside of the allowed priority range, it will automatically be mapped to the nearest valid priority (lowest for large positive numbers or highest for large negative numbers).
