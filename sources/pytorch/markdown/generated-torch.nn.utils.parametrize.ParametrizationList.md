ParametrizationList[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.parametrize.ParametrizationList.html#parametrizationlist "Link to this heading")

====================================================================================================================================================================

_class_ torch.nn.utils.parametrize.ParametrizationList(_modules_, _original_, _unsafe\=False_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/parametrize.py#L95)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.parametrize.ParametrizationList.html#torch.nn.utils.parametrize.ParametrizationList "Link to this definition")

A sequential container that holds and manages the original parameters or buffers of a parametrized [`torch.nn.Module`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Module.html#torch.nn.Module "torch.nn.Module")
.

It is the type of `module.parametrizations[tensor_name]` when `module[tensor_name]` has been parametrized with [`register_parametrization()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.parametrize.register_parametrization.html#torch.nn.utils.parametrize.register_parametrization "torch.nn.utils.parametrize.register_parametrization")
.

If the first registered parametrization has a `right_inverse` that returns one tensor or does not have a `right_inverse` (in which case we assume that `right_inverse` is the identity), it will hold the tensor under the name `original`. If it has a `right_inverse` that returns more than one tensor, these will be registered as `original0`, `original1`, …

Warning

This class is used internally by [`register_parametrization()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.parametrize.register_parametrization.html#torch.nn.utils.parametrize.register_parametrization "torch.nn.utils.parametrize.register_parametrization")
. It is documented here for completeness. It shall not be instantiated by the user.

Parameters:

*   **modules** (_sequence_) – sequence of modules representing the parametrizations
    
*   **original** ([_Parameter_](https://docs.pytorch.org/docs/2.15/generated/torch.nn.parameter.Parameter.html#torch.nn.parameter.Parameter "torch.nn.parameter.Parameter")
     _or_ [_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – parameter or buffer that is parametrized
    
*   **unsafe** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    ) – a boolean flag that denotes whether the parametrization may change the dtype and shape of the tensor. Default: False Warning: the parametrization is not checked for consistency upon registration. Enable this flag at your own risk.
    

right\_inverse(_value_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/parametrize.py#L255)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.parametrize.ParametrizationList.html#torch.nn.utils.parametrize.ParametrizationList.right_inverse "Link to this definition")

Call the `right_inverse` methods of the parametrizations in the inverse registration order.

Then, it stores the result in `self.original` if `right_inverse` outputs one tensor or in `self.original0`, `self.original1`, … if it outputs several.

Parameters:

**value** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
) – Value to which initialize the module
