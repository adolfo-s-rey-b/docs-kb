[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pad_packed_sequence.html#torch.nn.utils.rnn.pad_packed_sequence "Link to this definition")

Pad a packed batch of variable length sequences.

It is an inverse operation to [`pack_padded_sequence()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pack_padded_sequence.html#torch.nn.utils.rnn.pack_padded_sequence "torch.nn.utils.rnn.pack_padded_sequence")
.

The returned Tensor’s data will be of size `T x B x *` (if `batch_first` is `False`) or `B x T x *` (if `batch_first` is `True`) , where `T` is the length of the longest sequence and `B` is the batch size.

Example

\>>> from torch.nn.utils.rnn import pack\_padded\_sequence, pad\_packed\_sequence
\>>> seq \= torch.tensor(\[\[1, 2, 0\], \[3, 0, 0\], \[4, 5, 6\]\])
\>>> lens \= \[2, 1, 3\]
\>>> packed \= pack\_padded\_sequence(
...     seq, lens, batch\_first\=True, enforce\_sorted\=False
... )
\>>> packed
PackedSequence(data=tensor(\[4, 1, 3, 5, 2, 6\]), batch\_sizes=tensor(\[3, 2, 1\]),
               sorted\_indices=tensor(\[2, 0, 1\]), unsorted\_indices=tensor(\[1, 2, 0\]))
\>>> seq\_unpacked, lens\_unpacked \= pad\_packed\_sequence(packed, batch\_first\=True)
\>>> seq\_unpacked
tensor(\[\[1, 2, 0\],\
        \[3, 0, 0\],\
        \[4, 5, 6\]\])
\>>> lens\_unpacked
tensor(\[2, 1, 3\])

Copy to clipboard

Note

`total_length` is useful to implement the `pack sequence -> recurrent network -> unpack sequence` pattern in a [`Module`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Module.html#torch.nn.Module "torch.nn.Module")
 wrapped in [`DataParallel`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.DataParallel.html#torch.nn.DataParallel "torch.nn.DataParallel")
. See [this FAQ section](https://docs.pytorch.org/docs/2.15/notes/faq.html#pack-rnn-unpack-with-data-parallelism)
 for details.

Parameters:

*   **sequence** ([_PackedSequence_](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
    ) – batch to pad
    
*   **batch\_first** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – if `True`, the output will be in `B x T x *` format, `T x B x *` otherwise.
    
*   **padding\_value** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    _,_ _optional_) – values for padded elements.
    
*   **total\_length** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – if not `None`, the output will be padded to have length `total_length`. This method will throw [`ValueError`](https://docs.python.org/3/builtins/exceptions.html#ValueError "(in Python v3.15)")
     if `total_length` is less than the max sequence length in `sequence`.
    

Returns:

Tuple of Tensor containing the padded sequence, and a Tensor containing the list of lengths of each sequence in the batch. Batch elements will be re-ordered as they were ordered originally when the batch was passed to `pack_padded_sequence` or `pack_sequence`.
