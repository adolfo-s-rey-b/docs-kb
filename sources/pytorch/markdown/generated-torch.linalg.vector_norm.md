torch.linalg.vector\_norm[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.vector_norm.html#torch-linalg-vector-norm "Link to this heading")

=========================================================================================================================================================

torch.linalg.vector\_norm(_x_, _ord\=2_, _dim\=None_, _keepdim\=False_, _\*_, _dtype\=None_, _out\=None_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/linalg/__init__.py#L1491)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.vector_norm.html#torch.linalg.vector_norm "Link to this definition")

Computes a vector norm.

If `x` is complex valued, it computes the norm of `x`.abs()

Supports input of float, double, cfloat and cdouble dtypes.

This function does not necessarily treat multidimensional `x` as a batch of vectors, instead:

*   If `dim`\= None, `x` will be flattened before the norm is computed.
    
*   If `dim` is an int or a tuple, the norm will be computed over these dimensions and the other dimensions will be treated as batch dimensions.
    

This behavior is for consistency with [`torch.linalg.norm()`](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.norm.html#torch.linalg.norm "torch.linalg.norm")
.

`ord` defines the vector norm that is computed. The following norms are supported:

| `ord` | vector norm |
| --- | --- |
| 2 (default) | 2\-norm (see below) |
| inf | max(abs(x)) |
| \-inf | min(abs(x)) |
| 0   | sum(x != 0) |
| other int or float | sum(abs(x)^{ord})^{(1 / ord)} |

where inf refers to float(‘inf’), NumPy’s inf object, or any equivalent object.

`dtype` may be used to perform the computation in a more precise dtype. It is semantically equivalent to calling `linalg.vector_norm(x.to(dtype))` but it is faster in some cases.

See also

[`torch.linalg.matrix_norm()`](https://docs.pytorch.org/docs/2.15/generated/torch.linalg.matrix_norm.html#torch.linalg.matrix_norm "torch.linalg.matrix_norm")
 computes a matrix norm.

Parameters:

*   **x** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – tensor, flattened by default, but this behavior can be controlled using `dim`. (Note: the keyword argument input can also be used as an alias for x.)
    
*   **ord** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ [_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    _,_ _inf__,_ _\-inf__,_ _optional_) – order of norm. Default: 2
    
*   **dim** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _Tuple__\[_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _\]__,_ _optional_) – dimensions over which to compute the norm. See above for the behavior when `dim`\= None. Default: None
    
*   **keepdim** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – If set to True, the reduced dimensions are retained in the result as dimensions with size one. Default: False
    

Keyword Arguments:

*   **out** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    _,_ _optional_) – output tensor. Ignored if None. Default: None.
    
*   **dtype** ([`torch.dtype`](https://docs.pytorch.org/docs/2.15/tensor_attributes.html#torch.dtype "torch.dtype")
    , optional) – If specified `x` is cast to `dtype` prior to doing the accumulation. Default: None
    

Returns:

A real-valued tensor, even when `x` is complex.

Examples:

\>>> from torch import linalg as LA
\>>> a \= torch.arange(9, dtype\=torch.float) \- 4
\>>> a
tensor(\[-4., -3., -2., -1.,  0.,  1.,  2.,  3.,  4.\])
\>>> B \= a.reshape((3, 3))
\>>> B
tensor(\[\[-4., -3., -2.\],\
        \[-1.,  0.,  1.\],\
        \[ 2.,  3.,  4.\]\])
\>>> LA.vector\_norm(a, ord\=3.5)
tensor(5.4345)
\>>> LA.vector\_norm(B, ord\=3.5)
tensor(5.4345)
