PackedSequence[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#packedsequence "Link to this heading")

=============================================================================================================================================

_class_ torch.nn.utils.rnn.PackedSequence(_data_, _batch\_sizes\=None_, _sorted\_indices\=None_, _unsorted\_indices\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/utils/rnn.py#L39)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "Link to this definition")

Holds the data and list of [`batch_sizes`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence.batch_sizes "torch.nn.utils.rnn.PackedSequence.batch_sizes")
 of a packed sequence.

All RNN modules accept packed sequences as inputs.

Note

Instances of this class should never be created manually. They are meant to be instantiated by functions like [`pack_padded_sequence()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pack_padded_sequence.html#torch.nn.utils.rnn.pack_padded_sequence "torch.nn.utils.rnn.pack_padded_sequence")
.

Batch sizes represent the number of elements at each sequence step in the batch, not the varying sequence lengths passed to [`pack_padded_sequence()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.pack_padded_sequence.html#torch.nn.utils.rnn.pack_padded_sequence "torch.nn.utils.rnn.pack_padded_sequence")
. For instance, given data `abc` and `x` the [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
 would contain data `axbc` with `batch_sizes=[2,1,1]`.

Variables:

*   **data** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Tensor containing packed sequence
    
*   **batch\_sizes** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – Tensor of integers holding information about the batch size at each sequence step
    
*   **sorted\_indices** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    _,_ _optional_) – Tensor of integers holding how this [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
     is constructed from sequences.
    
*   **unsorted\_indices** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    _,_ _optional_) – Tensor of integers holding how this to recover the original sequences with correct order.
    

Return type:

[_Self_](https://docs.python.org/3/library/typing.html#typing.Self "(in Python v3.15)")

Note

[`data`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence.data "torch.nn.utils.rnn.PackedSequence.data")
 can be on arbitrary device and of arbitrary dtype. [`sorted_indices`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence.sorted_indices "torch.nn.utils.rnn.PackedSequence.sorted_indices")
 and [`unsorted_indices`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence.unsorted_indices "torch.nn.utils.rnn.PackedSequence.unsorted_indices")
 must be `torch.int64` tensors on the same device as [`data`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence.data "torch.nn.utils.rnn.PackedSequence.data")
.

However, [`batch_sizes`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence.batch_sizes "torch.nn.utils.rnn.PackedSequence.batch_sizes")
 should always be a CPU `torch.int64` tensor.

This invariant is maintained throughout [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
 class, and all functions that construct a [`PackedSequence`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.rnn.PackedSequence.html#torch.nn.utils.rnn.PackedSequence "torch.nn.utils.rnn.PackedSequence")
 in PyTorch (i.e., they only pass in tensors conforming to this constraint).
