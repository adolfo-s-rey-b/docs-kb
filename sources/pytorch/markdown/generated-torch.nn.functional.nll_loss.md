torch.nn.functional.nll\_loss(_input_, _target_, _weight\=None_, _size\_average\=None_, _ignore\_index\=\-100_, _reduce\=None_, _reduction\='mean'_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/functional.py#L3180)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.functional.nll_loss.html#torch.nn.functional.nll_loss "Link to this definition")

Compute the negative log likelihood loss.

See [`NLLLoss`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.NLLLoss.html#torch.nn.NLLLoss "torch.nn.NLLLoss")
 for details.

Parameters:

*   **input** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – (N,C)(N, C)(N,C) where C = number of classes or (N,C,H,W)(N, C, H, W)(N,C,H,W) in case of 2D Loss, or (N,C,d1,d2,...,dK)(N, C, d\_1, d\_2, ..., d\_K)(N,C,d1​,d2​,...,dK​) where K≥1K \\geq 1K≥1 in the case of K-dimensional loss. input is expected to be log-probabilities.
    
*   **target** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – (N)(N)(N) where each value is 0≤targets\[i\]≤C−10 \\leq \\text{targets}\[i\] \\leq C-10≤targets\[i\]≤C−1, or (N,d1,d2,...,dK)(N, d\_1, d\_2, ..., d\_K)(N,d1​,d2​,...,dK​) where K≥1K \\geq 1K≥1 for K-dimensional loss.
    
*   **weight** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    _,_ _optional_) – A manual rescaling weight given to each class. If given, has to be a Tensor of size C
    
*   **size\_average** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Deprecated (see `reduction`).
    
*   **ignore\_index** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
    _,_ _optional_) – Specifies a target value that is ignored and does not contribute to the input gradient. When `size_average` is `True`, the loss is averaged over non-ignored targets. Default: -100
    
*   **reduce** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Deprecated (see `reduction`).
    
*   **reduction** ([_str_](https://docs.python.org/3/builtins/stdtypes.html#str "(in Python v3.15)")
    _,_ _optional_) – Specifies the reduction to apply to the output: `'none'` | `'mean'` | `'sum'`. `'none'`: no reduction will be applied, `'mean'`: the sum of the output will be divided by the number of elements in the output, `'sum'`: the output will be summed. Note: `size_average` and `reduce` are in the process of being deprecated, and in the meantime, specifying either of those two args will override `reduction`. Default: `'mean'`
    

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")

Example:

\>>> \# input is of size N x C = 3 x 5
\>>> input \= torch.randn(3, 5, requires\_grad\=True)
\>>> \# each element in target has to have 0 <= value < C
\>>> target \= torch.tensor(\[1, 0, 4\])
\>>> output \= F.nll\_loss(F.log\_softmax(input, dim\=1), target)
\>>> output.backward()
