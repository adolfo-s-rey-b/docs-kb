torch.fake\_quantize\_per\_channel\_affine[#](https://docs.pytorch.org/docs/2.15/generated/torch.fake_quantize_per_channel_affine.html#torch-fake-quantize-per-channel-affine "Link to this heading")

======================================================================================================================================================================================================

torch.fake\_quantize\_per\_channel\_affine(_input_, _scale_, _zero\_point_, _axis_, _quant\_min_, _quant\_max_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[#](https://docs.pytorch.org/docs/2.15/generated/torch.fake_quantize_per_channel_affine.html#torch.fake_quantize_per_channel_affine "Link to this definition")

Returns a new tensor with the data in `input` fake quantized per channel using `scale`, `zero_point`, `quant_min` and `quant_max`, across the channel specified by `axis`.

output\=(min(quant\_max,max(quant\_min,std::nearby\_int(input/scale)+zero\_point))−zero\_point)×scale\\text{output} = ( min( \\text{quant\\\_max}, max( \\text{quant\\\_min}, \\text{std::nearby\\\_int}(\\text{input} / \\text{scale}) + \\text{zero\\\_point} ) ) - \\text{zero\\\_point} ) \\times \\text{scale} output\=(min(quant\_max,max(quant\_min,std::nearby\_int(input/scale)+zero\_point))−zero\_point)×scale

Parameters:

*   **input** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – the input value(s), in `torch.float32`
    
*   **scale** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – quantization scale, per channel in `torch.float32`
    
*   **zero\_point** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – quantization zero\_point, per channel in `torch.int32` or `torch.half` or `torch.float32`
    
*   **axis** (_int32_) – channel axis
    
*   **quant\_min** (_int64_) – lower bound of the quantized domain
    
*   **quant\_max** (_int64_) – upper bound of the quantized domain
    

Returns:

A newly fake\_quantized per channel `torch.float32` tensor

Return type:

[Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")

Example:

\>>> x \= torch.randn(2, 2, 2)
\>>> x
tensor(\[\[\[-0.2525, -0.0466\],\
         \[ 0.3491, -0.2168\]\],\
\
        \[\[-0.5906,  1.6258\],\
         \[ 0.6444, -0.0542\]\]\])
\>>> scales \= (torch.randn(2) + 1) \* 0.05
\>>> scales
tensor(\[0.0475, 0.0486\])
\>>> zero\_points \= torch.zeros(2).to(torch.int32)
\>>> zero\_points
tensor(\[0, 0\])
\>>> torch.fake\_quantize\_per\_channel\_affine(x, scales, zero\_points, 1, 0, 255)
tensor(\[\[\[0.0000, 0.0000\],\
         \[0.3405, 0.0000\]\],\
\
        \[\[0.0000, 1.6134\],\
        \[0.6323, 0.0000\]\]\])
