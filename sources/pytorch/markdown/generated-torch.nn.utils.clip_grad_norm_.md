[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.clip_grad_norm_.html#torch.nn.utils.clip_grad_norm_ "Link to this definition")

Clip the gradient norm of an iterable of parameters.

The norm is computed over the norms of the individual gradients of all parameters, as if the norms of the individual gradients were concatenated into a single vector. Gradients are modified in-place.

This function is equivalent to [`torch.nn.utils.get_total_norm()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.get_total_norm.html#torch.nn.utils.get_total_norm "torch.nn.utils.get_total_norm")
 followed by [`torch.nn.utils.clip_grads_with_norm_()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.utils.clip_grads_with_norm_.html#torch.nn.utils.clip_grads_with_norm_ "torch.nn.utils.clip_grads_with_norm_")
 with the `total_norm` returned by `get_total_norm`.

Parameters:

*   **parameters** (_Iterable__\[_[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")\
    _\] or_ [_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – an iterable of Tensors or a single Tensor that will have gradients normalized
    
*   **max\_norm** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    ) – max norm of the gradients
    
*   **norm\_type** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
    _,_ _optional_) – type of the used p-norm. Can be `'inf'` for infinity norm. Default: 2.0
    
*   **error\_if\_nonfinite** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – if True, an error is thrown if the total norm of the gradients from `parameters` is `nan`, `inf`, or `-inf`. Default: False
    
*   **foreach** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – use the faster foreach-based implementation. If `None`, use the foreach implementation for CUDA and CPU native tensors and silently fall back to the slow implementation for other device types. Default: `None`
    

Returns:

Total norm of the parameter gradients (viewed as a single vector).

Return type:

[_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
