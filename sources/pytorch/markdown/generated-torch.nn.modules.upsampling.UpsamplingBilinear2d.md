_class_ torch.nn.modules.upsampling.UpsamplingBilinear2d(_size\=None_, _scale\_factor\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/modules/upsampling.py#L250)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.modules.upsampling.UpsamplingBilinear2d.html#torch.nn.modules.upsampling.UpsamplingBilinear2d "Link to this definition")

Applies a 2D bilinear upsampling to an input signal composed of several input channels.

To specify the scale, it takes either the `size` or the `scale_factor` as its constructor argument.

When `size` is given, it is the output size of the image (h, w).

Parameters:

*   **size** ([_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")
     _or_ _Tuple__\[_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _,_ [_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _\]__,_ _optional_) – output spatial sizes
    
*   **scale\_factor** ([_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")
     _or_ _Tuple__\[_[_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")\
    _,_ [_float_](https://docs.python.org/3/builtins/functions.html#float "(in Python v3.15)")\
    _\]__,_ _optional_) – multiplier for spatial size.
    

Warning

This class is deprecated in favor of `interpolate()`. It is equivalent to `nn.functional.interpolate(..., mode='bilinear', align_corners=True)`.

Shape:

*   Input: (N,C,Hin,Win)(N, C, H\_{in}, W\_{in})(N,C,Hin​,Win​)
    
*   Output: (N,C,Hout,Wout)(N, C, H\_{out}, W\_{out})(N,C,Hout​,Wout​) where
    

Hout\=⌊Hin×scale\_factor⌋H\_{out} = \\left\\lfloor H\_{in} \\times \\text{scale\\\_factor} \\right\\rfloor Hout​\=⌊Hin​×scale\_factor⌋

Wout\=⌊Win×scale\_factor⌋W\_{out} = \\left\\lfloor W\_{in} \\times \\text{scale\\\_factor} \\right\\rfloor Wout​\=⌊Win​×scale\_factor⌋

Examples:

\>>> input \= torch.arange(1, 5, dtype\=torch.float32).view(1, 1, 2, 2)
\>>> input
tensor(\[\[\[\[1., 2.\],\
          \[3., 4.\]\]\]\])

\>>> m \= nn.UpsamplingBilinear2d(scale\_factor\=2)
\>>> m(input)
tensor(\[\[\[\[1.0000, 1.3333, 1.6667, 2.0000\],\
          \[1.6667, 2.0000, 2.3333, 2.6667\],\
          \[2.3333, 2.6667, 3.0000, 3.3333\],\
          \[3.0000, 3.3333, 3.6667, 4.0000\]\]\]\])
