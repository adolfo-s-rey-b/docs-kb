L1Loss[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.modules.loss.L1Loss.html#l1loss "Link to this heading")

========================================================================================================================

_class_ torch.nn.modules.loss.L1Loss(_size\_average\=None_, _reduce\=None_, _reduction\='mean'_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/modules/loss.py#L66)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.modules.loss.L1Loss.html#torch.nn.modules.loss.L1Loss "Link to this definition")

Creates a criterion that measures the mean absolute error (MAE) between each element in the input xxx and target yyy.

The unreduced (i.e. with `reduction` set to `'none'`) loss can be described as:

ℓ(x,y)\=L\={l1,…,lN}⊤,ln\=∣xn−yn∣,\\ell(x, y) = L = \\{l\_1,\\dots,l\_N\\}^\\top, \\quad l\_n = \\left| x\_n - y\_n \\right|, ℓ(x,y)\=L\={l1​,…,lN​}⊤,ln​\=∣xn​−yn​∣,

where NNN is the batch size. If `reduction` is not `'none'` (default `'mean'`), then:

ℓ(x,y)\={mean⁡(L),if reduction\=‘mean’;sum⁡(L),if reduction\=‘sum’.\\ell(x, y) = \\begin{cases} \\operatorname{mean}(L), & \\text{if reduction} = \\text{\`mean';}\\\\ \\operatorname{sum}(L), & \\text{if reduction} = \\text{\`sum'.} \\end{cases} ℓ(x,y)\={mean(L),sum(L),​if reduction\=‘mean’;if reduction\=‘sum’.​

xxx and yyy are tensors of arbitrary shapes with a total of NNN elements each.

The sum operation still operates over all the elements, and divides by NNN.

The division by NNN can be avoided if one sets `reduction = 'sum'`.

Supports real-valued and complex-valued inputs.

Parameters:

*   **size\_average** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Deprecated (see `reduction`). By default, the losses are averaged over each loss element in the batch. Note that for some losses, there are multiple elements per sample. If the field `size_average` is set to `False`, the losses are instead summed for each minibatch. Ignored when `reduce` is `False`. Default: `True`
    
*   **reduce** ([_bool_](https://docs.python.org/3/builtins/functions.html#bool "(in Python v3.15)")
    _,_ _optional_) – Deprecated (see `reduction`). By default, the losses are averaged or summed over observations for each minibatch depending on `size_average`. When `reduce` is `False`, returns a loss per batch element instead and ignores `size_average`. Default: `True`
    
*   **reduction** ([_str_](https://docs.python.org/3/builtins/stdtypes.html#str "(in Python v3.15)")
    _,_ _optional_) – Specifies the reduction to apply to the output: `'none'` | `'mean'` | `'sum'`. `'none'`: no reduction will be applied, `'mean'`: the sum of the output will be divided by the number of elements in the output, `'sum'`: the output will be summed. Note: `size_average` and `reduce` are in the process of being deprecated, and in the meantime, specifying either of those two args will override `reduction`. Default: `'mean'`
    

Shape:

*   Input: (∗)(\*)(∗), where ∗\*∗ means any number of dimensions.
    
*   Target: (∗)(\*)(∗), same shape as the input.
    
*   Output: scalar. If `reduction` is `'none'`, then (∗)(\*)(∗), same shape as the input.
    

Examples

\>>> loss \= nn.L1Loss()
\>>> input \= torch.randn(3, 5, requires\_grad\=True)
\>>> target \= torch.randn(3, 5)
\>>> output \= loss(input, target)
\>>> output.backward()
