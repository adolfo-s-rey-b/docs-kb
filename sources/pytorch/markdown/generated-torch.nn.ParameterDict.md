ParameterDict[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ParameterDict.html#parameterdict "Link to this heading")

================================================================================================================================

_class_ torch.nn.ParameterDict(_parameters\=None_)[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/nn/modules/container.py#L800)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ParameterDict.html#torch.nn.ParameterDict "Link to this definition")

Holds parameters in a dictionary.

ParameterDict can be indexed like a regular Python dictionary, but Parameters it contains are properly registered, and will be visible by all Module methods. Other objects are treated as would be done by a regular Python dictionary

[`ParameterDict`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ParameterDict.html#torch.nn.ParameterDict "torch.nn.ParameterDict")
 is an **ordered** dictionary. [`update()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ParameterDict.html#torch.nn.ParameterDict.update "torch.nn.ParameterDict.update")
 with other unordered mapping types (e.g., Python’s plain `dict`) does not preserve the order of the merged mapping. On the other hand, `OrderedDict` or another [`ParameterDict`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ParameterDict.html#torch.nn.ParameterDict "torch.nn.ParameterDict")
 will preserve their ordering.

Note that the constructor, assigning an element of the dictionary and the [`update()`](https://docs.pytorch.org/docs/2.15/generated/torch.nn.ParameterDict.html#torch.nn.ParameterDict.update "torch.nn.ParameterDict.update")
 method will convert any [`Tensor`](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
 into `Parameter`.

Parameters:

**values** (_iterable__,_ _optional_) – a mapping (dictionary) of (string : Any) or an iterable of key-value pairs of type (string, Any)

Example:

class MyModule(nn.Module):
    def \_\_init\_\_(self) \-> None:
        super().\_\_init\_\_()
        self.params \= nn.ParameterDict(
            {
                "left": nn.Parameter(torch.randn(5, 10)),
                "right": nn.Parameter(torch.randn(5, 10)),
            }
        )

    def forward(self, x, choice):
        x \= self.params\[choice\].mm(x)
        return x
