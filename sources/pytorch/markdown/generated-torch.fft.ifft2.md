torch.fft.ifft2[#](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifft2.html#torch-fft-ifft2 "Link to this heading")

=============================================================================================================================

torch.fft.ifft2(_input_, _s\=None_, _dim\=(-2, \-1)_, _norm\=None_, _\*_, _out\=None_) → [Tensor](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
[\[source\]](https://github.com/pytorch/pytorch/blob/v2.15.0/torch/fft/__init__.py#L190)
[#](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifft2.html#torch.fft.ifft2 "Link to this definition")

Computes the 2 dimensional inverse discrete Fourier transform of `input`. Equivalent to [`ifftn()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifftn.html#torch.fft.ifftn "torch.fft.ifftn")
 but IFFTs only the last two dimensions by default.

Note

Supports torch.half and torch.chalf on CUDA with GPU Architecture SM53 or greater. However it only supports powers of 2 signal length in every transformed dimensions.

Parameters:

*   **input** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
    ) – the input tensor
    
*   **s** (_Tuple__\[_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _\]__,_ _optional_) – Signal size in the transformed dimensions. If given, each dimension `dim[i]` will either be zero-padded or trimmed to the length `s[i]` before computing the IFFT. If a length `-1` is specified, no padding is done in that dimension. Default: `s = [input.size(d) for d in dim]`
    
*   **dim** (_Tuple__\[_[_int_](https://docs.python.org/3/builtins/functions.html#int "(in Python v3.15)")\
    _\]__,_ _optional_) – Dimensions to be transformed. Default: last two dimensions.
    
*   **norm** ([_str_](https://docs.python.org/3/builtins/stdtypes.html#str "(in Python v3.15)")
    _,_ _optional_) –
    
    Normalization mode. For the backward transform ([`ifft2()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifft2.html#torch.fft.ifft2 "torch.fft.ifft2")
    ), these correspond to:
    
    *   `"forward"` - no normalization
        
    *   `"backward"` - normalize by `1/n`
        
    *   `"ortho"` - normalize by `1/sqrt(n)` (making the IFFT orthonormal)
        
    
    Where `n = prod(s)` is the logical IFFT size. Calling the forward transform ([`fft2()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.fft2.html#torch.fft.fft2 "torch.fft.fft2")
    ) with the same normalization mode will apply an overall normalization of `1/n` between the two transforms. This is required to make [`ifft2()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifft2.html#torch.fft.ifft2 "torch.fft.ifft2")
     the exact inverse.
    
    Default is `"backward"` (normalize by `1/n`).
    

Keyword Arguments:

**out** ([_Tensor_](https://docs.pytorch.org/docs/2.15/tensors.html#torch.Tensor "torch.Tensor")
_,_ _optional_) – the output tensor.

Example

\>>> x \= torch.rand(10, 10, dtype\=torch.complex64)
\>>> ifft2 \= torch.fft.ifft2(x)

Copy to clipboard

The discrete Fourier transform is separable, so [`ifft2()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifft2.html#torch.fft.ifft2 "torch.fft.ifft2")
 here is equivalent to two one-dimensional [`ifft()`](https://docs.pytorch.org/docs/2.15/generated/torch.fft.ifft.html#torch.fft.ifft "torch.fft.ifft")
 calls:

\>>> two\_iffts \= torch.fft.ifft(torch.fft.ifft(x, dim\=0), dim\=1)
\>>> torch.testing.assert\_close(ifft2, two\_iffts, check\_stride\=False)
