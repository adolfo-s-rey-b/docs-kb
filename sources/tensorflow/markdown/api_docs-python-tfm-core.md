Modules
-------

[`actions`](https://www.tensorflow.org/api_docs/python/tfm/core/actions)
 module: Provides TFM orbit actions and associated helper functions/classes.

[`base_task`](https://www.tensorflow.org/api_docs/python/tfm/core/base_task)
 module: Defines the base task abstraction.

[`base_trainer`](https://www.tensorflow.org/api_docs/python/tfm/core/base_trainer)
 module: Standard Trainer implementation.

[`config_definitions`](https://www.tensorflow.org/api_docs/python/tfm/core/config_definitions)
 module: Common configuration settings.

[`exp_factory`](https://www.tensorflow.org/api_docs/python/tfm/core/exp_factory)
 module: Experiment factory methods.

[`export_base`](https://www.tensorflow.org/api_docs/python/tfm/core/export_base)
 module: Base class for model export.

[`file_writers`](https://www.tensorflow.org/api_docs/python/tfm/core/file_writers)
 module: File writer functions for dataset preparation, infra validation, and unit tests.

[`input_reader`](https://www.tensorflow.org/api_docs/python/tfm/core/input_reader)
 module: A common dataset reader.

[`registry`](https://www.tensorflow.org/api_docs/python/tfm/core/registry)
 module: Registry utility.

[`savedmodel_checkpoint_manager`](https://www.tensorflow.org/api_docs/python/tfm/core/savedmodel_checkpoint_manager)
 module: Custom checkpoint manager that also exports saved models.

[`task_factory`](https://www.tensorflow.org/api_docs/python/tfm/core/task_factory)
 module: A global factory to register and access all registered tasks.

[`tf_example_builder`](https://www.tensorflow.org/api_docs/python/tfm/core/tf_example_builder)
 module: Builder class for preparing tf.train.Example.

[`tf_example_feature_key`](https://www.tensorflow.org/api_docs/python/tfm/core/tf_example_feature_key)
 module: Data classes for tf.Example proto feature keys.

[`train_lib`](https://www.tensorflow.org/api_docs/python/tfm/core/train_lib)
 module: TFM common training driver library.

[`train_utils`](https://www.tensorflow.org/api_docs/python/tfm/core/train_utils)
 module: Training utils.
