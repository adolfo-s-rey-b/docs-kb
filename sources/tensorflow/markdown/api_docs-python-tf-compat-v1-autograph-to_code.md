Returns the source code generated by AutoGraph, as a string.

tf.compat.v1.autograph.to_code(
        entity,
        recursive=True,
        arg_values=None,
        arg_types=None,
        indentation='  ',
        experimental_optional_features=None
    )

#### Example usage:

    def f(x):

Also see: [`tf.autograph.to_graph`](https://www.tensorflow.org/api_docs/python/tf/autograph/to_graph)
.

    @tf.function

|     |     |
| --- | --- |
| Args<br>---- |     |
| `entity` | Python callable or class. |
| `recursive` | Whether to recursively convert any functions that the converted function may call. |
| `arg_values` | Deprecated. |
| `arg_types` | Deprecated. |
| `indentation` | Deprecated. |
| `experimental_optional_features` | `None`, a tuple of, or a single [`tf.autograph.experimental.Feature`](https://www.tensorflow.org/api_docs/python/tf/autograph/experimental/Feature)<br> value. |

|     |
| --- |
| Returns<br>------- |     |
| The converted code as string. |     |
