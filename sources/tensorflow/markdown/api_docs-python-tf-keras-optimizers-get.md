Retrieves a Keras Optimizer instance.

tf.keras.optimizers.get(
        identifier
    )

|     |     |
| --- | --- |
| Args<br>---- |     |
| `identifier` | Optimizer identifier, one of:<br><br>*   String: name of an optimizer<br>*   Dictionary: configuration dictionary.<br>*   Keras Optimizer instance (it will be returned unchanged). |

|     |
| --- |
| Returns<br>------- |     |
| A Keras Optimizer instance. |     |
