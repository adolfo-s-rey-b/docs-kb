ufunc.ntypes[#](https://numpy.org/doc/stable/reference/generated/numpy.ufunc.ntypes.html#numpy.ufunc.ntypes "Link to this definition")

The number of types.

The number of numerical NumPy types - of which there are 18 total - on which the ufunc can operate.

See also

[`numpy.ufunc.types`](https://numpy.org/doc/stable/reference/generated/numpy.ufunc.types.html#numpy.ufunc.types "numpy.ufunc.types")
