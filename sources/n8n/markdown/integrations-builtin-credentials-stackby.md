You can use these credentials to authenticate the following nodes:

*   [Stackby](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.stackby)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/stackby#prerequisites)

--------------------------------------------------------------------------------------------

Create a [Stackby](https://stackby.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/stackby#supported-authentication-methods)

----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/stackby#related-resources)

----------------------------------------------------------------------------------------------------

Refer to [Stackby's API documentation](https://www.postman.com/lively-equinox-180638/stackby-s-public-workspace/overview)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/stackby#using-api-key)

--------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Go to your [**Account Settings > API**](https://www.stackby.com/account)
     to create an API Key. Refer to [API Key](https://help.stackby.com/en/articles/124-how-to-get-your-api-key-in-stackby)
     for more information.
