You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/hybridanalysis#prerequisites)

---------------------------------------------------------------------------------------------------

Create a [Hybrid Analysis](https://www.hybrid-analysis.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/hybridanalysis#supported-authentication-methods)

-----------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/hybridanalysis#related-resources)

-----------------------------------------------------------------------------------------------------------

Refer to [Hybrid Analysis' API documentation](https://www.hybrid-analysis.com/docs/api/v2)
 for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/hybrid-analysis/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/hybridanalysis#using-api-key)

---------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to the [Hybrid Analysis' API documentation](https://www.hybrid-analysis.com/docs/api/v2)
     for instructions on generating an API key.
