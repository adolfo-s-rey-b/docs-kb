This section contains details on how to deploy and share your node.

In this section[](https://docs.n8n.io/connect/create-nodes/deploy-your-node#in-this-section)

---------------------------------------------------------------------------------------------

*   [Submit community nodes](https://docs.n8n.io/connect/create-nodes/deploy-your-node/submit-community-nodes)
    : submit your node to the community node repository, so anyone can [install and use it](https://docs.n8n.io/integrations/community-nodes/installation-and-management)
     like any other community node. This is the only way to use custom nodes on Cloud.
    
*   [Install private nodes](https://docs.n8n.io/connect/create-nodes/deploy-your-node/install-private-nodes)
    : install the node into your own n8n instance as a private node.
