*   [Emelia](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.emelia)
    
*   [Emelia Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.emeliatrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/emelia#prerequisites)

-------------------------------------------------------------------------------------------

Create an [Emelia](https://emelia.io/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/emelia#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/emelia#related-resources)

---------------------------------------------------------------------------------------------------

Refer to [Emelia's API documentation](https://docs.emelia.io/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/emelia#using-api-key)

-------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: To generate an API Key in Emelia, access your **API Keys** by selecting the avatar in the top right (your **Settings**). Refer to the Authentication section of [Emelia's API documentation](https://docs.emelia.io/)
     for more information.
