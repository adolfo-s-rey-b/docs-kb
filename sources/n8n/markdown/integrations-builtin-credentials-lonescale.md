You can use these credentials to authenticate the following nodes:

*   [LoneScale](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.lonescale)
    
*   [LoneScale Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.lonescaletrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/lonescale#prerequisites)

----------------------------------------------------------------------------------------------

Create a [LoneScale](https://www.lonescale.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/lonescale#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/lonescale#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [LoneScale's API documentation](https://docs.lonescale.com/authentication)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/lonescale#using-api-key)

----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to [LoneScale's Generate an API key documentation](https://help-center.lonescale.com/en/articles/6454360-lonescale-public-api)
     to generate your key.
