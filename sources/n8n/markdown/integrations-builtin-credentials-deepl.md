You can use these credentials to authenticate the following nodes:

*   [DeepL](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.deepl)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/deepl#prerequisites)

------------------------------------------------------------------------------------------

Create a [DeepL developer](https://www.deepl.com/pro-api)
 account. n8n works with both Free and Pro API Plans.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/deepl#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/deepl#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [DeepL's API documentation](https://developers.deepl.com/docs)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/deepl#using-api-key)

------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to [DeepL's Authentication documentation](https://developers.deepl.com/docs/getting-started/auth#authentication)
     for more information on getting your API key.
    
*   To identify which **API Plan** you're on. DeepL has different API endpoints for each plan, so be sure you select the correct one:
    
    *   Pro Plan
        
    *   Free Plan
