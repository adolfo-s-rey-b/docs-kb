You can use these credentials to authenticate the following nodes:

*   [Rundeck](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.rundeck)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/rundeck#prerequisites)

--------------------------------------------------------------------------------------------

Create a user account on a [Rundeck](https://www.rundeck.com/)
 server.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/rundeck#supported-authentication-methods)

----------------------------------------------------------------------------------------------------------------------------------

*   API token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/rundeck#related-resources)

----------------------------------------------------------------------------------------------------

Refer to [Rundeck's API documentation](https://docs.rundeck.com/docs/api/)
 for more information about the service.

Using API token[](https://docs.n8n.io/integrations/builtin/credentials/rundeck#using-api-token)

------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   Your **URL**: Enter the base URL of your Rundeck server, for example `http://myserver:4440`. Refer to [URLs](https://docs.rundeck.com/docs/api/#urls)
     for more information.
    
*   A user API **Token**: To generate a user API token, go to your **Profile > User API Tokens**. Refer to [User API tokens](https://docs.rundeck.com/docs/manual/10-user.html#user-api-tokens)
     for more information.
