You can use these credentials to authenticate the following node:

*   [Clearbit](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.clearbit)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/clearbit#prerequisites)

---------------------------------------------------------------------------------------------

Create a [Clearbit](https://www.clearbit.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/clearbit#supported-authentication-methods)

-----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/clearbit#related-resources)

-----------------------------------------------------------------------------------------------------

Refer to [Clearbit's API documentation](https://dashboard.clearbit.com/docs)
 for more information about authenticating with the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/clearbit#using-api-key)

---------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to [Clearbit's API Authentication documentation](https://dashboard.clearbit.com/docs#authentication)
     for more information on creating and viewing API keys.
