You can use these credentials to authenticate the following nodes:

*   [LingvaNex](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.lingvanex)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/lingvanex#prerequisites)

----------------------------------------------------------------------------------------------

Create a [LingvaNex](https://lingvanex.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/lingvanex#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/lingvanex#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Lingvanex's Cloud API documentation](https://docs.lingvanex.com/reference/overview)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/lingvanex#using-api-key)

----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Generate an API key from your **Account** page. Refer to [Where can I get the authorization key?](https://docs.lingvanex.com/reference/translator-service-faq#where-can-i-get-the-authorization-key)
     for more detailed instructions.
