You can use these credentials to authenticate the following node:

*   [Brandfetch](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.brandfetch)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/brandfetch#prerequisites)

-----------------------------------------------------------------------------------------------

Create a [Brandfetch developer](https://developers.brandfetch.com/)
 developer account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/brandfetch#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/brandfetch#related-resources)

-------------------------------------------------------------------------------------------------------

Refer to [Brandfetch's API documentation](https://docs.brandfetch.com/get-started)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/brandfetch#using-api-key)

-----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: [Create an account](https://developers.brandfetch.com/dashboard/keys)
     to generate an API key.
