You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/alienvault#prerequisites)

-----------------------------------------------------------------------------------------------

Create an [AlienVault](https://otx.alienvault.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/alienvault#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/alienvault#related-resources)

-------------------------------------------------------------------------------------------------------

Refer to [AlienVault's documentation](https://otx.alienvault.com/api)
 for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/alienvault/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/alienvault#using-api-key)

-----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **OTX Key**: Once you have an AlienVault account, the **OTX Key** displays in your **Settings**.
