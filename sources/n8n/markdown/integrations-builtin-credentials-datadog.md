You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/datadog#prerequisites)

--------------------------------------------------------------------------------------------

Create a [Datadog](https://app.datadoghq.eu/signup)
 account.

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/datadog#related-resources)

----------------------------------------------------------------------------------------------------

Refer to [Datadog's API documentation](https://docs.datadoghq.com/api/latest/)
 for more information about authenticating with the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/datadog/)
 on n8n's website.

Using API Key[](https://docs.n8n.io/integrations/builtin/credentials/datadog#using-api-key)

--------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   Your Datadog instance **Host**
    
*   An **API Key**
    
*   An **App Key**
    

Refer to [Authentication](https://docs.datadoghq.com/api/latest/authentication/)
 on Datadog's website for more information.
