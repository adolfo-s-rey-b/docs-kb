Using API Token[](https://docs.n8n.io/integrations/builtin/credentials/solarwindsobservability#using-api-token)

----------------------------------------------------------------------------------------------------------------

To configure this credential, you'll need a SolarWinds Observability SaaS account and:

*   **URL**: The URL you use to access the SolarWinds Observability SaaS platform
    
*   **API Token**: An API token found in the SolarWinds Observability SaaS platform under **Settings > Api Tokens**
    

Refer to [SolarWinds Observability SaaS's API documentation](https://documentation.solarwinds.com/en/success_center/observability/content/settings/api-tokens.htm)
 for more information about authenticating to the service.
