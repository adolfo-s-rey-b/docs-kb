The HTTP Request node is one of the most versatile nodes in n8n. Use this node to make HTTP requests to query data from any app or service with a REST API.

Refer to [HTTP Request](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 for information on node settings.

See [Pagination](https://docs.n8n.io/build/code-in-n8n/cookbook/http-request-node/pagination)
 for examples of paging through results with this node.
