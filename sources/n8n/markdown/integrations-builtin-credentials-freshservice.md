You can use these credentials to authenticate the following nodes:

*   [Freshservice](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.freshservice)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/freshservice#prerequisites)

-------------------------------------------------------------------------------------------------

Create a [Freshservice](https://freshservice.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/freshservice#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/freshservice#related-resources)

---------------------------------------------------------------------------------------------------------

Refer to [Freshservice's API documentation](https://api.freshservice.com/v2/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/freshservice#using-api-key)

-------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to the [Freshservice API authenticaton documentation](https://api.freshservice.com/v2/#authentication)
     for detailed instructions on getting your API key.
    
*   Your Freshservice **Domain**: Use the subdomain of your Freshservice account. This is part of the URL, for example `https://<subdomain>.freshservice.com`. So if you access Freshservice through `https://n8n.freshservice.com`, enter `n8n` as your **Domain**.
