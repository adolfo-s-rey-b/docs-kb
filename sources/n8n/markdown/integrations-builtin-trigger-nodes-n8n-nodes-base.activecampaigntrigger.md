[ActiveCampaign](https://www.activecampaign.com/)
 is a cloud software platform for small-to-mid-sized business. The company offers software for customer experience automation, which combines the email marketing, marketing automation, sales automation, and CRM categories.

**Credentials**

Refer to the [ActiveCampaign credentials documentation](https://docs.n8n.io/integrations/builtin/credentials/activecampaign)
 for authentication information for this node.
