You can use these credentials to authenticate the following nodes:

*   [Travis CI](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.travisci)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/travisci#prerequisites)

---------------------------------------------------------------------------------------------

Create a [Travis CI](https://travis-ci.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/travisci#supported-authentication-methods)

-----------------------------------------------------------------------------------------------------------------------------------

*   API token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/travisci#related-resources)

-----------------------------------------------------------------------------------------------------

Refer to [Travis CI's API documentation](https://docs.travis-ci.com/user/developer/)
 for more information about the service.

Using API token[](https://docs.n8n.io/integrations/builtin/credentials/travisci#using-api-token)

-------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Token**: Get your API token from **Account Settings >** [**API Token**](https://packagecloud.io/api_token)
     or generate one through the Travis CI [command line client](https://github.com/travis-ci/travis.rb#installation)
     .
