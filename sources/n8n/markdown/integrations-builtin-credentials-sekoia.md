You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/sekoia#prerequisites)

-------------------------------------------------------------------------------------------

Create a [Sekoia SOC platform](https://www.sekoia.io/en/homepage/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/sekoia#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/sekoia#related-resources)

---------------------------------------------------------------------------------------------------

Refer to [Sekoia's documentation](https://docs.sekoia.io/getting_started/)
 for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/sekoia/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/sekoia#using-api-key)

-------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: To generate an API key, select **\+ API Key**. Refer to [Create an API key](https://docs.sekoia.io/getting_started/manage_api_keys/#create-an-api-key)
     for more information.
