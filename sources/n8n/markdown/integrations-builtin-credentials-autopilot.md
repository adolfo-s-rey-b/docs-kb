You can use these credentials to authenticate the following nodes:

*   [Autopilot](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.autopilot)
    
*   [Autopilot Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.autopilottrigger)
    

**Autopilot branding change**

Autopilot has become Ortto. The Autopilot credentials and nodes are only compatible with Autopilot, not the new Ortto API.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/autopilot#prerequisites)

----------------------------------------------------------------------------------------------

Create an [Autopilot](https://app.autopilothq.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/autopilot#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/autopilot#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Autopilot's API documentation](https://autopilot.docs.apiary.io/#)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/autopilot#using-api-key)

----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Generate an API key in **Settings > Autopilot API**. Refer to [Autopilot API authentication](https://autopilot.docs.apiary.io/#reference/authentication)
     for more information.
