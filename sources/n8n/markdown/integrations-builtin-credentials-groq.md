Using API key[](https://docs.n8n.io/integrations/builtin/credentials/groq#using-api-key)

-----------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**
    

To get your API key:

1.  Go to the [API Keys](https://console.groq.com/keys)
     page of your Groq console.
    
2.  Select **Create API Key**.
    
3.  Enter a **display name** for the key, like `n8n integration`, and select **Submit**.
    
4.  Copy the key and paste it into your n8n credential.
    

Refer to [Groq's API Keys documentation](https://console.groq.com/docs/quickstart)
 for more information.

**Groq API keys**

Groq binds API keys to the organization, not the user.
