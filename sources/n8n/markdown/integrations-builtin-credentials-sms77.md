You can use these credentials to authenticate the following nodes:

*   [seven](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.sms77)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/sms77#prerequisites)

------------------------------------------------------------------------------------------

Create a [seven](https://www.seven.io/en)
 developer account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/sms77#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/sms77#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [seven's API documentation](https://docs.seven.io/en)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/sms77#using-api-key)

------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API key**: Go to **Account > Developer >** [**API Keys**](https://app.seven.io/developer#create-api-key)
     to create an API key. Refer to [API First Steps](https://docs.seven.io/en/rest-api/first-steps)
     for more information.
