You can use these credentials to authenticate the following nodes:

*   [Marketstack](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.marketstack)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/marketstack#prerequisites)

------------------------------------------------------------------------------------------------

Create a [Marketstack](https://marketstack.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/marketstack#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/marketstack#related-resources)

--------------------------------------------------------------------------------------------------------

Refer to [Marketstack's API documentation](https://marketstack.com/documentation)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/marketstack#using-api-key)

------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: View and generate API keys in your Marketstack [account dashboard](https://marketstack.com/dashboard)
    .
    
*   Select whether to **Use HTTPS**: Make this selection based on your Marketstack account plan level:
    
    *   Free plan: Turn off **Use HTTPS**
        
    *   All other plans: Turn on **Use HTTPS**
