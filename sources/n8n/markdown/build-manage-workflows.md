In this section[](https://docs.n8n.io/build/manage-workflows#in-this-section)

*   [Configure workflow settings](https://docs.n8n.io/build/manage-workflows/configure-workflow-settings)
    : manage settings for an individual workflow.
    
*   [Tag workflows](https://docs.n8n.io/build/manage-workflows/tag-workflows)
    : label workflows to make them easier to browse.
    
*   [Favorite items](https://docs.n8n.io/build/manage-workflows/favorite-items)
    : pin workflows, folders, projects, and data tables for quick access.

    : view and restore previous versions of your workflow.
    
*   [Review workflows](https://docs.n8n.io/build/manage-workflows/workflow-reviews)
    : submit a workflow version for review before publishing.

    : move workflows in and out of n8n.

    : bundle workflows and their structure into a portable file to move between instances.
    
*   [Share with others](https://docs.n8n.io/build/manage-workflows/share-with-others)
    : share workflows between users.
