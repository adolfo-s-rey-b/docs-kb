Keep your n8n version up to date to get the latest features and fixes.

Some tips when updating:

*   Update frequently: this avoids having to jump multiple versions at once, reducing the risk of a disruptive update. Try to update at least once a month.
    
*   Check the [Release notes](https://docs.n8n.io/changelog/release-notes-2.x)
     for breaking changes.
    
*   Use [Environments](https://docs.n8n.io/administer/use-source-control-and-environments)
     to create a test version of your instance. Test the update there first.
    

For instructions on how to update, refer to the documentation for your installation method:

*   [Installed with npm](https://docs.n8n.io/deploy/host-n8n/install-options/install-with-npm#updating)
    
*   [Installed with Docker or Docker Compose](https://docs.n8n.io/deploy/host-n8n/install-options/install-with-docker#updating)
