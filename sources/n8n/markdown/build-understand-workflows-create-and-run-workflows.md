A workflow is a collection of nodes connected together to automate a process. You build workflows on the workflow canvas.

Create a workflow[](https://docs.n8n.io/build/understand-workflows/create-and-run-workflows#create-a-workflow)

---------------------------------------------------------------------------------------------------------------

1.  Select the ![universal create resource icon](https://docs.n8n.io/~gitbook/image?url=https%3A%2F%2F3488703508-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FrPN1zU5jaYNvwH7RzxqA%252Fuploads%252Fgit-blob-67e6f1d372835116e41a7e6ddd39acae384e5e29%252Funiversal-resource-button.png%3Falt%3Dmedia&width=39&dpr=3&quality=100&sign=04157a32047d49328e59f9a393beab01&sv=3) **button** in the upper-left corner of the side menu. Select workflow.
    
2.  If your n8n instance supports projects, you'll also need to choose whether to create the workflow inside your **personal space** or a specific **project** you have access to. If you're using the community version, you'll always create workflows inside your personal space.
    
3.  Get started by adding a trigger node: select **Add first step...**
    

Or:

1.  Select the ![universal create resource icon](https://docs.n8n.io/~gitbook/image?url=https%3A%2F%2F3488703508-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FrPN1zU5jaYNvwH7RzxqA%252Fuploads%252Fgit-blob-67e6f1d372835116e41a7e6ddd39acae384e5e29%252Funiversal-resource-button.png%3Falt%3Dmedia&width=39&dpr=3&quality=100&sign=04157a32047d49328e59f9a393beab01&sv=3) **create** button in the upper-right corner from either the **Overview** page or a specific **project**. Select workflow.
    
2.  If you're doing this from the **Overview** page, you'll create the workflow inside your personal space. If you're doing this from inside a project, you'll create the workflow inside that specific project.
    
3.  Get started by adding a trigger node: select **Add first step...**
    

If it's your first time building a workflow, you may want to use the [quickstart guides](https://docs.n8n.io/build-your-first-workflow)
 to quickly try out n8n features.

Run workflows manually[](https://docs.n8n.io/build/understand-workflows/create-and-run-workflows#run-workflows-manually)

-------------------------------------------------------------------------------------------------------------------------

You may need to run your workflow manually when building and testing, or if your workflow doesn't have a trigger node.

To run manually, select **Execute Workflow**.

Run workflows automatically[](https://docs.n8n.io/build/understand-workflows/create-and-run-workflows#run-workflows-automatically)

-----------------------------------------------------------------------------------------------------------------------------------

All new workflows are unpublished by default. See [Publishing and saving workflows](https://docs.n8n.io/build/understand-workflows/save-and-publish-workflows)
.

You need to publish workflows that start with a trigger node or Webhook node so that they can run automatically. When a workflow isn't published, you must run it manually.

To publish your workflow, open your workflow and click **Publish**. The option to unpublish is in the workflow settings menu.

Published workflows run whenever its trigger conditions are met.
