**Feature availability**

The Flow service has shut down and its API no longer responds, so the Flow and Flow Trigger nodes can't connect to it. Workflows using these nodes will fail. Remove them or switch to another service.

You can use these credentials to authenticate the following nodes:

*   [Flow](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.flow)
    
*   [Flow Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.flowtrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/flow#prerequisites)

-----------------------------------------------------------------------------------------

Create a Flow account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/flow#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/flow#using-api-key)
