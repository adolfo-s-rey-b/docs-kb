You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/malcore#prerequisites)

--------------------------------------------------------------------------------------------

Create a [Malcore](https://app.malcore.io/register)
 account.

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/malcore#related-resources)

----------------------------------------------------------------------------------------------------

Refer to [Malcore's API documentation](https://malcore.readme.io/reference/)
 for more information about authenticating with the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/malcore/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/malcore#using-api-key)

--------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Get an API Key from your **Account > API**.
    

Refer to [Using the Malcore API](https://support.malcore.io/hc/en-au/articles/17711707070617-Using-the-Malcore-API)
 for more information.
