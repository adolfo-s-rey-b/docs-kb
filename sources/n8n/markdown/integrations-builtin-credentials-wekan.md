You can use these credentials to authenticate the following nodes:

*   [Wekan](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.wekan)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/wekan#prerequisites)

------------------------------------------------------------------------------------------

Install [Wekan](https://github.com/wekan/wekan/wiki)
 on your server.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/wekan#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   Basic auth
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/wekan#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [Wekan's API documentation](https://github.com/wekan/wekan/wiki/REST-API)
 for more information about authenticating with the service.

Using basic auth[](https://docs.n8n.io/integrations/builtin/credentials/wekan#using-basic-auth)

------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **Username**: Enter your Wekan username.
    
*   A **Password**: Enter your Wekan password.
    
*   A **URL**: Enter your Wekan domain.
