You can use these credentials to authenticate the following nodes:

*   [Humantic AI](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.humanticai)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/humanticai#prerequisites)

-----------------------------------------------------------------------------------------------

Create a [Humantic AI](https://humantic.ai/)
 account.

You can also try out an API key as a free trial at the [Humantic AI API](https://api.humantic.ai/)
 page.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/humanticai#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/humanticai#related-resources)

-------------------------------------------------------------------------------------------------------

Refer to [Humantic AI's API documentation](https://api.humantic.ai/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/humanticai#using-api-key)

-----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Get an API key from the [Humantic AI API](https://api.humantic.ai/)
     page.
