You can use these credentials to authenticate the following nodes:

*   [Cloudflare node](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.cloudflare)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/cloudflare#prerequisites)

-----------------------------------------------------------------------------------------------

*   Create a [Cloudflare account](https://developers.cloudflare.com/fundamentals/setup/account/)
    .
    
*   [Add a domain](https://developers.cloudflare.com/fundamentals/setup/manage-domains/add-site/)
    .
    

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/cloudflare#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------

*   API token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/cloudflare#related-resources)

-------------------------------------------------------------------------------------------------------

Refer to [Cloudflare's API documentation](https://developers.cloudflare.com/fundamentals/api/)
 for more information about the service.

Using API token[](https://docs.n8n.io/integrations/builtin/credentials/cloudflare#using-api-token)

---------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API token**: Follow the [Cloudflare documentation to create an API token](https://developers.cloudflare.com/fundamentals/api/get-started/create-token/)
    .
