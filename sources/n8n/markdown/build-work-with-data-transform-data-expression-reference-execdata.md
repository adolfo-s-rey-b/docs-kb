`$exec`.`**customData**`[](https://docs.n8n.io/build/work-with-data/transform-data/expression-reference/execdata#dollarexeccustomdata)

---------------------------------------------------------------------------------------------------------------------------------------

**Description:** Set and get custom execution data (e.g. to filter executions by). You can also do this with the ‘Execution Data’ node. [More info](https://docs.n8n.io/build/understand-workflows/understand-executions/customize-executions-data)

**Syntax:** `$exec`.`$exec`.`**customData**`

**Returns:** CustomData

**Source:** Custom n8n functionality

`$exec`.`**id**`[](https://docs.n8n.io/build/work-with-data/transform-data/expression-reference/execdata#dollarexecid)

-----------------------------------------------------------------------------------------------------------------------

**Description:** The ID of the current workflow execution

**Syntax:** `$exec`.`$exec`.`**id**`

**Returns:** String

**Source:** Custom n8n functionality

`$exec`.`**mode**`[](https://docs.n8n.io/build/work-with-data/transform-data/expression-reference/execdata#dollarexecmode)

---------------------------------------------------------------------------------------------------------------------------

**Description:** Can be one of 3 values: either `test` (meaning the execution was triggered by clicking a button in n8n) or `production` (meaning the execution was triggered automatically). When running workflow tests, `evaluation` is used.

**Syntax:** `$exec`.`$exec`.`**mode**`

**Returns:** String

**Source:** Custom n8n functionality

`$exec`.`**resumeFormUrl**`[](https://docs.n8n.io/build/work-with-data/transform-data/expression-reference/execdata#dollarexecresumeformurl)

---------------------------------------------------------------------------------------------------------------------------------------------

**Description:** The URL to access a form generated by the [’Wait’ node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.wait)
.

**Syntax:** `$exec`.`$exec`.`**resumeFormUrl**`

**Returns:** String

**Source:** Custom n8n functionality

`$exec`.`**resumeUrl**`[](https://docs.n8n.io/build/work-with-data/transform-data/expression-reference/execdata#dollarexecresumeurl)

-------------------------------------------------------------------------------------------------------------------------------------

**Description:** The webhook URL to call to resume a workflow waiting at a [’Wait’ node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.wait)
.

**Syntax:** `$exec`.`$exec`.`**resumeUrl**`

**Returns:** String

**Source:** Custom n8n functionality
