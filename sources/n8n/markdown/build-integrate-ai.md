n8n lets you build AI workflows that connect different LLM providers such as OpenAI, Anthropic, and Google, add tools and memory, and combine several models in one workflow.

In this section[](https://docs.n8n.io/build/integrate-ai#in-this-section)

--------------------------------------------------------------------------

*   [MCP servers](https://docs.n8n.io/build/integrate-ai/mcp-servers)
    : connect an AI agent to an MCP registry server in one click.
    
*   [Understand AI components](https://docs.n8n.io/build/integrate-ai/understand-ai-components)
    : learn about agents, chains, tools, memory, and vector databases.
    
*   [LangChain in n8n](https://docs.n8n.io/build/integrate-ai/langchain-in-n8n)
    : understand how n8n implements LangChain concepts.
    
*   [Test and improve AI workflows](https://docs.n8n.io/build/integrate-ai/test-and-improve-ai-workflows)
    : use evaluations to build reliable AI workflows.
    
*   [AI examples](https://docs.n8n.io/build/integrate-ai/ai-examples)
    : example workflows and use cases for building AI functionality.
