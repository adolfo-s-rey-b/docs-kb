You can use these credentials to authenticate the following nodes:

*   [Sendy](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.sendy)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/sendy#prerequisites)

------------------------------------------------------------------------------------------

Host a [Sendy](https://sendy.co/get-started)
 application.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/sendy#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/sendy#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [Sendy's API documentation](https://sendy.co/api)
 for more information about the service.

Using API Key[](https://docs.n8n.io/integrations/builtin/credentials/sendy#using-api-key)

------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **URL**: The URL of your Sendy application.
    
*   An **API Key**: Get your API key from your user profile > **Settings > Your API Key**.
