*   [Segment](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.segment)

 account.

----------------------------------------------------------------------------------------------------

 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/segment#using-api-key)

--------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **Write Key**: To get a Write Key, go to **Sources > Add Source**. Add a **Node.js** source and copy that write key to add to your n8n credential.
    

Refer to [Locate your Write Key](https://segment.com/docs/connections/find-writekey/)
 for more information.
