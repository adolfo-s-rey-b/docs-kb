n8n gives you several ways to build a workflow, from typing a request in natural language to writing every node by hand.

In this section[](https://docs.n8n.io/build/ways-of-building-workflows#in-this-section)

----------------------------------------------------------------------------------------

*   [Use n8n Assistant](https://docs.n8n.io/build/ways-of-building-workflows/n8n-assistant)
    : create, edit, test, and troubleshoot workflows from a chat.
    
*   [Use n8n MCP server](https://docs.n8n.io/build/ways-of-building-workflows/connect-to-n8n-mcp-server)
    : build and run workflows from MCP clients such as Claude Desktop or Claude Code.
    
*   [Use templates](https://docs.n8n.io/build/ways-of-building-workflows/use-templates)
    : start from a pre-built workflow instead of an empty canvas.
    
*   [Use Ask n8n AI](https://docs.n8n.io/build/ways-of-building-workflows/use-the-ai-assistant)
    : get in-editor help building, debugging, and optimizing workflows.
    
*   [Use Chat Hub](https://docs.n8n.io/build/ways-of-building-workflows/chat-hub)
    : chat with multiple AI models and n8n agents from one interface.
