You can use these credentials to authenticate the following nodes:

*   [Mindee](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.mindee)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/mindee#prerequisites)

-------------------------------------------------------------------------------------------

Create a [Mindee](https://mindee.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/mindee#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   Invoice API key: For use with the [Invoice OCR API](https://www.mindee.com/product/invoice-ocr-api)
    
*   Receipt API key: For use with the [Receipt OCR API](https://www.mindee.com/product/receipt-ocr-api)
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/mindee#related-resources)

---------------------------------------------------------------------------------------------------

Refer to [Mindee's Invoice OCR API documentation](https://developers.mindee.com/docs/invoice-ocr)
 and [Mindee's Receipt OCR API documentation](https://developers.mindee.com/docs/receipt-ocr)
 for more information about each service.

Using invoice API key[](https://docs.n8n.io/integrations/builtin/credentials/mindee#using-invoice-api-key)

-----------------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to the Mindee [Create & Manage API Keys documentation](https://developers.mindee.com/docs/create-api-key)
     for instructions on creating API keys.
    

Using receipt API key[](https://docs.n8n.io/integrations/builtin/credentials/mindee#using-receipt-api-key)

-----------------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to the Mindee [Create & Manage API Keys documentation](https://developers.mindee.com/docs/create-api-key)
     for instructions on creating API keys.
