You can use these credentials to authenticate the following nodes:

*   [Vonage](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.vonage)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/vonage#prerequisites)

-------------------------------------------------------------------------------------------

Create a [Vonage developer](https://developer.vonage.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/vonage#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/vonage#related-resources)

---------------------------------------------------------------------------------------------------

Refer to [Vonage's SMS API documentation](https://developer.vonage.com/en/api/sms)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/vonage#using-api-key)

-------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**
    
*   An **API Secret**
    

Get your **API Key** and **API Secret** from your [developer dashboard](https://dashboard.nexmo.com/)
 **user account > Settings > API Settings**. Refer to [Retrieve your account information](https://developer.vonage.com/en/account/guides/dashboard-management#retrieve-your-account-information)
 for more information.
