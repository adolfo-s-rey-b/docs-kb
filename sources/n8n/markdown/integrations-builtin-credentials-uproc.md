You can use these credentials to authenticate the following nodes:

*   [uProc](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.uproc)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/uproc#prerequisites)

------------------------------------------------------------------------------------------

Create a [uProc](https://uproc.io/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/uproc#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/uproc#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [uProc's API documentation](https://docs.uproc.io/api/)
 for more information about the service.

Using API Key[](https://docs.n8n.io/integrations/builtin/credentials/uproc#using-api-key)

------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **Email** address: Enter the email address you use to log in to uProc. This is also displayed in **Settings > Integrations > API Credentials**.
    
*   An **API Key**: Go to **Settings > Integrations > API Credentials**. Copy the **API Key (real)** from the **API Credentials** section and enter it in your n8n credential.
