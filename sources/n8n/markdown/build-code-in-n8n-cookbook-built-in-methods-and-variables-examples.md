n8n provides built-in methods and variables for working with data and accessing n8n data. This section provides usage examples.

In this section[](https://docs.n8n.io/build/code-in-n8n/cookbook/built-in-methods-and-variables-examples#in-this-section)

--------------------------------------------------------------------------------------------------------------------------

*   [execution](https://docs.n8n.io/build/code-in-n8n/cookbook/built-in-methods-and-variables-examples/execution)
    : set and get custom execution data.
    
*   [getWorkflowStaticData](https://docs.n8n.io/build/code-in-n8n/cookbook/built-in-methods-and-variables-examples/getworkflowstaticdata)
    : access the static workflow data.
    
*   [("node-name").all](https://docs.n8n.io/build/code-in-n8n/cookbook/built-in-methods-and-variables-examples/node-name-.all)
    : access all the items of the current or parent nodes.
    
*   [vars](https://docs.n8n.io/build/code-in-n8n/cookbook/built-in-methods-and-variables-examples/vars)
    : access your environment's custom variables.
