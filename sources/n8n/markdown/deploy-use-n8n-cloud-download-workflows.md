n8n Cloud instance owners can download their workflows from an n8n Cloud backup in the [n8n Cloud console](https://docs.n8n.io/deploy/use-n8n-cloud/use-the-cloud-console)
. n8n creates backups automatically. They contain workflows only, never credentials.

How to download workflows[](https://docs.n8n.io/deploy/use-n8n-cloud/download-workflows#how-to-download-workflows)

-------------------------------------------------------------------------------------------------------------------

1.  Open the [Cloud console](https://docs.n8n.io/deploy/use-n8n-cloud/use-the-cloud-console)
    .
    
2.  In the sidebar, select **Export**. n8n opens the **Data export** page.
    
3.  In **Workflow backups**, use the **Backup** dropdown to choose which backup to export. If only one backup exists, n8n shows it instead of a dropdown.
    
4.  Select **Download workflows**. The export opens in a new tab.
    

The **Latest backup** card on the **Overview** page shows when n8n created your most recent backup. Select **Download** on that card to go to the **Export** page.

If your instance is new or has been offline for a long time, it might not have any backups yet. In that case, the **Export** page shows **No backups available yet**.

Workflow export isn't available yet for instances that n8n hosts on PostgreSQL. For these instances, the **Export** page shows **Export is unavailable for this instance**, with a link to create a support ticket so n8n support can export your workflows.

Accessing workflows after your free trial[](https://docs.n8n.io/deploy/use-n8n-cloud/download-workflows#accessing-workflows-after-your-free-trial)

---------------------------------------------------------------------------------------------------------------------------------------------------

You have **90 days** to download your workflows after your free trial ends. After that, all workflows will be **permanently deleted** and are unrecoverable.
