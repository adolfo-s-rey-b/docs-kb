You can use these credentials to authenticate the following nodes:

*   [Quick Base](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.quickbase)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/quickbase#prerequisites)

----------------------------------------------------------------------------------------------

Create a [Quick Base](https://www.quickbase.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/quickbase#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/quickbase#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Quick Base's API documentation](https://developer.quickbase.com/auth/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/quickbase#using-api-key)

----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **Hostname**: The string of characters located between `https://` and `/db` in your Quick Base URL.
    
*   A **User Token**: To generate a token, select your **Profile > My preferences > My User Information > Manage my user tokens**. Refer to [Create and use user tokens](https://help.quickbase.com/docs/create-and-use-user-tokens)
     for detailed instructions.
