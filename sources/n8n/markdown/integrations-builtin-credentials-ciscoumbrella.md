You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/ciscoumbrella#prerequisites)

--------------------------------------------------------------------------------------------------

*   Create a [Cisco DevNet developer account](https://developer.cisco.com/)
    .
    
*   A [Cisco Umbrella user account](https://umbrella.cisco.com/)
     with **Full Admin** role.
    

Authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/ciscoumbrella#authentication-methods)

--------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/ciscoumbrella#related-resources)

----------------------------------------------------------------------------------------------------------

Refer to [Cisco Umbrella's API documentation](https://developer.cisco.com/docs/cloud-security/)
 for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/cisco-umbrella/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/ciscoumbrella#using-api-key)

--------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**
    
*   A **Secret**: Provided when you generate an API key
    

Refer to the [Cisco Umbrella Manage API Keys documentation](https://developer.cisco.com/docs/cloud-security/authentication/#manage-api-keys)
 for instructions on creating an Umbrella API key.
