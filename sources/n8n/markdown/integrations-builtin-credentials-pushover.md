You can use these credentials to authenticate the following nodes:

*   [Pushover](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.pushover)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/pushover#prerequisites)

---------------------------------------------------------------------------------------------

Create a [Pushover](https://pushover.net/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/pushover#supported-authentication-methods)

-----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/pushover#related-resources)

-----------------------------------------------------------------------------------------------------

Refer to [Pushover's API documentation](https://pushover.net/api)
 for more information about authenticating with the service.

Using API Key[](https://docs.n8n.io/integrations/builtin/credentials/pushover#using-api-key)

---------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Generated when you [register an application](https://pushover.net/apps/build)
    . Refer to [Application Registration](https://pushover.net/api#registration)
     for more information.
