You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/fortigate#prerequisites)

----------------------------------------------------------------------------------------------

Create a [Fortinet FortiGate](https://www.fortinet.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/fortigate#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API access token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/fortigate#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Fortinet FortiGate's API documentation](https://docs.fortinet.com/document/fortigate/7.4.3/administration-guide/940602/using-apis)
 for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/fortinet-fortigate/)
 on n8n's website.

Using API access token[](https://docs.n8n.io/integrations/builtin/credentials/fortigate#using-api-access-token)

----------------------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An API **Access Token**: To generate an access token, create a [REST API administrator](https://docs.fortinet.com/document/fortigate/7.4.3/administration-guide/399023/rest-api-administrator)
    .
    

Refer to the [Fortinet FortiGate Using APIs documentation](https://docs.fortinet.com/document/fortigate/7.4.3/administration-guide/940602/using-apis)
 for more information about token-based authentication in FortiGate.
