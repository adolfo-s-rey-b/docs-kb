*   [Toggl Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.toggltrigger)

 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/toggl#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   Basic auth
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/toggl#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [Toggl's API documentation](https://engineering.toggl.com/docs/)
 for more information about the service.

Using basic auth[](https://docs.n8n.io/integrations/builtin/credentials/toggl#using-basic-auth)

------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **Username**: Enter your user email address.
    
*   A **Password**: Enter your user password.
    

Refer to [Authentication](https://engineering.toggl.com/docs/authentication)
 for more information.
