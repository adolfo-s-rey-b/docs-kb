You can use these credentials to authenticate the following nodes:

*   [Peekalink](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.peekalink)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/peekalink#prerequisites)

----------------------------------------------------------------------------------------------

Create a [Peekalink](https://www.peekalink.io/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/peekalink#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/peekalink#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Peekalink's API documentation](https://docs.peekalink.io/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/peekalink#using-api-key)

----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: To get your API key, access your Peekalink [dashboard](https://peekalink.io/app)
     and copy the key in the **Your API Key** section. Refer to [Get your API key](https://docs.peekalink.io/quickstart#1-get-your-api-key)
     for more information.
