You can use these credentials to authenticate the following nodes:

*   [Lemlist](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.lemlist)
    
*   [Lemlist Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.lemlisttrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/lemlist#prerequisites)

--------------------------------------------------------------------------------------------

Create an account on a [Lemlist](https://www.lemlist.com/)
 instance.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/lemlist#supported-authentication-methods)

----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/lemlist#related-resources)

----------------------------------------------------------------------------------------------------

Refer to [Lemlist's API documentation](https://developer.lemlist.com/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/lemlist#using-api-key)

--------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Access your API key in **Settings > Integrations**. Refer to the [API Authentication documentation](https://developer.lemlist.com/#authentication)
     for more information.
