You can use these credentials to authenticate the following nodes:

*   [Serp](https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.toolserpapi)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/serp#prerequisites)

-----------------------------------------------------------------------------------------

Create a [SerpApi](https://serpapi.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/serp#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/serp#related-resources)

-------------------------------------------------------------------------------------------------

Refer to [Serp's API documentation](https://serpapi.com/search-api)
 for more information about the service.

View n8n's [Advanced AI](https://docs.n8n.io/build/integrate-ai)
 documentation.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/serp#using-api-key)

-----------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**
    

To get your API key:

1.  Go to **Your Account >** [**API Key**](https://serpapi.com/manage-api-key)
    .
    
2.  Copy **Your Private API Key** and enter it as the **API Key** in your n8n credential.
