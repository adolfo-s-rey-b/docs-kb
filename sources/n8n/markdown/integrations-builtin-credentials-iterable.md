You can use these credentials to authenticate the following nodes:

*   [Iterable](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.iterable)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/iterable#prerequisites)

---------------------------------------------------------------------------------------------

Create an [Iterable](https://iterable.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/iterable#supported-authentication-methods)

-----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/iterable#related-resources)

-----------------------------------------------------------------------------------------------------

Refer to Iterable's API documentation for more information about the service:

*   [US-based Iterable projects](https://api.iterable.com/api/docs)
    
*   [Europe-based Iterable projects](https://api.eu.iterable.com/api/docs)
    

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/iterable#using-api-key)

---------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to [Iterable's Creating API keys documentation](https://support.iterable.com/hc/en-us/articles/360043464871-API-Keys#creating-api-keys)
     for instructions on creating API keys.
