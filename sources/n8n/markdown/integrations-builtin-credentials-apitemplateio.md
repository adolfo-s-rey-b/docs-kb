You can use these credentials to authenticate the following nodes:

*   [APITemplate.io](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.apitemplateio)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/apitemplateio#prerequisites)

--------------------------------------------------------------------------------------------------

Create an [APITemplate.io](https://apitemplate.io/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/apitemplateio#supported-authentication-methods)

----------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/apitemplateio#related-resources)

----------------------------------------------------------------------------------------------------------

Refer to [APITemplate.io's API documentation](https://apitemplate.io/apiv2/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/apitemplateio#using-api-key)

--------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Once you've created an APITemplate.io account, go to **API Integration** to copy the **API Key**.
