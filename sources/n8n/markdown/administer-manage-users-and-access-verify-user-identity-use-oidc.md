**Feature availability**

*   Available on Enterprise plans.
    
*   You need to be an instance owner or admin to enable and configure OIDC.
    

This section covers how to enable and manage OpenID Connect (OIDC) for single sign-on (SSO). You can learn more about how OIDC works by visiting [what is OpenID Connect](https://openid.net/developers/how-connect-works/)
 by the OpenID Foundation.
