You can use these credentials to authenticate the following nodes:

*   [Acuity Scheduling Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.acuityschedulingtrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/acuityscheduling#prerequisites)

-----------------------------------------------------------------------------------------------------

Create an [Acuity Scheduling](https://acuityscheduling.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/acuityscheduling#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------------

*   API key
    
*   OAuth2
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/acuityscheduling#related-resources)

-------------------------------------------------------------------------------------------------------------

Refer to [Acuity's API documentation](https://developers.acuityscheduling.com/reference/quick-start)
 for more information about working with the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/acuityscheduling#using-api-key)

-----------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A numeric **User ID**
    
*   An **API Key**
    

Refer to the [Acuity API Quick Start authentication instructions](https://developers.acuityscheduling.com/reference/quick-start#authentication)
 to generate an API key and view your User ID.

Using OAuth2[](https://docs.n8n.io/integrations/builtin/credentials/acuityscheduling#using-oauth2)

---------------------------------------------------------------------------------------------------

**Note for n8n Cloud users**

Cloud users don't need to provide connection details. Select **Connect my account** to connect through your browser.

If you need to set this up from scratch, complete the [Acuity OAuth2 Account Registration page](https://acuityscheduling.com/oauth2/register)
. Use the **Client ID** and **Client Secret** provided from that registration.
