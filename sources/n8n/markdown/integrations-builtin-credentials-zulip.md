You can use these credentials to authenticate the following nodes:

*   [Zulip](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.zulip)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/zulip#prerequisites)

------------------------------------------------------------------------------------------

Create a [Zulip](https://zulip.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/zulip#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/zulip#related-resources)

--------------------------------------------------------------------------------------------------

Refer to [Zulip's API documentation](https://zulip.com/api/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/zulip#using-api-key)

------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **URL**: Enter the URL of your Zulip domain.
    
*   An **Email** address: Enter the email address you use to log in to Zulip.
    
*   An **API Key**: Get your API key in the **Gear cog > Personal Settings > Account & privacy > API Key**. Refer to [API Keys](https://zulip.com/api/api-keys)
     for more information.
