Use the AI Transform node to generate code snippets based on your prompt. The AI is context-aware, understanding the workflow’s nodes and their data types.

**Feature availability**

The AI Transform node is available on:

*   **n8n Cloud:** All plans
    

It isn't available on self-hosted n8n.

Node parameters[](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.aitransform#node-parameters)

------------------------------------------------------------------------------------------------------------------

### Instructions[](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.aitransform#instructions)

Enter your prompt for the AI and click the **Generate code** button to automatically populate the **Transformation Code**. For example, you can specify how you want to process or categorize your data. Refer to [Writing good prompts](https://docs.n8n.io/build/code-in-n8n/get-coding-help-from-ai#writing-good-prompts)
 for more information.

The prompt should be in plain English and under 500 characters.

### Transformation Code[](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.aitransform#transformation-code)

The code snippet generated by the node is read-only. To edit this code, adjust your prompt in **Instructions** or copy and paste it into a [Code](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.code)
 node.
