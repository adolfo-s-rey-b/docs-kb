Using API key[](https://docs.n8n.io/integrations/builtin/credentials/airtop#using-api-key)

-------------------------------------------------------------------------------------------

To configure this credential, you'll need an [Airtop](https://portal.airtop.ai/sign-up)
 account and an **API key**. To generate a new key:

1.  Log in to the [Airtop Portal](https://portal.airtop.ai/)
    .
    
2.  Go to [API Keys](https://portal.airtop.ai/api-keys)
    .
    
3.  Select the **\+ Create new key** button.
    
4.  Enter a name for the API key.
    
5.  Select the generated key to copy the key.
    
6.  Enter this as the **API Key** in your n8n credential.
    

Refer to [Airtop's Support](https://docs.airtop.ai/guides/misc/support)
 for assistance if you have any issues creating your API key.
