You can use these credentials to authenticate the following nodes:

*   [Affinity](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.affinity)
    
*   [Affinity Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.affinitytrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/affinity#prerequisites)

---------------------------------------------------------------------------------------------

Create an [Affinity](https://www.affinity.co/)
 account at the Scale, Advanced, or Enterprise subscription tiers.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/affinity#supported-authentication-methods)

-----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/affinity#related-resources)

-----------------------------------------------------------------------------------------------------

Refer to [Affinity's API documentation](https://support.affinity.co/s/article/Getting-started-with-the-Affinity-API-FAQs)
 for more information about working with the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/affinity#using-api-key)

---------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to [How to obtain your Affinity API key documentation](https://support.affinity.co/hc/en-us/articles/360032633992-How-to-obtain-your-Affinity-API-key)
     to get your API key.
