[Customer.io](https://customer.io/)
 enables users to send newsletters to selected segments of customers using their website data. You can send targeted emails, push notifications, and SMS to lower churn, create stronger relationships, and drive subscriptions.

**Credentials**

Refer to the [Customer.io credentials documentation](https://docs.n8n.io/integrations/builtin/credentials/customerio)
 for authentication information for this node.

**Examples and templates**

For usage examples and templates to help you get started, refer to n8n's [Customer.io Trigger integrations](https://n8n.io/integrations/customerio-trigger/)
 page.
