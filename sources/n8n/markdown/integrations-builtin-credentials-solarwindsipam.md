Using Username & Password[](https://docs.n8n.io/integrations/builtin/credentials/solarwindsipam#using-username-and-password)

-----------------------------------------------------------------------------------------------------------------------------

To configure this credential, you'll need a SolarWinds IPAM account and:

*   **URL**: The base URL of your SolarWinds IPAM server
    
*   **Username**: The username you use to access SolarWinds IPAM
    
*   **Password**: The password you use to access SolarWinds IPAM
    

Refer to [SolarWinds IPAM's API documentation](https://github.com/solarwinds/OrionSDK/wiki/REST)
 for more information about authenticating to the service.
