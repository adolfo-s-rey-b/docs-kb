Self-host with Docker Compose:

*   [DigitalOcean](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-digital-ocean)
    : self-host n8n on a DigitalOcean droplet with a real domain and automatic HTTPS.
    
*   [Heroku](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-heroku)
    : self-host n8n on Heroku.
    
*   [Hetzner Cloud](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-hetzner)
    : self-host n8n on a Hetzner Cloud server.
    

Self-host with Google Cloud Run (with access to n8n workflow tools for Google Workspace, for example Gmail and Drive):

*   [Google Cloud Run](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-google-cloud-run)
    : self-host n8n on Google Cloud Run, a serverless container runtime.
    

Starting points for a Kubernetes setup:

*   [AWS](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-aws)
    : self-host n8n on Amazon Web Services with Postgres and Kubernetes.
    
*   [AWS with Terraform](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-aws-with-terraform)
    : deploy a production-grade, highly available n8n instance on AWS using the official Terraform module.
    
*   [Azure](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-azure)
    : self-host n8n on Azure with Postgres and Kubernetes.
    
*   [Google Kubernetes Engine (GKE)](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-google-kubernetes)
    : self-host n8n on Google Kubernetes Engine.
    
*   [OpenShift Local (CRC)](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/deploy-to-openshift-local-crc)
    : deploy n8n on a local OpenShift cluster for testing, without cloud costs.
    

Configuration guides to help you get started on other platforms:

*   [Docker Compose](https://docs.n8n.io/deploy/host-n8n/install-options/use-a-cloud-provider/use-docker-compose)
    : install and run n8n using Docker Compose.
