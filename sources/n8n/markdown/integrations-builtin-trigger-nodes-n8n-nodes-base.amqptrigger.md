[AMQP](https://www.amqp.org/)
 is an open standard application layer protocol for message-oriented middleware. The defining features of AMQP are message orientation, queuing, routing, reliability and security. This node supports AMQP 1.0 compatible message brokers.

**Credentials**

Refer to the [AMQP credentials documentation](https://docs.n8n.io/integrations/builtin/credentials/amqp)
 for authentication information for this node.
