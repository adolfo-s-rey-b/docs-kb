You can use these credentials to authenticate the following nodes:

*   [Venafi TLS Protect Cloud node](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.venafitlsprotectcloud)
    
*   [Venafi TLS Protect Cloud Trigger node](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.venafitlsprotectcloudtrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/venafitlsprotectcloud#prerequisites)

----------------------------------------------------------------------------------------------------------

Create a Venafi [TLS Protect Cloud](https://venafi.com/tls-protect/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/venafitlsprotectcloud#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/venafitlsprotectcloud#related-resources)

------------------------------------------------------------------------------------------------------------------

Refer to [Venafi TLS Protect Cloud's API documentation](https://docs.venafi.cloud/api/vaas-rest-api/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/venafitlsprotectcloud#using-api-key)

----------------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **Region**: Select the region that matches your business needs. Choose **EU** if you're located in the European Union. Otherwise, choose **US**.
    
*   An **API Key**: Go to your **avatar > Preferences > API Keys** to get your API key. You can also use VCert to get your API key. Refer to [Obtaining an API Key](https://docs.venafi.cloud/api/obtaining-api-key/)
     for more information.
