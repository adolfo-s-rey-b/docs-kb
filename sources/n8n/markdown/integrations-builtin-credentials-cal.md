You can use these credentials to authenticate the following nodes:

*   [Cal.com Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.caltrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/cal#prerequisites)

----------------------------------------------------------------------------------------

Create a [Cal.com](https://www.cal.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/cal#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/cal#related-resources)

------------------------------------------------------------------------------------------------

Refer to [Cal.com's API documentation](https://cal.com/docs/enterprise-features/api#api-server-specifications)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/cal#using-api-key)

----------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to the [Cal.com API documentation](https://cal.com/docs/api-reference/v2/introduction)
     for information on how to generate a new API key.
    
*   A **Host**: If you're using the cloud version of Cal.com, leave the Host as `https://api.cal.com`. If you're self-hosting Cal.com, enter the **Host** for your Cal.com instance.
