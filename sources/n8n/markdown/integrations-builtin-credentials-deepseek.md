Using API key[](https://docs.n8n.io/integrations/builtin/credentials/deepseek#using-api-key)

---------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**
    

To generate your API Key:

1.  Login to your DeepSeek account or [create](https://platform.deepseek.com/sign_up)
     an account.
    
2.  Open your [API keys](https://platform.deepseek.com/api_keys)
     page.
    
3.  Select **Create new secret key** to create an API key, optionally naming the key.
    
4.  Copy your key and add it as the **API Key** in n8n.
    

Refer to the [Your First API Call](https://api-docs.deepseek.com/)
 page for more information.
