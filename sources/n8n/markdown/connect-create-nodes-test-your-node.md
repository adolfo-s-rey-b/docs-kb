This section contains information about testing your node. You can test nodes manually and automatically. You should use both testing methods before publishing your node.

In this section[](https://docs.n8n.io/connect/create-nodes/test-your-node#in-this-section)

-------------------------------------------------------------------------------------------

*   [Run your node locally](https://docs.n8n.io/connect/create-nodes/test-your-node/run-your-node-locally)
    : manually test your node on your own machine, within a local n8n instance.
    
*   [Node linter](https://docs.n8n.io/connect/create-nodes/test-your-node/node-linter)
    : automatically test your node against n8n's linting rules.
    
*   [Troubleshooting](https://docs.n8n.io/connect/create-nodes/test-your-node/troubleshooting)
    : common issues you might encounter, and how to fix them.
