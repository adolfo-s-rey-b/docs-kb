[ConvertKit](https://www.convertkit.com/)
 is a fully featured email marketing platform. Use ConvertKit to build an email list, send email broadcasts, automate sequences, create segments, and build landing pages.

**Credentials**

Refer to the [ConvertKit credentials documentation](https://docs.n8n.io/integrations/builtin/credentials/convertkit)
 for authentication information for this node.

**Examples and templates**

For usage examples and templates to help you get started, refer to n8n's [ConvertKit Trigger integrations](https://n8n.io/integrations/convertkit-trigger/)
 page.
