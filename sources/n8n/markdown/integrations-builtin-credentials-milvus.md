You can use these credentials to authenticate the following nodes:

*   [Milvus Vector Store](https://docs.n8n.io/integrations/builtin/cluster-nodes/root-nodes/n8n-nodes-langchain.vectorstoremilvus)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/milvus#prerequisites)

-------------------------------------------------------------------------------------------

Create and run an [Milvus](https://milvus.io/)
 instance. Refer to the [Install Milvus](https://milvus.io/docs/install-overview.md)
 for more information.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/milvus#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   Basic auth
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/milvus#related-resources)

---------------------------------------------------------------------------------------------------

Refer to [Milvus's Authentication documentation](https://milvus.io/docs/authenticate.md?tab=docker#Authenticate-User-Access)
 for more information about setting up authentication.

View n8n's [Advanced AI](https://docs.n8n.io/build/integrate-ai)
 documentation.

Using basic auth[](https://docs.n8n.io/integrations/builtin/credentials/milvus#using-basic-auth)

-------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   **Base URL**: The base URL of your Milvus instance. The default is `http://localhost:19530`.
    
*   **Username**: The username to authenticate to your Milvus instance. The default value is `root`.
    
*   **Password**: The password to authenticate to your Milvus instance. The default value is `Milvus`.
