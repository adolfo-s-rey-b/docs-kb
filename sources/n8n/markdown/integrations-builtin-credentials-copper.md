You can use these credentials to authenticate the following nodes:

*   [Copper](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.copper)
    
*   [Copper Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.coppertrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/copper#prerequisites)

-------------------------------------------------------------------------------------------

Create a [Copper](https://www.copper.com/)
 account at the **Professional** or **Business** plan level.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/copper#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/copper#related-resources)

---------------------------------------------------------------------------------------------------

Refer to [Copper's API documentation](https://developer.copper.com/)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/copper#using-api-key)

-------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Refer to the [Copper Generating an API key documentation](https://support.copper.com/en/articles/8823347-generating-an-api-key)
     for information on generating an API key.
    
*   An **Email** address: Use the API key creator's email address
