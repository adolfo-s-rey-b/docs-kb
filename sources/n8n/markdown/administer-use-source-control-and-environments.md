**Feature availability**

*   Available on Business and Enterprise plans.
    
*   You must be an n8n instance owner or instance admin to enable and configure source control.
    
*   Instance owners and instance admins can push changes to and pull changes from the connected repository.
    
*   Project admins can push changes to the connected repository. They can't pull changes from the repository.
    

**New version available**

These pages cover Environments (Classic). For the new version, in Preview and available on Enterprise plans, see [Environments](https://docs.n8n.io/administer/environments)
. To compare the versions and upgrade an instance, see [Upgrade from Environments (Classic)](https://docs.n8n.io/administer/environments/upgrade-from-environments-classic)
.

n8n uses Git-based source control to support environments. Linking your n8n instances to a Git repository lets you create multiple n8n environments, backed by Git branches.
