You can use these credentials to authenticate the following nodes:

*   [Cohere](https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.lmcohere)
    
*   [Cohere Chat](https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.lmchatcohere)
    
*   [Reranker Cohere](https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.rerankercohere)
    
*   [Embeddings Cohere](https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.embeddingscohere)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/cohere#prerequisites)

-------------------------------------------------------------------------------------------

Create a [Cohere account](https://cohere.com/)
.

You'll need an account with the following access:

*   For the Trial API, you need User or Owner permissions.
    
*   For Production API, you need Owner permissions.
    

Refer to [Cohere Teams and Roles documentation](https://docs.cohere.com/reference/teams-and-roles)
 for more information.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/cohere#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------

*   API key

*   An **API Key**: To generate a Cohere API key, go to the [API Keys section of your Cohere dashboard](https://dashboard.cohere.com/api-keys)
