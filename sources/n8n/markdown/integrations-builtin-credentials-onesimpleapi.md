You can use these credentials to authenticate the following nodes:

*   [One Simple API](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.onesimpleapi)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/onesimpleapi#prerequisites)

-------------------------------------------------------------------------------------------------

Create a [One Simple API](https://onesimpleapi.com/register)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/onesimpleapi#supported-authentication-methods)

---------------------------------------------------------------------------------------------------------------------------------------

*   API token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/onesimpleapi#related-resources)

---------------------------------------------------------------------------------------------------------

Refer to [One Simple API's documentation](https://onesimpleapi.com/docs)
 for more information about the service.

Using API token[](https://docs.n8n.io/integrations/builtin/credentials/onesimpleapi#using-api-token)

-----------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API token**: Create a new API token on the [API Tokens](https://onesimpleapi.com/user/api-tokens)
     page. Be sure you select appropriate permissions for the token.
    

You can also access the API Tokens page by selecting your **Profile > API Tokens**.
