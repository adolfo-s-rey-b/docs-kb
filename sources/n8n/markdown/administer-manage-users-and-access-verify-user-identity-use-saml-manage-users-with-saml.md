**Feature availability**

*   Available on Business and Enterprise plans.
    
*   You need to be an instance owner or admin to enable and configure SAML.
    

There are some user management tasks that are affected by SAML.

Exempt users from SAML[](https://docs.n8n.io/administer/manage-users-and-access/verify-user-identity/use-saml/manage-users-with-saml#exempt-users-from-saml)

-------------------------------------------------------------------------------------------------------------------------------------------------------------

You can allow users to log in without using SAML. To do this:

1.  Go to **Settings** > **Users**.
    
2.  Select the menu icon by the user you want to exempt from SAML.
    
3.  Select **Allow Manual Login**.
    

Deleting users[](https://docs.n8n.io/administer/manage-users-and-access/verify-user-identity/use-saml/manage-users-with-saml#deleting-users)

---------------------------------------------------------------------------------------------------------------------------------------------

If you remove a user from your IdP, they remain logged in to n8n. You need to manually remove them from n8n as well. Refer to [Manage users](https://docs.n8n.io/administer/manage-users-and-access/add-and-remove-users)
 for guidance on deleting users.
