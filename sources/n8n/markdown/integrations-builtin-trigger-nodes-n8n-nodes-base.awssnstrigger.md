[AWS SNS](https://aws.amazon.com/sns/)
 is a notification service provided as part of Amazon Web Services. It provides a low-cost infrastructure for the mass delivery of messages, predominantly to mobile users.

**Credentials**

Refer to the [AWS credentials documentation](https://docs.n8n.io/integrations/builtin/credentials/aws)
 for authentication information for this node.

**Examples and templates**

For usage examples and templates to help you get started, refer to n8n's [AWS SNS Trigger integrations](https://n8n.io/integrations/aws-sns-trigger/)
 page.
