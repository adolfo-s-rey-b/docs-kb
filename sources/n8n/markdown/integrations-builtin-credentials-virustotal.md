You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/virustotal#prerequisites)

-----------------------------------------------------------------------------------------------

Create a [VirusTotal](https://www.virustotal.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/virustotal#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/virustotal#related-resources)

-------------------------------------------------------------------------------------------------------

Refer to [VirusTotal's documentation](https://docs.virustotal.com/reference/overview)
 for more information about the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/virustotal/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/virustotal#using-api-key)

-----------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Token**: Go to your **user account menu > API key** to get your API key. Enter this as the **API Token** in your n8n credential. Refer to [API authentication](https://docs.virustotal.com/reference/authentication)
     for more information.
