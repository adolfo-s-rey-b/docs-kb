This section contains reference information for node builders. It covers node UI elements, key parameters in your node's base and credentials files, and the guidelines for submitting your node for [verification by n8n](https://docs.n8n.io/integrations/community-nodes/installation-and-management/install-verified-community-nodes)
.

In this section[](https://docs.n8n.io/connect/create-nodes/build-your-node/reference#in-this-section)

------------------------------------------------------------------------------------------------------

*   [Node UI elements](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/node-ui-elements)
    : the predefined UI components available for your node's parameters.
    
*   [Code standards](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/code-standards)
    : good code practices for node building.
    
*   [Error handling](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/error-handling)
    : the error classes n8n provides for node implementations.
    
*   [Versioning](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/versioning)
    : make changes to an existing node without breaking its current behavior.
    
*   [Base files](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/base-files)
    : the core code of your node, for declarative and programmatic styles.
    
*   [Codex files](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/codex-files)
    : the JSON file that holds your node's metadata.
    
*   [Credentials files](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/credentials-files)
    : define the authorization methods for your node.
    
*   [HTTP request helpers](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/http-request-helpers)
    : make HTTP requests from your node.
    
*   [Item linking](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/item-linking)
    : link output items back to the items that generated them.
    
*   [UX guidelines](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/ux-guidelines)
    : the UI conventions a verified community node must follow.
    
*   [Verification guidelines](https://docs.n8n.io/connect/create-nodes/build-your-node/reference/verification-guidelines)
    : the requirements for n8n to verify your community node.
