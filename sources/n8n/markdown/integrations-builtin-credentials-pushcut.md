You can use these credentials to authenticate the following nodes:

*   [Pushcut](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.pushcut)
    
*   [Pushcut Trigger](https://docs.n8n.io/integrations/builtin/trigger-nodes/n8n-nodes-base.pushcuttrigger)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/pushcut#prerequisites)

--------------------------------------------------------------------------------------------

Download the [Pushcut](https://www.pushcut.io/)
 app.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/pushcut#supported-authentication-methods)

----------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/pushcut#related-resources)

----------------------------------------------------------------------------------------------------

Refer to [Pushcut's Guides documentation](https://www.pushcut.io/guides)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/pushcut#using-api-key)

--------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: To generate an API key, go to **Account > Integrations > Add API Key**. Refer to [Create an API key](https://www.pushcut.io/guides/homekit-api-schedule-cancel#step_2)
     for more information.
