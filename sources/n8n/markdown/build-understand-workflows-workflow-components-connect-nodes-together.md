A connection establishes a link between nodes to route data through the workflow. A connection between two nodes passes data from one node's output to another node's input.

![](https://docs.n8n.io/~gitbook/image?url=https%3A%2F%2F3488703508-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FrPN1zU5jaYNvwH7RzxqA%252Fuploads%252Fgit-blob-bbf94eae044d747c8c90b8ccb67791ef16265797%252Fexample.gif%3Falt%3Dmedia&width=768&dpr=3&quality=100&sign=01b196724719367a9ea0b3899b4e8f9f&sv=3)

Example of creating and deleting a connection

Create a connection[](https://docs.n8n.io/build/understand-workflows/workflow-components/connect-nodes-together#create-a-connection)

-------------------------------------------------------------------------------------------------------------------------------------

To create a connection between two nodes, select the grey dot or **Add node** ![Add node icon](https://docs.n8n.io/~gitbook/image?url=https%3A%2F%2F3488703508-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FrPN1zU5jaYNvwH7RzxqA%252Fuploads%252Fgit-blob-73e6ba16c5921db1159055c997764094715b508e%252Fadd-node-small.png%3Falt%3Dmedia&width=40&dpr=3&quality=100&sign=b0d68592e1e36e94c9f6e4f46843819b&sv=3) on the right side of a node and slide the arrow to the grey rectangle on the left side of the following node.

Delete a connection[](https://docs.n8n.io/build/understand-workflows/workflow-components/connect-nodes-together#delete-a-connection)

-------------------------------------------------------------------------------------------------------------------------------------

Hover over the connection, then select **Delete** ![Delete connector icon](https://docs.n8n.io/~gitbook/image?url=https%3A%2F%2F3488703508-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FrPN1zU5jaYNvwH7RzxqA%252Fuploads%252Fgit-blob-e4a0688f3f38d222fe681c8322126446e27da49a%252Fdelete-connector.png%3Falt%3Dmedia&width=39&dpr=3&quality=100&sign=ba7904684b190e98b35fff91d2c62c26&sv=3).
