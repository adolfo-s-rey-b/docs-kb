You can use these credentials to authenticate the following nodes:

*   [ProfitWell](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.profitwell)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/profitwell#prerequisites)

-----------------------------------------------------------------------------------------------

Create a [ProfitWell](https://www2.profitwell.com/signup/start)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/profitwell#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------------

*   API token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/profitwell#related-resources)

-------------------------------------------------------------------------------------------------------

Refer to [Profitwell's API documentation](https://profitwellapiv2.docs.apiary.io/)
 for more information about the service.

Using API token[](https://docs.n8n.io/integrations/builtin/credentials/profitwell#using-api-token)

---------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Token**: To get an API key or token, go to **Account Settings > Integrations** and select **ProfitWell API**.
