You can use these credentials to authenticate the following nodes:

*   [Kitemaker](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.kitemaker)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/kitemaker#prerequisites)

----------------------------------------------------------------------------------------------

Create a [Kitemaker](https://www.kitemaker.co/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/kitemaker#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API access token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/kitemaker#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Kitemaker's API documentation](https://kitemakerhq.github.io/rest-docs/)
 for more information about the service.

Using API access token[](https://docs.n8n.io/integrations/builtin/credentials/kitemaker#using-api-access-token)

----------------------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   A **Personal Access Token**: Generate a personal access token from **Manage > Developer settings**. Refer to [API Authentication](https://kitemakerhq.github.io/rest-docs/#documentationauthentication)
     for more detailed instructions.
