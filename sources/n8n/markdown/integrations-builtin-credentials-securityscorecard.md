You can use these credentials to authenticate the following nodes:

*   [SecurityScorecard](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.securityscorecard)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/securityscorecard#prerequisites)

------------------------------------------------------------------------------------------------------

Create a [SecurityScorecard](https://securityscorecard.com/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/securityscorecard#supported-authentication-methods)

--------------------------------------------------------------------------------------------------------------------------------------------

*   API key
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/securityscorecard#related-resources)

--------------------------------------------------------------------------------------------------------------

Refer to [SecurityScorecard's Developer documentation](https://securityscorecard.readme.io/docs/integrate-ratings-platform-services)
 and [API documentation](https://securityscorecard.readme.io/reference/introduction)
 for more information about the service.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/securityscorecard#using-api-key)

------------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Generate an API key in one of two ways:
    
    *   As a user in [**My Settings > API**](https://platform.securityscorecard.io/#/my-settings/api)
        . Refer to [Get an API key](https://securityscorecard.readme.io/docs/getting-started#step-1-get-an-api-key)
         for more information.
        
    *   As a bot user: View the bot user and select **create token**. Refer to [Authenticate with a bot user](https://securityscorecard.readme.io/docs/authentication#)
         for more information.
