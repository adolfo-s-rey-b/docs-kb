You can use these credentials to authenticate the following nodes:

*   [Coda](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.coda)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/coda#prerequisites)

-----------------------------------------------------------------------------------------

Create a [Coda](https://www.coda.io/)
 account.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/coda#supported-authentication-methods)

-------------------------------------------------------------------------------------------------------------------------------

*   API access token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/coda#related-resources)

-------------------------------------------------------------------------------------------------

Refer to [Coda's API documentation](https://coda.io/developers/apis/v1)
 for more information about the service.

Using API access token[](https://docs.n8n.io/integrations/builtin/credentials/coda#using-api-access-token)

-----------------------------------------------------------------------------------------------------------

*   An API **Access Token**: Generate an API access token in your Coda [**Account settings**](https://coda.io/@oleg/getting-started-guide-coda-api/start-here-5#_luxC4)
    .
