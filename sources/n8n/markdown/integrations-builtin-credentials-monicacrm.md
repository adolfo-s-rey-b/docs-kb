You can use these credentials to authenticate the following nodes:

*   [Monica CRM](https://docs.n8n.io/integrations/builtin/app-nodes/n8n-nodes-base.monicacrm)
    

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/monicacrm#prerequisites)

----------------------------------------------------------------------------------------------

Sign up for a [Monica CRM](https://www.monicahq.com/)
 account or self-host an instance.

Supported authentication methods[](https://docs.n8n.io/integrations/builtin/credentials/monicacrm#supported-authentication-methods)

------------------------------------------------------------------------------------------------------------------------------------

*   API token
    

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/monicacrm#related-resources)

------------------------------------------------------------------------------------------------------

Refer to [Monica's documentation](https://docs.monicahq.com/)
 for more information about the service.

Using API token[](https://docs.n8n.io/integrations/builtin/credentials/monicacrm#using-api-token)

--------------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   Your **Environment**:
    
    *   Select **Cloud-Hosted** if you access your Monica instance through Monica.
        
    *   Select **Self-Hosted** if you have self-hosted Monica on your own server. Provide your **Self-Hosted Domain**.
        
    
*   An **API Token**: Generate a token in **Settings > API**.
