You can use these credentials to authenticate when using the [HTTP Request node](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.httprequest)
 to make a [Custom API call](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
.

Prerequisites[](https://docs.n8n.io/integrations/builtin/credentials/filescan#prerequisites)

---------------------------------------------------------------------------------------------

Create a [Filescan](https://www.filescan.io/auth/signup/)
 account.

Related resources[](https://docs.n8n.io/integrations/builtin/credentials/filescan#related-resources)

-----------------------------------------------------------------------------------------------------

Refer to [Filescan's API documentation](https://www.filescan.io/api/docs)
 for more information about authenticating with the service.

This is a credential-only node. Refer to [Custom API operations](https://docs.n8n.io/integrations/builtin/custom-api-actions-for-existing-nodes)
 to learn more. View [example workflows and related content](https://n8n.io/integrations/filescan/)
 on n8n's website.

Using API key[](https://docs.n8n.io/integrations/builtin/credentials/filescan#using-api-key)

---------------------------------------------------------------------------------------------

To configure this credential, you'll need:

*   An **API Key**: Generate your API key from your [**profile settings**](https://www.filescan.io/users/profile)
     **\> API Key**. Refer to the [Filescan FAQ](https://www.filescan.io/help/faq)
     for more information.
