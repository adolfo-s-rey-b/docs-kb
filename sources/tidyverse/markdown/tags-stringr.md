[package](https://tidyverse.org/categories/package)

Hadley Wickham

This release deprecates `str_like(ignore_case)` and changes the behaviour of `str_replace_all()` for function replacements. It also introduces `str_ilike()` for case-insensitive SQL-like pattern matching, three new case conversion functions (`str_to_camel()`, `str_to_snake()`, and `str_to_kebab()`), and preserves names in all relevant functions.
