R packages for data science
===========================

The tidyverse is an opinionated [collection of R packages](https://tidyverse.org/packages)
 designed for data science. All packages share an underlying design philosophy, grammar, and data structures.

Install the complete tidyverse with:

    install.packages("tidyverse")
