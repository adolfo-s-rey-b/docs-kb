KerasHub Samplers
=================

KerasHub samplers are used to control the sampling process when generating text with generative models. See [`keras_hub.models.CausalLM`](https://keras.io/keras_hub/api/base_classes/causal_lm#causallm-class)
 for the high-level generative API.
