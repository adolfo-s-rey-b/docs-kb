Command Line Operations[](https://docs.posit.co/ide/desktop-pro/2025.09.1/license_management/command_line_operations.html#command-line-operations)

---------------------------------------------------------------------------------------------------------------------------------------------------

All licensing operations available in the RStudio user interface may also be performed from the command-line using the _license-manager_ executable. This is rarely necessary, except in some cases outlined earlier in this document, or if instructed by a customer support representative.

|     |     |
| --- | --- | 
| Windows | C:\\Program Files\\RStudio\\bin\\license-manager.exe |
| macOS | /Applications/RStudio.app/Contents/MacOS/license-manager |
| Linux | /usr/lib/rstudio/bin/license-manager |
