---------------------------------------------------------------------------------------------------------

When a user first starts RStudio it will activate an initial evaluation period during which the product is fully usable. After the evaluation period expires, the product will need to be activated with a license to continue using it.

### Viewing License Status[](https://docs.posit.co/ide/desktop-pro/2025.09.2/getting_started/activation.html#viewing-license-status)

Use **Help/Manage License** menu to display the _Manage RStudio License_ dialog and view the amount of time remaining in the evaluation.

![](https://docs.posit.co/ide/desktop-pro/2025.09.2/images/manage-first-run-eval.png)

Manage License Dialog Showing Evaluation Period

The license status can also be viewed from the _About_ dialog.

![](https://docs.posit.co/ide/desktop-pro/2025.09.2/images/about-first-run-eval.png)

RStudio Pro About Dialog

### License Activation[](https://docs.posit.co/ide/desktop-pro/2025.09.2/getting_started/activation.html#license-activation)

After [purchasing a license](https://docs.posit.co/ide/desktop-pro/2025.09.2/license_management/license_management.html#purchasing-a-license)
, you will receive a license file (.lic). From the **Manage RStudio License** dialog, click **Select license file…** and follow the instructions.

Additional details on license management can be found in the [License Management](https://docs.posit.co/ide/desktop-pro/2025.09.2/license_management/license_management.html)
 section.
