### Beginning Evaluations[](https://docs.posit.co/ide/desktop-pro/2026.08.1/license_management/evaluations.html#beginning-evaluations)

In most configurations, an evaluation starts automatically when Posit professional software is run for the first time by a given user account on a given computer.

|     |     |     |
| --- | --- | --- |  
| Physical | Yes | Automatic |
| Physical | No  | Automatic |
| Virtual | Yes | Automatic |
| Virtual | No  | Manual (requires license file-based trial) |

For the final case, a virtual machine without internet access, contact Posit to obtain a license file to enable a trial period.

### Extending Evaluations[](https://docs.posit.co/ide/desktop-pro/2026.08.1/license_management/evaluations.html#extending-evaluations)

If you cannot complete your evaluation of Posit professional software within the initial period, request an extension through the [Posit support form](https://support.posit.co/hc/en-us/requests/new)
. Posit Support will provide a short-term license file, which you install exactly like a standard license.
