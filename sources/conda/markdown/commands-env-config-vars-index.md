`conda env config vars`[#](https://docs.conda.io/projects/conda/en/stable/commands/env/config/vars/index.html#conda-env-config-vars "Link to this heading")

============================================================================================================================================================

Interact with environment variables associated with Conda environments.

usage: conda env config vars \[\-h\] {list,set,unset} ...

Copy to clipboard

Examples:

> conda env config vars list -n my\_env conda env config vars set MY\_VAR=foo conda env config vars unset MY\_VAR
