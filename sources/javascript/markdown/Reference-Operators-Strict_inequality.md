Strict inequality (!==)
=======================

Baseline

Widely available

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Strict_inequality#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **strict inequality (`!==`)** operator checks whether its two operands are not equal, returning a Boolean result. Unlike the [inequality](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Inequality)
 operator, the strict inequality operator always considers operands of different types to be different.

[Try it](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Strict_inequality#try_it)

---------------------------------------------------------------------------------------------------------------

[Syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Strict_inequality#syntax)

[Description](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Strict_inequality#description)

 operator so the following two lines will always give the same result:

For details of the comparison algorithm, see the page for the [strict equality](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Strict_equality)
 operator.

Like the strict equality operator, the strict inequality operator will always consider operands of different types to be different:
