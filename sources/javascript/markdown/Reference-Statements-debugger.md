debugger
========

Baseline

Widely available

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/debugger#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`debugger`** statement invokes any available debugging functionality, such as setting a breakpoint. If no debugging functionality is available, this statement has no effect.

[Syntax](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/debugger#syntax)

When the debugger is invoked, execution is paused at the `debugger` statement. It is like a breakpoint in the script source.
