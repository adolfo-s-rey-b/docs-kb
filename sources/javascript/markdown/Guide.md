JavaScript Guide
================

The JavaScript Guide shows you how to use [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
 and gives an overview of the language. If you need exhaustive information about a language feature, have a look at the [JavaScript reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
.

This Guide is divided into the following chapters.
