Math.LOG2E
==========

Baseline

Widely available

This feature is well established and works across many devices and browser versions. It’s been available across browsers since July 2015.

*   [See full compatibility](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/LOG2E#browser_compatibility)
    
*   [Learn more](https://developer.mozilla.org/en-US/docs/Glossary/Baseline/Compatibility)
    

The **`Math.LOG2E`** static data property represents the base 2 logarithm of [e](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/E)
, approximately 1.443.

[Try it](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/LOG2E#try_it)

-------------------------------------------------------------------------------------------------------------

    function getLog2e() {
      return Math.LOG2E;
    }
    
    console.log(getLog2e());
    // Expected output: 1.4426950408889634
    

[Value](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/LOG2E#value)

-----------------------------------------------------------------------------------------------------------

[Description](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/LOG2E#description)

-----------------------------------------------------------------------------------------------------------------------

Because `LOG2E` is a static property of `Math`, you always use it as `Math.LOG2E`, rather than as a property of a `Math` object you created (`Math` is not a constructor).

[Examples](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/LOG2E#examples)

-----------------------------------------------------------------------------------------------------------------

### [Using Math.LOG2E](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/LOG2E#using_math.log2e)

The following function returns the base 2 logarithm of e:

js

    function getLog2e() {
      return Math.LOG2E;
    }
    
    getLog2e(); // 1.4426950408889634
